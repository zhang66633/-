# 题库编写规范与黄金示例

> 本文件是给题库编写 agent 的规范说明,**不是数据文件**(yaml 加载器跳过非 .yaml)。
> 题目写在 `quiz_data_<批次>.yaml` 中(按你负责的单元),格式见下。

## 格式

```yaml
- id: modeler_lp_01_q1          # 全局唯一: {unit_id}_q{n}, n 从 1 起
  unit_id: modeler_lp_01        # 必须对应 content/<role>/ 下真实存在的单元 id
  role: modeler                 # modeler | programmer | writer
  category: 优化                # 与单元 method_category 一致;编程手/论文手统一用「编程」/「论文写作」
  difficulty: beginner          # beginner | intermediate | advanced(与单元难度一致)
  question: |
    题干。可以是多行,可含 LaTeX($...$ 行内、$$...$$ 独立行)。
  options:
    - 选项A(4 个,顺序打乱,不写 A./B. 前缀)
    - 选项B
    - 选项C
    - 选项D
  answer_index: 2               # 0-3,正确答案下标
  explanation: |
    解析:讲清为什么正确答案对、为什么干扰项错。
    干扰项必须是「常见错误结论」而非明显荒谬的选项。
  tags: [线性规划, 标准形式]
```

## 质量铁律

1. **4 个选项,全部有迷惑性** — 干扰项取自常见错误(符号反了、公式记混、步骤漏了)
2. **数字亲手验算** — 涉及计算,把结果在 Python/手算里验证过再写
3. **解析讲透** — 对 + 错 都解释,学生看了解析能举一反三
4. **与单元内容呼应** — 每单元 3 道题覆盖该单元核心概念/公式/经典例题三个角度
5. **难度对齐单元** — 入门=概念直问/一步计算;进阶=两步推理;实战=综合判断
6. **不要**出现「以上都对/以上都不对」型选项;不要把答案线索藏在选项长度/语气里

## 黄金示例(3 道,基准质量)

```yaml
- id: modeler_lp_01_q1
  unit_id: modeler_lp_01
  role: modeler
  category: 优化
  difficulty: beginner
  question: |
    将线性规划问题化为标准形式时,下列说法**错误**的是:
    原问题 $\\max z = 3x_1 + 5x_2$,$\\text{s.t. } x_1 \\leq 4,\\ 2x_2 \\leq 12,\\ x_1,x_2 \\geq 0$
  options:
    - 目标函数化为 $\\min -3x_1 - 5x_2$
    - $\\leq$ 约束应加上非负的松弛变量变为等式
    - 标准形式要求所有变量非负,原问题已满足
    - 松弛变量的目标系数应取 1
  answer_index: 3
  explanation: |
    松弛变量是「用不完的资源余量」,对目标函数没有任何贡献,目标系数必须为 0。
    取 1 意味着每单位松弛量反而「赚钱」,是典型错误。
    其余三项都是标准化的正确操作:max 转 min 取负目标系数、≤ 约束加非负松弛变量、
    原问题变量已非负无需处理。
  tags: [线性规划, 标准形式, 松弛变量]

- id: modeler_lp_01_q2
  unit_id: modeler_lp_01
  role: modeler
  category: 优化
  difficulty: beginner
  question: |
    用图解法求解 $\\max z = 3x_1 + 5x_2$,约束为 $x_1 \\leq 4$、$2x_2 \\leq 12$、
    $3x_1 + 2x_2 \\leq 18$、$x_1, x_2 \\geq 0$。最优解与最优值为:
  options:
    - $x_1 = 4,\\ x_2 = 3,\\ z = 27$
    - $x_1 = 2,\\ x_2 = 6,\\ z = 36$
    - $x_1 = 0,\\ x_2 = 6,\\ z = 30$
    - $x_1 = 4,\\ x_2 = 0,\\ z = 12$
  answer_index: 1
  explanation: |
    四个选项都是可行域顶点(所以都有迷惑性),需逐一检验:
    (4,3) 违反 $3x_1+2x_2 \\leq 18$(左端 18 恰好取等,可行!)——但 $z=27 < 36$,非最优;
    (2,6) 使第 2、3 约束同时取等($2x_2=12$、$3x_1+2x_2=18$),$z=36$ 最大,是最优解;
    (0,6) 与 (4,0) 是其余两个顶点,目标值 30 与 12,均非最优。
    判断顶点最优性的正确姿势:把所有顶点代入目标比大小(或用单纯形表逐一检验数)。
  tags: [线性规划, 图解法, 顶点]

- id: modeler_lp_01_q3
  unit_id: modeler_lp_01
  role: modeler
  category: 优化
  difficulty: intermediate
  question: |
    某 LP 最优时,资源约束 $x_1 + x_2 \\leq 10$ 取等号,其对偶变量 $y^* = 3$;
    另一约束 $x_1 \\leq 4$ 为严格不等式。下列说法**正确**的是:
  options:
    - 资源 1 增加 1 单位,最优目标值约改善 3;资源 2 的影子价格为 0
    - 资源 1 增加 1 单位,最优目标值约改善 10;资源 2 的影子价格为 3
    - 资源 1 的影子价格为 3,资源 2 的影子价格为 0,且两个约束都应继续加严
    - 影子价格只在对偶问题退化时才有意义,此处无法判断
  answer_index: 0
  explanation: |
    影子价格 = 对偶最优解 $y^*$:资源 1 约束取等(稀缺),每增 1 单位目标改善约 $y^*=3$;
    资源 2 是严格不等式(富余),互补松弛 ⇒ 其影子价格为 0 —— 增资源也无收益。
    「改善 10」混淆了右端项与影子价格;「都应加严」方向错误(富余资源无需加严);
    影子价格对非退化 LP 恒有意义,与是否退化无关。
  tags: [线性规划, 对偶理论, 影子价格, 互补松弛]
```
