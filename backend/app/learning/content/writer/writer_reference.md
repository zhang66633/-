# 文献检索与引用规范

> **难度**:实战 · **预计学习时长**:40 分钟 · **主讲智能体**:✏️ 编辑 · **类别**:论文写作

## 🎯 学习目标

学完本单元,你应该能够:

- 根据建模主题设计检索式,熟练使用知网、Google Scholar 等渠道并筛选高质量文献
- 掌握 GB/T 7714 的四种文献著录格式(期刊、专著、会议、网络),写出规范的参考文献表
- 正确使用 BibTeX + gbt7714 样式自动生成参考文献,并用 biblatex 处理中文文献
- 把握引用时机(假设、数据、方法对比处),避免无关引用堆砌与学术不端

## 📖 核心概念

### 1. 文献的三个作用

- **支撑**:假设的依据、参数的数据来源、方法的出处——「引用」让论文的每一步都有据可查
- **站位**:展示你对问题背景的调研深度,说明你的方法与已有工作的关系(改进/借鉴/对比)
- **避坑**:查过文献才知道前人做过了什么,避免「重新发明轮子」或踩已知的坑

> 国赛论文参考文献 10–20 条是常见区间:支撑数据来源、方法出处、经典教材,三类都要有。

### 2. 检索渠道与策略

| 渠道 | 定位 | 技巧 |
|------|------|------|
| **知网** | 中文期刊、学位论文 | 用「主题+关键词」组合;限定近 5 年、核心期刊(北大核心/CSSCI);看被引量排序 |
| **Google Scholar** | 英文文献入口 | 检索式用英文关键词;利用「被引用次数」与「相关文章」滚雪球 |
| **Web of Science** | SCI/SSCI 权威索引 | 按「高被引论文」筛选领域经典 |
| **arXiv** | 预印本(优化/机器学习类最新工作) | 时效性最强,注意非同行评审 |
| **GitHub** | 算法代码实现 | 复现论文方法时找开源实现,注意 license |
| **官方数据源** | 统计局、政府网站、行业报告 | 数据类引用的首选,权威且可复核 |

**检索策略三条**:①检索式 = 核心概念 + 方法词(如「车辆路径 遗传算法 时间窗」);②先精读 2–3 篇高被引综述/学位论文的文献综述部分,顺藤摸瓜(滚雪球法);③按「高被引 + 近 5 年」双标准筛选,兼顾经典与前沿。

### 3. 引用时机:五个必引之处

1. **数据来源处**:「本模型参数取自 ×× 市统计年鉴(2023)的数据[1]」
2. **假设依据处**:「乘客到达服从 Poisson 分布是排队系统的常规设定[2]」
3. **方法出处处**:「本文采用遗传算法[3]求解」——经典方法也要引,这既是学术规范也展示站位
4. **方法对比处**:「与文献[4]的贪心算法相比,本文方法总里程缩短 9.6%」——对比是「创造性」最直观的证明
5. **结论印证处**:「该结论与文献[5]对同类城市的调查一致」

### 4. GB/T 7714 著录格式(四种)

| 类型 | 格式 | 示例 |
|------|------|------|
| 期刊[J] | 作者. 题名[J]. 刊名, 年, 卷(期): 页码. | 王强, 李明. 基于改进遗传算法的车辆路径优化[J]. 运筹与管理, 2022, 31(4): 45-52. |
| 专著[M] | 作者. 书名[M]. 版本. 出版地: 出版社, 年: 页码. | 姜启源, 谢金星, 叶俊. 数学模型[M]. 3 版. 北京: 高等教育出版社, 2003: 1-20. |
| 会议[C] | 作者. 题名[C]//会议名. 出版地: 出版社, 年: 页码. | Smith J, Li M. A hybrid heuristic for CVRP[C]//Proceedings of the 2019 IEEE Congress on Evolutionary Computation. Wellington: IEEE, 2019: 102-109. |
| 网络[EB/OL] | 作者. 题名[EB/OL]. (发布日期)[引用日期]. 网址. | 国家统计局. 2023 年国民经济和社会发展统计公报[EB/OL]. (2024-02-29)[2024-08-10]. https://www.stats.gov.cn. |

> 文内引用用上标序号[1]、[2-3],按正文出现顺序编号;参考文献表与文内序号一一对应。**规范 = 全表格式统一**,一条写成期刊格式、一条写成网络格式的混乱是最高频问题。

### 5. BibTeX 与 biblatex:让文献自动化

- 参考文献库 `refs.bib` 每条一个条目,正文 `\cite{key}` 引用,编译时自动排序编号与排版——**改文献顺序、增删文献都不会导致编号错乱**,这是 LaTeX 相对 Word 的又一碾压级优势
- 中文文献推荐 biblatex + `gb7714-2015` 样式(严格按国标),编译引擎 Biber;英文环境可用 BibTeX + `gbt7714` 宏包
- 知网导出:文献详情页「导出与分析 → GB/T 7714-2015 格式引文」,可直接复制成 BibTeX 或手工转写条目

## 💡 经典例题

### 例题 1:差参考文献表 vs 好参考文献表(逐条对照)

**差表**:

> [1] 百度百科. 遗传算法. https://baike.baidu.com
> [2] 某博客文章:车辆路径问题简介
> [3] 姜启源. 数学模型
> [4] Genetic algorithms in search optimization and machine learning. 1989.

**逐条点评**:①百科与博客不是学术文献,评委会直接判定文献质量低下;②[2] 无作者、无出处、无日期,三无条目;③[3] 缺版本、出版地、出版社、年份——格式要素不全;④[4] 作者(应写 Goldberg D E)、出版社、出版地全缺,书名大小写不规范。四条全部不合格,且文内没有任何上标引用位置——文献表成了摆设。

**好表**:

> [1] 姜启源, 谢金星, 叶俊. 数学模型[M]. 3 版. 北京: 高等教育出版社, 2003.
> [2] 王强, 李明. 基于改进遗传算法的车辆路径优化[J]. 运筹与管理, 2022, 31(4): 45-52.
> [3] Goldberg D E. Genetic Algorithms in Search, Optimization and Machine Learning[M]. Boston: Addison-Wesley, 1989.
> [4] 国家统计局. 2023 年国民经济和社会发展统计公报[EB/OL]. (2024-02-29)[2024-08-10]. https://www.stats.gov.cn.

**点评**:类型齐全(专著/期刊/网络)、格式统一、著录要素完整;文内对应位置分别用上标 [1](模型假设处)、[2][3](方法对比处)、[4](数据来源处)引用。

### 例题 2:检索实操——从主题到文献(以「无人机配送路径规划」为例)

1. **拆词**:核心概念「无人机配送」+ 方法词「路径规划/车辆路径问题(VRP)」+ 约束词「时间窗/能耗」
2. **中文检索式**(知网):`主题=(无人机配送) AND (路径规划 OR 车辆路径) AND 时间窗`,限定 2019 年后、核心期刊;按被引排序,取前 3 篇精读
3. **英文检索式**(Google Scholar):`"drone delivery" AND "vehicle routing" AND "time window"`,查看高被引文献的被引列表滚雪球
4. **数据源**:民航局/邮政局的行业统计报告,用于参数(无人机载重、续航)取值
5. **落地**:最终文献表 = 1 本教材(建模方法)+ 2 篇中文核心(问题背景)+ 3 篇英文(算法前沿)+ 1 份官方报告(数据)——共 7 条,条条在正文有引用位置

### 例题 3:BibTeX 条目改错

```bibtex
@article{wang2022,
  author = {王强 and 李明},
  title = {基于改进遗传算法的车辆路径优化},
  journal = {运筹与管理},
  year = {2022},
}
```

**问题**:缺 `volume`、`number`、`pages` 字段——参考文献表会缺卷期页码,格式不完整。

**修正**:

```bibtex
@article{wang2022,
  author  = {王强 and 李明},
  title   = {基于改进遗传算法的车辆路径优化},
  journal = {运筹与管理},
  year    = {2022},
  volume  = {31},
  number  = {4},
  pages   = {45--52},
}
```

> 要点:多作者用 `and` 连接;页码区间用 `--`(双连字符)输出 en-dash;中文条目与英文条目同库混用没问题,样式宏包会统一排版。

## ⚠️ 常见易错点

1. **用百科/博客/营销文当文献**。百度百科、知乎、CSDN 博客不是学术来源——同类信息必须追到期刊论文、教材或官方报告
2. **文献表与正文脱节**。表里 15 条,正文一个上标都没有——每条文献都必须有至少一个引用位置
3. **格式要素缺失**。期刊缺卷期页码、专著缺出版社、网络缺访问日期——逐条对照 GB/T 7714 模板检查
4. **全文格式不统一**。一条半角逗号一条全角逗号、一条有出版社一条没有——统一是规范的第一要义
5. **引用无关文献凑数**。把与本题无关的文献塞进表里充数,评委抽查时一眼看穿,反而伤害全文可信度
6. **大段照抄文献**。直接复制文献原文段落是学术不端行为;引用必须改写并标注出处

## ✏️ 自测练习(选择题)

**第 1 题**:下列参考文献条目中,符合 GB/T 7714 期刊著录格式的是:

A. 李四, 供应链优化模型研究, 管理科学学报, 2019, 22(3): 12-20.
B. 王强, 李明. 基于改进遗传算法的车辆路径优化[J]. 运筹与管理, 2022, 31(4): 45-52.
C. 姜启源. 数学模型
D. 百度百科. 遗传算法. https://baike.baidu.com

<details><summary>查看答案与解析</summary>
**答案:B**。GB/T 7714 期刊格式:作者. 题名[J]. 刊名, 年, 卷(期): 页码.——B 要素齐全、分隔符正确。A 缺文献类型标识 [J],且作者与题名之间的句点丢失;C 缺版本、出版地、出版社、年份,著录要素不全;D 百科不是学术文献,评委会直接判定文献质量低下。
</details>

**第 2 题**:国赛论文中,以下哪个位置不属于「五个必引之处」?

A. 数据来源处:「本模型参数取自 ×× 市统计年鉴(2023)的数据[1]」
B. 方法出处处:「本文采用遗传算法[3]求解」
C. 结论印证处:「该结论与文献[5]对同类城市的调查一致」
D. 自己推导出的模型目标函数处

<details><summary>查看答案与解析</summary>
**答案:D**。五个必引之处:数据来源、假设依据、方法出处、方法对比、结论印证。自己推导的目标函数是原创内容,无需引用(反而应避免无关引用堆砌)。A、B、C 都是必引场景——数据有出处、经典方法也要引(既是规范也是站位)、结论与文献互证。
</details>

**第 3 题**:采用 biblatex + gb7714-2015 样式编排中英文参考文献,正确的编译流程是:

A. xelatex main 一次即可
B. xelatex → bibtex → xelatex → xelatex
C. xelatex → biber → xelatex → xelatex
D. biber → xelatex → bibtex(顺序不影响结果)

<details><summary>查看答案与解析</summary>
**答案:C**。biblatex 的后端工具是 Biber:先 xelatex 收集 \cite 信息,再 biber 生成文献数据,最后再编译两次写入并稳定编号。A 只编译一次,引用处显示 [?]、文献表空白;B 用了 BibTeX——那是传统 BibTeX 方案的后端,不能处理 biblatex;D 顺序错乱,且 biblatex 与 bibtex 混用必然报错。
</details>

## 🏆 竞赛实战链接

- **文献量与奖项**:历年一等奖论文的参考文献多在 10–20 条;文献质量(核心期刊、权威数据源)是「调研充分性」的直接体现,也是评阅专家判断队伍准备程度的第一印象之一
- **数据引用的评阅价值**:模型参数有权威出处(统计年鉴、行业报告)的论文,比「据估计取 0.5」的论文可信度高一个档次——数据引用是文献的「隐藏考点」
- **方法对比与「创造性」**:官方评阅标准中的「建模的创造性」,在文献对比中显性化:与文献 [n] 的方法相比,本文在××方面改进、结果提升 ×%——这类句子是创造性最直接的证据
- **美赛差异**:美赛引用无固定格式要求(常见 APA/自定格式),但同样要求引用来源;COMAP 强调引用 AI 工具使用情况(AI 生成内容需在报告中声明),文献部分依然要规范

## 💻 代码实现

**BibTeX 方案**(英文环境/简单需求):

```latex
% main.tex 中
\usepackage{gbt7714}          % 国标样式宏包(CTAN 提供)
...
\bibliographystyle{gbt7714-2005}
\bibliography{refs}
```

**biblatex 方案**(推荐,中英文文献统一按国标):

```latex
% main.tex 导言区
\usepackage[backend=biber, style=gb7714-2015]{biblatex}
\addbibresource{refs.bib}
% 正文末尾
\printbibliography
```

**refs.bib 示例**:

```bibtex
@book{jiang2003,
  author    = {姜启源 and 谢金星 and 叶俊},
  title     = {数学模型},
  edition   = {3},
  publisher = {高等教育出版社},
  address   = {北京},
  year      = {2003},
}

@article{wang2022,
  author  = {王强 and 李明},
  title   = {基于改进遗传算法的车辆路径优化},
  journal = {运筹与管理},
  year    = {2022},
  volume  = {31},
  number  = {4},
  pages   = {45--52},
}

@misc{stats2024,
  author  = {{国家统计局}},
  title   = {2023年国民经济和社会发展统计公报},
  year    = {2024},
  url     = {https://www.stats.gov.cn},
  urldate = {2024-08-10},
}
```

**编译流程**:`xelatex main` → `biber main`(BibTeX 方案用 `bibtex main`)→ `xelatex main` → `xelatex main`。正文用 `\cite{jiang2003}` 引用,文献表自动生成并按 GB/T 7714-2015 排版。

## 🧠 小结

1. 文献三作用:支撑(假设/数据/方法)、站位(调研深度)、避坑(不重复造轮子);10–20 条为常见区间
2. 检索三策略:核心概念+方法词组检索式、滚雪球法、高被引+近 5 年双筛选
3. 五个必引时机:数据来源、假设依据、方法出处、方法对比、结论印证
4. GB/T 7714 四种格式:期刊[J]、专著[M]、会议[C]、网络[EB/OL];全表统一是规范第一要义
5. BibTeX/biblatex 自动编号,编译流水线 XeLaTeX → Biber → XeLaTeX → XeLaTeX;百科与博客不进文献表
