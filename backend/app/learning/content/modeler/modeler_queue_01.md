# 排队论建模

> **难度**:进阶 · **预计学习时长**:45 分钟 · **主讲智能体**:🧩 建模手 · **方法类别**:排队论/随机服务

## 🎯 学习目标

学完本单元,你应该能够:

- 用 Little 公式在 $L$、$\lambda$、$W$ 之间自由换算,并分清 $L$ 与 $L_q$、$W$ 与 $W_q$
- 会用 Erlang C 公式计算 M/M/c 系统的等待概率,做服务台数量的成本优化

## 📖 核心概念

### 1. 排队系统的六大要素

| 要素 | 要回答的问题 | 常见选项 |
|------|------------|---------|
| **输入过程** | 顾客怎么来? | 泊松到达(间隔指数分布)、定长、一般分布 |
| **服务时间** | 服务多快? | 指数分布、定长、Erlang 分布 |
| **服务台数** | 几个窗口? | 单台、多台 |
| **系统容量** | 能排多长? | 无限、有限($K$) |
| **排队规则** | 谁先服务? | FCFS、优先级、随机 |
| **顾客源** | 顾客有多少? | 无限、有限($m$) |

### 2. Kendall 记号与泊松到达

记号 **A/B/c/K/m/Z**(前两项为到达间隔分布 / 服务时间分布,$M$ 表示指数分布即「马尔可夫无记忆」,$D$ 表示定长,$G$ 表示一般;后四项缺省依次表示无限)。最常见的模型:

- **M/M/1**:泊松到达、指数服务、单服务台——排队论的「入门款」
- **M/M/c**:泊松到达、指数服务、$c$ 个并行服务台——窗口设计的标准模型
- **M/G/1**:一般服务时间,需 Pollaczek-Khinchin 公式,此处不展开

为什么「泊松到达」如此普遍?因为大量独立个体的随机到达叠加,到达间隔自然逼近指数分布;而指数分布的**无记忆性** $P(X > s+t \mid X > s) = P(X > t)$ 使系统状态构成马尔可夫链,解析公式才推得出来。

### 3. 生灭过程:排队论的「发动机」

设 $N(t)$ 为系统中顾客数(排队中的 + 正在服务的)。对 M/M/1,状态转移图是:

$$0 \underset{\mu}{\overset{\lambda}{\rightleftarrows}} 1 \underset{\mu}{\overset{\lambda}{\rightleftarrows}} 2 \underset{\mu}{\overset{\lambda}{\rightleftarrows}} 3 \underset{\mu}{\overset{\lambda}{\rightleftarrows}} \cdots$$

含义:状态 $n$ 以速率 $\lambda$ 生到 $n+1$(来一个顾客),以速率 $\mu$ 灭到 $n-1$(服务完一个)。稳态时,对每个「切割面」,流入等于流出——这就是**局部平衡方程**。

### 4. 性能指标:论文里必须算齐的四个数

- $L$:系统中平均人数(排队 + 服务);$L_q$:队列中平均等待人数(不含正在服务的)
- $W$:顾客平均逗留时间(等待 + 服务);$W_q$:平均排队等待时间
- $p_0$:系统空闲概率;$P(N \ge k)$:系统中至少 $k$ 人的概率(容量设计的依据)

> 💡 **建模心法**:排队题的最终落点永远是「**服务台数 / 容量该设多少**」。指标算完只是第一步,把等待成本与增设窗口成本放进同一个目标函数做优化,才是完整答案。

## 🧮 公式与结论

### M/M/1 稳态分布的完整推导

由状态转移图写局部平衡方程:

$$\lambda p_0 = \mu p_1,\qquad \lambda p_{n-1} = \mu p_n \ (n \ge 1)$$

记 $\rho = \lambda/\mu$(服务强度),递推得:

$$p_n = \rho^n p_0$$

归一化 $\sum_{n=0}^{\infty} p_n = p_0 \sum_{n=0}^{\infty} \rho^n = \dfrac{p_0}{1-\rho} = 1$(要求 $\rho < 1$),故:

$$p_0 = 1 - \rho,\qquad p_n = (1-\rho)\rho^n \quad (\rho < 1)$$

系统人数服从**几何分布**。据此可算出全部指标:

| 指标 | 公式 | 本例($\lambda=20,\mu=25$) |
|------|------|--------------------------|
| 服务强度 | $\rho = \lambda/\mu$ | $0.8$ |
| 空闲概率 | $p_0 = 1 - \rho$ | $0.2$ |
| 平均人数 | $L = \dfrac{\rho}{1-\rho}$ | $4$ 人 |
| 平均队长 | $L_q = \dfrac{\rho^2}{1-\rho}$ | $3.2$ 人 |
| 平均逗留 | $W = \dfrac{1}{\mu-\lambda}$ | $0.2$ h = 12 min |
| 平均等待 | $W_q = \dfrac{\rho}{\mu-\lambda}$ | $0.16$ h = 9.6 min |
| 至少 $k$ 人 | $P(N \ge k) = \rho^k$ | $P(N\ge5) = 0.3277$ |

($L$ 的求法:$\sum_{n} n(1-\rho)\rho^n = \rho/(1-\rho)$;$W$ 直接由 Little 公式得:$W = L/\lambda = 1/(\mu-\lambda)$,与直观分解「逗留时间 = 等待时间 + 服务时间」即 $W = W_q + 1/\mu$ 一致,可互相验证。)

### Little 公式:排队论第一定理

$$L = \lambda W,\qquad L_q = \lambda W_q$$

含义:系统中平均人数 = 到达率 × 平均逗留时间。它不依赖服务规则与到达分布,**只要系统稳态、顾客守恒**,对 G/G/c 都成立。验证:$W = L/\lambda = \dfrac{\rho}{\lambda(1-\rho)} = \dfrac{1}{\mu - \lambda}$ ✓。

### M/M/c 与 Erlang C 公式

$c$ 个服务台,每个速率 $\mu$,记 $a = \lambda/\mu$,$\rho = a/c$(每个台的服务强度):

$$p_0 = \left[\sum_{n=0}^{c-1}\frac{a^n}{n!} + \frac{a^c}{c!(1-\rho)}\right]^{-1}$$

**Erlang C 公式**(顾客到达时所有台都忙,必须等待的概率):

$$P(\text{等待}) = \frac{a^c}{c!}\,p_0\,\frac{1}{1-\rho}$$

进而 $L_q = P(\text{等待})\cdot\dfrac{\rho}{1-\rho}$,$L = L_q + a$,$W = L/\lambda$,$W_q = L_q/\lambda$。

### 服务台数优化:排队论题目的标准收尾

$$\min_{c} \ C(c) = c_s\cdot c + c_w\cdot L(c)$$

其中 $c_s$ 是每个服务台单位时间成本,$c_w$ 是每个顾客等待单位时间的机会成本,$L(c)$ 随 $c$ 增大而减小——总成本是「设施成本 + 等待成本」的折中,通常有唯一最优 $c$。

## 💡 经典例题

### 例题 1:M/M/1 全指标计算(从状态图到答案)

> 某银行自助服务区(单机):顾客到达服从泊松过程,平均 20 人/小时;服务时间服从指数分布,平均服务率 25 人/小时。求所有性能指标。

**第一步:写状态转移图与稳态方程**。$\lambda = 20$/h,$\mu = 25$/h,图见核心概念节,局部平衡方程 $\lambda p_{n-1} = \mu p_n$。

**第二步:求稳态分布**。$\rho = 20/25 = 0.8 < 1$,系统稳定:

$$p_0 = 1 - 0.8 = 0.2,\qquad p_n = 0.2 \times 0.8^n$$

即系统 20% 的时间空闲;$p_1 = 0.16$,$p_2 = 0.128$,$p_3 = 0.1024$,……

**第三步:算指标**:

$$L = \frac{0.8}{0.2} = 4\ \text{人},\quad L_q = \frac{0.64}{0.2} = 3.2\ \text{人}$$
$$W = \frac{1}{25 - 20} = 0.2\ \text{h} = 12\ \text{min},\quad W_q = \frac{0.8}{25-20} = 0.16\ \text{h} = 9.6\ \text{min}$$

**第四步:容量设计**。若候车区只能容纳 5 人,溢出概率为:

$$P(N \ge 5) = 0.8^5 = 0.3277$$

**解析**:注意几个要点——①先检查 $\rho < 1$,否则一切公式失效;②$L$ 与 $L_q$ 差 0.8 人,正好是「正在服务」的平均人数 $\rho$,即 $L = L_q + \rho$;③$W$ 与 $W_q$ 差 2.4 分钟,正是平均服务时间 $1/\mu$;④溢出概率用 $P(N \ge k) = \rho^k$(几何分布的尾概率),这是容量设计的标准依据。

### 例题 2:M/M/c 服务台数设计(Erlang C)

> 某医院挂号大厅:到达率 $\lambda = 60$ 人/小时,每个窗口服务率 $\mu = 25$ 人/小时。至少需要几个窗口?开 3 个窗口时的等待概率和平均等待时间是多少?

**第一步:可行性**。$a = \lambda/\mu = 2.4$。窗口数必须满足 $c > a = 2.4$,故至少 $c = 3$(此时 $\rho = 0.8 < 1$)。

**第二步:算 $p_0$**:

$$p_0 = \left[1 + 2.4 + \frac{2.4^2}{2} + \frac{2.4^3}{3!(1-0.8)}\right]^{-1} = \left[1 + 2.4 + 2.88 + \frac{13.824}{6\times 0.2}\right]^{-1}$$

括号内 $= 6.28 + 11.52 = 17.8$,故 $p_0 = 0.0562$。

**第三步:Erlang C 等待概率**:

$$P(\text{等待}) = \frac{2.4^3}{3!}\times 0.0562 \times \frac{1}{1 - 0.8} = 2.304 \times 0.0562 \times 5 = 0.647$$

即约 65% 的顾客到达时需要排队——三个窗口相当拥挤。

**第四步:等待指标**:

$$L_q = 0.647\times\frac{0.8}{0.2} = 2.59\ \text{人},\qquad L = 2.59 + 2.4 = 4.99\ \text{人}$$
$$W = \frac{4.99}{60} = 0.0832\ \text{h} \approx 5.0\ \text{min},\qquad W_q = \frac{2.59}{60} = 0.0432\ \text{h} \approx 2.6\ \text{min}$$

**解析**:对照例题 1 的 M/M/1:同样是每个台 $\rho = 0.8$,多台并联后平均等待从 9.6 分钟降到 2.6 分钟——**同样的服务强度,多台并联远比单台高效**(这就是「取号排队」优于「各排各队」的数学原因)。注意 $W_q = W - 1/\mu = 5.0 - 2.4 = 2.6$ 分钟,交叉验证一致。

### 例题 3:窗口数成本优化

> 接例题 2。每个窗口运营成本 $c_s = 5$ 元/小时,每个顾客等待的机会成本 $c_w = 10$ 元/小时。求最优窗口数。

**计算**:$C(c) = 5c + 10\,L(c)$,依次算 $c = 3, 4, 5$(用例题 2 的步骤,结果如下):

| 窗口数 $c$ | $\rho$ | $p_0$ | $P(\text{等待})$ | $L$ | 总成本 $C(c)$ |
|-----------|--------|-------|-----------------|-----|--------------|
| 3 | 0.800 | 0.0562 | 0.647 | 4.99 | 15 + 49.9 = **64.9** |
| 4 | 0.600 | 0.0831 | 0.287 | 2.83 | 20 + 28.3 = **48.3** |
| 5 | 0.480 | 0.0889 | 0.113 | 2.50 | 25 + 25.0 = **50.0** |

**结论**:最优窗口数 $c^* = 4$。从 3 到 4,多开一个窗口花 5 元,省下等待成本 21.6 元,划算;从 4 到 5,多花 5 元只省 3.3 元,不划算——**边际成本与边际等待成本相等处即最优**,这是排队优化题的万能话术。

**解析**:本题是排队论的完整答题结构:建模(选 M/M/c)→ 求指标(Erlang C)→ 优化(边际分析)→ 结论(开 4 个窗口)。实际竞赛中 $c_s$、$c_w$ 往往需要从题目数据中估计,还要对这两个参数做**灵敏度分析**,说明结论的稳健性。

## ⚠️ 常见易错点

1. **$\rho \ge 1$ 时照套公式**。$\lambda \ge \mu$ 时队列无限增长,不存在稳态,所有公式失效——第一步必须检查稳定性,不稳定就加服务台或减到达率
2. **单位不统一**。$\lambda$ 用「人/小时」,$\mu$ 用「人/分钟」,$\rho$ 错 60 倍。全部统一到小时(或分钟)再动笔
3. **$L$ 与 $L_q$、$W$ 与 $W_q$ 混用**。$L_q$ 不含正在服务的顾客,$L = L_q + \rho$;$W = W_q + 1/\mu$。论文里用错下标,指标全错
4. **把平均等待当上限**。$W_q = 2.6$ 分钟不代表「最多等 2.6 分钟」;等待时间服从指数分布,约 37% 的顾客会超过平均等待。容量设计要用 $P(N \ge k)$ 或分位数,不能用均值
5. **不检验指数假设就套 M/M/c**。实际数据先看服务时间/到达间隔的直方图、算变异系数;若服务时间接近定长(变异系数小),M/M/c 会高估等待,应用 M/D/c 或仿真
6. **忘记 Little 公式的稳态前提**。非稳态(开业初期、突发高峰)时 $L = \lambda W$ 不成立;排队系统还要区分有效到达率(容量有限时部分顾客流失,$\lambda_{\text{eff}} = \lambda(1-p_K)$)

## ✏️ 自测练习

**第 1 题(判断)**:某 M/M/1 系统 $\lambda = 12$/h,$\mu = 10$/h。能否用公式 $L = \rho/(1-\rho)$ 计算平均队长?

<details><summary>查看答案</summary>

**不能**。$\rho = 12/10 = 1.2 > 1$,系统不稳定,队列长度随时间线性增长,不存在稳态分布,公式无意义。正确做法:增加服务台(如 M/M/2)或提高 $\mu$,使服务强度降到 1 以下再计算。

</details>

**第 2 题(计算)**:M/M/1 系统,$\lambda = 30$/h,$\mu = 40$/h。求 $\rho$、$p_0$、$L$、$W$。

<details><summary>查看答案</summary>

$\rho = 30/40 = 0.75$,$p_0 = 0.25$。

$L = \dfrac{0.75}{0.25} = 3$ 人;$W = \dfrac{1}{\mu-\lambda} = \dfrac{1}{10}$ h = 6 分钟(用 Little 公式验证:$L/\lambda = 3/30 = 0.1$ h ✓)。

$L_q = L - \rho = 2.25$ 人,$W_q = 4.5$ 分钟。

</details>

**第 3 题(计算)**:M/M/1 系统中,「没有人在排队」的概率是多少?即 $P(\text{队列为空})$。

<details><summary>查看答案</summary>

队列为空 = 系统中人数为 0 或 1(0 人:系统空;1 人:正在服务、无人排队):

$$P(N \le 1) = p_0 + p_1 = (1-\rho) + (1-\rho)\rho = 1 - \rho^2$$

以 $\rho = 0.75$ 为例:$1 - 0.5625 = 0.4375$。注意本题若答成 $p_0 = 1 - \rho$ 就错了——那是「系统空闲」概率,不是「无人排队」概率。

</details>

**第 4 题(概念)**:Little 公式 $L = \lambda W$ 为什么对任意排队规则都成立?给出直观解释。

<details><summary>查看答案</summary>

考虑一段时间 $[0, T]$ 内的「人·时」总量:它一方面等于系统人数曲线下的面积,除以 $T$ 即时间平均人数 $L$;另一方面等于每个顾客的逗留时间之和,除以 $T$ 即 $\dfrac{N(T)}{T}\cdot W = \lambda W$($N(T)/T$ 为平均到达率)。只要系统稳态、进出守恒,两种算法相等。排队规则只改变「谁等多久」的分配,不改变总量守恒,所以公式与规则无关。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:2009 国赛 B「眼科病床安排」是排队论的经典真题——到达、服务时间都需从数据估计分布,再设计病床分配规则;2019 国赛 C「机场出租车」把排队论与司机决策(排队 vs 空返)结合,是排队 + 博弈/优化的组合题
- **论文加分点**:①从**真实数据估计 $\lambda$、$\mu$**,并用卡方或 Q-Q 图检验指数假设;②解析公式算一遍 + **蒙特卡洛仿真验证一遍**,两套结果对照(参见《蒙特卡洛模拟》单元);③服务台数优化给出边际分析表(如例题 3);④对到达率做灵敏度分析,给出「高峰期」与「平峰期」两套方案
- **工具**:解析计算用 `numpy`;离散事件仿真可用 `simpy` 或手写事件循环(本单元代码实现即为一例)

## 💻 代码实现

```python
import numpy as np
from math import factorial

# ---- M/M/1 解析公式 ----
lam, mu = 20.0, 25.0
rho = lam / mu
assert rho < 1, "系统不稳定!"
p0 = 1 - rho
L = rho / (1 - rho); Lq = rho**2 / (1 - rho)
W, Wq = 1 / (mu - lam), rho / (mu - lam)
print(f"rho={rho:.2f} p0={p0:.2f} L={L:.2f} Lq={Lq:.2f} "
      f"W={W*60:.1f}min Wq={Wq*60:.1f}min P(N>=5)={rho**5:.4f}")

# ---- M/M/c: Erlang C ----
def mmc(lam, mu, c):
    a = lam / mu
    rho = a / c
    assert rho < 1, "请增加服务台数"
    p0 = 1 / (sum(a**n / factorial(n) for n in range(c))
              + a**c / (factorial(c) * (1 - rho)))
    Pwait = a**c / factorial(c) * p0 / (1 - rho)
    Lq = Pwait * rho / (1 - rho)
    L = Lq + a
    return p0, Pwait, L, L / lam, Lq / lam

for c in [3, 4, 5]:
    p0, Pw, L, W, Wq = mmc(60, 25, c)
    print(f"c={c}: p0={p0:.4f} P(等待)={Pw:.3f} L={L:.2f} "
          f"W={W*60:.1f}min 总成本={5*c + 10*L:.1f}元/h")

# ---- 事件仿真验证 Little 公式: L = λW ----
rng = np.random.default_rng(42)
n = 20000
arr = np.cumsum(rng.exponential(1/lam, n))
svc = rng.exponential(1/mu, n)
dep, free = np.empty(n), 0.0
for i in range(n):
    free = max(arr[i], free) + svc[i]
    dep[i] = free
W_sim = np.mean(dep - arr)
L_sim = np.sum(dep - arr) / dep[-1]
print(f"仿真: W={W_sim*60:.2f}min, L={L_sim:.3f}; "
      f"公式: W={W*60:.1f}min, L={L:.2f}")
print("Little 验证 |λW - L| =", abs(lam * W_sim - L_sim))
```

## 🧠 小结

1. 排队系统六要素 → Kendall 记号 → 选标准模型(M/M/1、M/M/c),先查 $\rho < 1$ 再动笔
2. 生灭过程的局部平衡方程 $\lambda p_{n-1} = \mu p_n$ 是 M/M/1 一切结论的源头:$p_n = (1-\rho)\rho^n$,几何分布
