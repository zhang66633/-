# 博弈论基础

> **难度**:进阶 · **预计学习时长**:50 分钟 · **主讲智能体**:🧩 建模手 · **方法类别**:博弈论

## 🎯 学习目标

学完本单元,你应该能够:

- 写出一个静态完全信息博弈的三要素(参与人、策略、收益),并用收益矩阵表示
- 用划线法求纯策略 Nash 均衡,解释「均衡」与「最优」的区别(囚徒困境)
- 用「让对方无差异」的等期望收益法求混合策略 Nash 均衡
- 推导古诺双寡头的反应函数与均衡产量,并与垄断、完全竞争对比
- 写出复制者动态方程,求演化博弈的内部均衡与 ESS,并解释其稳定性

## 📖 核心概念

### 1. 博弈的三要素与收益矩阵

| 要素 | 要回答的问题 | 例子(定价博弈) |
|------|------------|---------------|
| **参与人** | 谁在决策? | 两家竞争企业 |
| **策略** | 每人能选什么? | 高价 / 低价 |
| **收益** | 每种策略组合下各得多少? | 利润,依赖双方选择 |

两人有限策略博弈用**收益矩阵**表示:行是参与人 1 的策略,列是参与人 2 的策略,格子内写 $(u_1, u_2)$——先写清「行玩家、列玩家」再动笔,这是新手最容易弄反的地方。

### 2. 占优策略与劣策略消去

- **严格占优策略**:无论对手怎么选,该策略都严格更好。若存在,理性参与人必选之
- **严格劣策略**:无论对手怎么选都严格更差,理性参与人必不选,可以**迭代消去**

### 3. Nash 均衡(NE):博弈论的灵魂

> **定义**:在策略组合中,给定其他参与人的选择,**没有任何参与人能通过单方面改变策略而获得更高收益**。

求纯策略 NE 的**划线法**:对参与人 1,在每列中圈出他的最优行;对参与人 2,在每行中圈出他的最优列;**双圈**的格子就是 NE。

两个关键理解:

- NE 描述的是「稳定的策略组合」,**不是**「对大家最好的结果」——囚徒困境中唯一的 NE 恰恰是集体最差的结果
- 有限博弈**纯策略 NE 可能不存在**(如猜硬币),但混合策略(随机化)NE 一定存在(Nash 定理)

### 4. 混合策略:用随机化让对方无差异

混合策略 = 按概率随机选择纯策略。其精妙之处在于:**我随机化的目的,是让你的每一种纯策略期望收益相等,使你「无所谓」选哪个**——因为只要你有严格更优的策略,你就一定会选它,而我的选择必须建立在对「你会选什么」的预判上。

### 5. 连续策略博弈:古诺双寡头

两家企业同时选择产量 $q_1, q_2$,市场价格由总产量决定:$P = a - b(q_1 + q_2)$。企业 $i$ 的利润:

$$\pi_i(q_1, q_2) = \big(a - b(q_1 + q_2) - c\big)q_i$$

每家对对方的产量做**最优反应**,得到反应函数;两个反应函数的交点就是古诺均衡。

### 6. 演化博弈:当参与人不会「算计」时

演化博弈不假设参与人完全理性,而是假设**策略的复制率与收益成正比**(更成功的策略被更多人采用)——这就是复制者动态:

$$\frac{dx}{dt} = x\left(f_A - \bar{f}\right)$$

其中 $x$ 是采用策略 A 的群体比例,$f_A$ 是 A 的适应度(收益),$\bar{f} = xf_A + (1-x)f_B$ 是群体平均适应度。收益高于平均则比例上升,低于平均则下降——**达尔文式的自然选择**。稳定下来的策略称为**演化稳定策略(ESS)**。

## 🧮 公式与结论

### 划线法与 2×2 纯策略 NE

对收益矩阵逐列(行玩家)、逐行(列玩家)找最优反应,双最优格即 NE。判断格 $(i,j)$ 是否 NE 的等价条件:

$$u_1(i,j) \ge u_1(k,j)\ \forall k,\qquad u_2(i,j) \ge u_2(i,l)\ \forall l$$

### 混合策略 NE:等期望收益法

行玩家以概率 $p$ 选行 1,列玩家以概率 $q$ 选列 1。行玩家的两个纯策略期望相等 → 解出 $q$;列玩家同理 → 解出 $p$:

$$\underbrace{q\,u_1(1,1) + (1-q)\,u_1(1,2)}_{\text{行1的期望}} = \underbrace{q\,u_1(2,1) + (1-q)\,u_1(2,2)}_{\text{行2的期望}}$$

### 古诺双寡头均衡

由一阶条件 $\dfrac{\partial \pi_i}{\partial q_i} = 0$ 得反应函数 $q_i = \dfrac{a - c - bq_j}{2b}$,对称解得:

$$q_1^* = q_2^* = \frac{a-c}{3b},\qquad P^* = \frac{a+2c}{3},\qquad \pi_i^* = \frac{(a-c)^2}{9b}$$

三个参照系对比(线性需求):

| 市场结构 | 总产量 | 价格 | 总利润 |
|---------|--------|------|--------|
| 完全竞争($P = c$) | $\dfrac{a-c}{b}$ | $c$ | 0 |
| **古诺双寡头** | $\dfrac{2(a-c)}{3b}$ | $\dfrac{a+2c}{3}$ | $\dfrac{2(a-c)^2}{9b}$ |
| 垄断 | $\dfrac{a-c}{2b}$ | $\dfrac{a+c}{2}$ | $\dfrac{(a-c)^2}{4b}$ |

产量:竞争 > 寡头 > 垄断;价格与利润反之——「竞争降低价格、造福消费者,但侵蚀利润」。

### 复制者动态与 ESS 判据

- 内部均衡:解 $f_A(x^*) = f_B(x^*)$;稳定性看 $f_A'(x^*) < 0$
- **Hawk-Dove 博弈**(鹰派:争夺到底;鸽派:谦让)。资源价值 $V$,争斗成本 $C$:

$$f_H = x\frac{V-C}{2} + (1-x)V,\qquad f_D = (1-x)\frac{V}{2}$$

内部均衡 $x^* = V/C$(推导见例题 3),此时群体中鹰派占 $V/C$、鸽派占 $1 - V/C$,均衡时两派收益相同。

- **ESS 与 NE 的关系**:ESS 一定是 NE,但 NE 不一定是 ESS——演化稳定比 Nash 均衡更严格(还需抵御小规模变异入侵)

## 💡 经典例题

### 例题 1:囚徒困境——划线法与「个体理性 vs 集体理性」

> 两名同案犯分别审讯,都可选择「坦白」或「沉默」,收益矩阵如下(负数表示刑期,行:甲,列:乙):

| 甲 \ 乙 | 坦白 | 沉默 |
|---------|------|------|
| **坦白** | $(-5, -5)$ | $(0, -10)$ |
| **沉默** | $(-10, 0)$ | $(-1, -1)$ |

**划线法求 NE**:对甲:乙选坦白时,甲坦白得 $-5$、沉默得 $-10$,圈坦白;乙选沉默时,甲坦白得 $0$、沉默得 $-1$,圈坦白。对乙(按行看):甲选坦白时,乙坦白得 $-5$、沉默得 $-10$,圈坦白;甲选沉默时,乙坦白得 $0$、沉默得 $-1$,圈坦白。

**结论**:唯一的 NE 是(坦白,坦白),各判 5 年——尽管(沉默,沉默)对两人都更好(各 1 年)。

**解析**:这个例子浓缩了博弈论最重要的教训:**NE 是稳定性的概念,不是福利最优的概念**。两人都沉默时,任何一方单方面坦白都能从 $-1$ 改善到 $0$,所以「都不坦白」不是稳定状态——正是这种单方面背叛的诱惑,让双方滑向双输。破解之道:重复博弈(未来合作的长期收益惩罚背叛)、外部制度(黑手党的报复)、或合同约束。竞赛中用囚徒困境框架分析「价格战」「军备竞赛」「减排搭便车」都是这个套路。

### 例题 2:混合策略 Nash 均衡(手算全程)

> 甲、乙约定一起行动,两人都更看重「在一起」:甲偏爱活动 A,乙偏爱活动 B。收益矩阵:

| 甲 \ 乙 | 选 A | 选 B |
|---------|------|------|
| **选 A** | $(3, 2)$ | $(0, 0)$ |
| **选 B** | $(0, 0)$ | $(2, 3)$ |

**第一步:纯策略 NE**。划线法:(A, A) 与 (B, B) 都是 NE——但谁去迁就谁?这就是「性别战」博弈的纠结:均衡存在却不唯一,且双方偏好不同。

**第二步:求混合策略 NE**。设甲选 A 的概率为 $p$,乙选 A 的概率为 $q$。

甲无差异:选 A 的期望 $= 3q + 0\cdot(1-q) = 3q$;选 B 的期望 $= 0\cdot q + 2(1-q) = 2 - 2q$。令相等:

$$3q = 2 - 2q \ \Rightarrow\ 5q = 2 \ \Rightarrow\ q = 0.4$$

乙无差异:选 A 的期望 $= 2p$;选 B 的期望 $= 3(1-p) = 3 - 3p$。令相等:

$$2p = 3 - 3p \ \Rightarrow\ 5p = 3 \ \Rightarrow\ p = 0.6$$

**第三步:验证期望收益**。甲的期望 $= 3 \times 0.4 = 1.2$;乙的期望 $= 2 \times 0.6 = 1.2$——都比纯策略 NE 中的「迁就者」(得 2)差,这正说明混合均衡的收益通常低于纯均衡。

**解析**:注意两个易错点——①解 $p$ 用的是**乙**的收益矩阵(乙无差异决定甲的随机化概率),解 $q$ 用**甲**的收益矩阵,千万别对调;②混合策略的意义不是「我随机选着玩」,而是「我按这个概率随机,让你的选择无利可图,从而稳定住你的行为」。

### 例题 3:古诺双寡头(数值计算)

> 市场需求 $P = 100 - Q$,两家企业边际成本均为 $c = 10$,同时定产量。求古诺均衡,并与垄断、完全竞争对比。

**第一步:利润函数**。$\pi_1 = (100 - q_1 - q_2 - 10)q_1 = (90 - q_1 - q_2)q_1$。

**第二步:反应函数**。$\dfrac{\partial \pi_1}{\partial q_1} = 90 - 2q_1 - q_2 = 0 \Rightarrow q_1 = \dfrac{90 - q_2}{2}$;对称地 $q_2 = \dfrac{90 - q_1}{2}$。

**第三步:解方程组**。$q_1 = \dfrac{90 - (90-q_1)/2}{2} \Rightarrow 4q_1 = 90 + q_1 \Rightarrow q_1 = 30$,故 $q_1^* = q_2^* = 30$。

**第四步:均衡价格与利润**。$Q = 60$,$P = 100 - 60 = 40$,每家 $\pi = (40 - 10)\times 30 = 900$。

**对比**:垄断时 $Q = 45$,$P = 55$,$\pi = 2025$(两家合谋各分约 1012);完全竞争时 $P = 10$,$Q = 90$,$\pi = 0$。古诺均衡恰在两者之间:总产量 60、价格 40、总利润 1800。

**解析**:本题的完整链条是「利润 → 反应函数 → 均衡 → 与参照系对比」。竞赛中的延展方向:①把单期博弈改成重复博弈,讨论**合谋的稳定性**(背叛一次多赚,但招致价格战);②引入差异化产品(需求函数各不相同);③用反应函数画图,展示均衡是两条曲线的交点——图表清晰是这类题论文的加分项。

**例题 3 拓展:鹰鸽博弈的演化稳定策略**

> 资源价值 $V = 2$,争斗成本 $C = 4$。求鹰派比例 $x$ 的复制者动态、内部均衡及其稳定性。

**第一步:写适应度**。鹰派遇到鹰派(概率 $x$):打架,期望 $(V-C)/2 = -1$;遇到鸽派:拿走全部,$V = 2$。故 $f_H = x(-1) + (1-x)\times 2 = 2 - 3x$。

鸽派遇到鹰派:让出资源得 $0$;遇到鸽派:平分得 $V/2 = 1$。故 $f_D = x\times 0 + (1-x)\times 1 = 1 - x$。

**第二步:复制者动态**。$\bar{f} = xf_H + (1-x)f_D$:

$$\frac{dx}{dt} = x(f_H - \bar{f}) = x(1-x)(f_H - f_D) = x(1-x)\big((2-3x) - (1-x)\big) = x(1-x)(1 - 2x)$$

**第三步:均衡与稳定性**。均衡点 $x = 0, 1, 0.5$。对 $x = 0.5$:其右侧 $(1-2x) < 0$ 使 $x$ 下降,左侧 $(1-2x) > 0$ 使 $x$ 上升,故 $x = 0.5$ **稳定**;$x = 0$、$x = 1$ 均不稳定。

**结论**:ESS 是 $x^* = V/C = 2/4 = 0.5$——一半鹰派一半鸽派的混合群体。均衡时 $f_H = f_D = 0.5$:群体平均收益 0.5,比全是鸽派(收益 1)还低——争斗成本的「内耗」使所有人变穷,这就是 ESS 不等于效率最优的又一例证。

**解析**:演化博弈的答题套路:写适应度 → 写复制者方程 → 求均衡 → 判稳定性 → 解释生态/社会含义。注意内部均衡 $x^* = V/C$ 的一般性:资源越值钱($V$ 大)、争斗越廉价($C$ 小),鹰派比例越高——现实中「鸟为食亡」正是 $V/C$ 逼近 1 的情形。

## ⚠️ 常见易错点

1. **把 NE 当「最优解」**。囚徒困境中 NE 是集体最差的结局;论文里必须分清「均衡」(稳定)与「帕累托最优」(福利),并讨论如何通过机制设计让二者重合
2. **混合策略解错变量**。解甲的概率 $p$ 要用**乙**的无差异方程(乙的收益矩阵),反之亦然;对调了概率就是错的
3. **划线法只划一边**。某格只是行玩家的最优反应、列玩家却不满意,不是 NE;必须**双方同时最优**
4. **收益矩阵行列写反**。格子里 $(u_1, u_2)$ 的顺序、行玩家与列玩家的标注一定要在矩阵旁写清楚,否则整题全错
5. **忽略信息与顺序结构**。序贯博弈(一方先动)必须用**逆向归纳**求子博弈精炼均衡,直接套静态 NE 会得出不可信的威胁;不完全信息要用贝叶斯博弈(参见《贝叶斯推断》单元)
6. **ESS 与 NE 混淆**。ESS 一定是 NE,但 NE 不一定是 ESS(如混合均衡需额外验证演化稳定性);另注意复制者动态的稳定均衡可能是内部点(如 $x^* = V/C$),不要默认端点才是答案

$$\begin{bmatrix} (5, 1) & (4, 4) \\ (9, -1) & (0, 0) \end{bmatrix}$$

用划线法求纯策略 Nash 均衡:

A. (按, 等待),收益 $(4, 4)$:小猪「按」时大猪最优是等待,小猪「等待」时大猪最优是按;大猪「按」与「等待」时小猪最优都是等待——双圈在(按, 等待)
B. (等待, 按),收益 $(9, -1)$:大猪搭便车最优
C. (按, 按),收益 $(5, 1)$:双方都出力
D. (等待, 等待),收益 $(0, 0)$:双方都不动

**答案:A**。利润 $\pi_i = (40 - q_1 - q_2 - 10)q_i$,一阶条件 $\frac{\partial \pi_1}{\partial q_1} = 30 - 2q_1 - q_2 = 0$ 得反应函数 $q_i = \frac{30 - q_j}{2}$,对称解 $q_1^* = q_2^* = 10$;总产量 20,价格 $P^* = 40 - 20 = 20$,每家利润 $(20-10)\times10 = 100$。对照三个参照系(线性需求下):垄断 $Q = 15$、$P = 25$、总利润 225——选项 B 把**垄断**解当成了古诺解;合谋卡特尔每家产量 $\frac{a-c}{4b} = 7.5$、总利润 225——选项 C 把**卡特尔**解当成了古诺解;完全竞争 $P = c = 10$、$Q = 30$——选项 D 把每家产量取成总产量、价格为 0,走向了荒谬。古诺均衡恰在垄断与竞争之间:产量 20 介于 15 与 30 之间,这正是「寡头竞争降低价格、造福消费者」的量化体现。

## 💻 代码实现

```python
import numpy as np
from scipy.integrate import solve_ivp

# ---- 例2: 混合策略 NE(等期望收益法) ----
A = np.array([[3, 0], [0, 2]])  # 行玩家(甲)收益
B = np.array([[2, 0], [0, 3]])  # 列玩家(乙)收益

# 甲无差异: 3q = 2(1-q) → q; 乙无差异: 2p = 3(1-p) → p
q = 2 / (3 + 2)
p = 3 / (2 + 3)
print(f"混合NE: 甲以 {p:.2f} 选A, 乙以 {q:.2f} 选A")
print(f"期望收益: 甲 {3 * q:.2f}, 乙 {2 * p:.2f}")

# ---- 例3拓展: 鹰鸽博弈复制者动态 ----
V, C = 2.0, 4.0


def hawk_dove(t, x):
    fH = x * (V - C) / 2 + (1 - x) * V
    fD = (1 - x) * V / 2
    fbar = x * fH + (1 - x) * fD
    return [x * (fH - fbar)]


sol = solve_ivp(hawk_dove, [0, 40], [0.05], t_eval=np.linspace(0, 40, 200))
print("理论ESS x*=V/C =", V / C, "; 数值终值 =", sol.y[0, -1])
print("均衡时两派收益:", (V - C) / 2 * (V / C) + (1 - V / C) * V)
```

## 🧠 小结

1. 博弈三要素:参与人、策略、收益;收益矩阵先标清「行玩家、列玩家」,这是零失误的第一步
2. Nash 均衡 = 无人愿意单方面偏离;划线法(纯策略)与等期望收益法(混合策略)是两道基本功;均衡是稳定性概念,不等于最优——囚徒困境永不过时
3. 古诺双寡头:反应函数 + 对称解,$q^* = (a-c)/3b$,并养成与垄断、竞争对比的习惯
4. 演化博弈:适应度 → 复制者方程 → 均衡与稳定性;鹰鸽博弈的 ESS $x^* = V/C$ 揭示了「争斗成本内耗」的普遍规律
5. 论文升华点:从均衡出发讨论机制设计(如何让个体理性 = 集体理性),比单纯算一个均衡高一个层次
