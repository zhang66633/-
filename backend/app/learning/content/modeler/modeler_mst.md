## 📖 核心概念

### 1. 树与生成树

**树**是连通且无环的图,等价刻画:$n$ 个顶点的树恰有 $n-1$ 条边,且任意两点间路径唯一。

**生成树**是「覆盖所有顶点」的树;每条边有权时,**最小生成树(MST)**是总权和最小的生成树:

$$\text{MST} = \arg\min_{\text{生成树 } T} \sum_{e \in T} w(e)$$

直觉:用最少的「线材」把 $n$ 个点连成一个连通网。铺设光缆、灌溉管道、供电线路都是 MST 场景。

### 2. 割性质与环性质:贪心为什么正确

- **割性质**:把顶点任意分成 $A$ 与 $V \setminus A$ 两边,**横跨这个割的最小权边一定属于某棵 MST**
- **环性质**:任意环上的**最大权边一定不属于任何 MST**

两条性质分别支撑两类算法:Prim 不断用割性质把「最近的邻居」拉进来;Kruskal 按权从小到大加边,遇到成环就跳过(环性质保证最大权边可弃)。这就是「贪心 + 正确性证明」的经典样本。

### 3. Kruskal 算法与并查集

1. 所有边按权**从小到大排序**
2. 依次考察每条边:若它的两个端点**尚未连通**(不在同一集合),则加入 MST,并合并两端点所在集合;否则跳过(会成环)
3. 加入 $n-1$ 条边后停止

「是否连通 / 会否成环」由**并查集**维护,带路径压缩与按秩合并后,单次操作近似 $O(1)$。总复杂度 $O(E \log E)$(排序主导)。

### 4. Prim 算法

从任意顶点出发,维护「已入树」集合;每次从**跨越树与树外**的边中挑最小权者,把对端顶点拉入树。用二叉堆维护候选边,复杂度 $O(E \log V)$。稠密图常用 Prim($O(V^2)$ 朴素版),稀疏图常用 Kruskal。

### 5. TSP:旅行商问题

**TSP**:给定 $n$ 个城市与两两距离,找一条**访问每城恰好一次并回到起点**的最短回路。它是著名的 **NP 困难**问题——目前没有多项式时间的精确算法,城市数一多,精确求解就不可能。

- **精确**:Held-Karp 动态规划 $O(n^2 2^n)$($n \leq 25$ 左右可行);分支定界
- **近似**(度量 TSP,距离满足三角不等式):Christofides 算法有 $1.5$ 倍近似比;「先求 MST 再深搜短接」给 $2$ 倍近似比
- **启发式**:最近邻(NN)贪心、2-opt 局部搜索、模拟退火、遗传算法、蚁群算法(参见《启发式算法综合实战》单元)

**MST 与 TSP 的联系**:最优 TSP 回路去掉一条边就是一棵生成树,所以 **MST 权是 TSP 最优值的下界**——这是竞赛论文里评估启发式解质量的标准手段(你的解离下界还有多远)。

## 🧮 公式与结论

**树的基本等式**($n$ 个顶点):

$$\text{边数} = n - 1, \qquad \sum \text{度数} = 2(n-1)$$

**Cayley 公式**:$n$ 个完全图的生成树共有 $n^{n-2}$ 棵(如 $n=4$ 时有 16 棵)——枚举不可行,必须用贪心。

**复杂度速查**:

| 算法 | 问题 | 复杂度 |
|------|------|--------|
| Kruskal | MST | $O(E \log E)$ |
| Prim(堆) | MST | $O(E \log V)$ |
| Held-Karp | TSP 精确 | $O(n^2 2^n)$ |
| 最近邻 / 2-opt | TSP 启发式 | $O(n^2)$ 级 |

**Held-Karp 递推**:$C(S, i)$ = 从 0 出发、访问集合 $S$ 中城市后停在 $i$ 的最短长度:

$$C(S, i) = \min_{j \in S \setminus \{i\}} \left[ C(S \setminus \{i\},\, j) + d(j, i) \right], \qquad C(\{i\}, i) = d(0, i)$$

最终答案 $\min_i [C(\text{全集}, i) + d(i, 0)]$。

**TSP 的 MST 下界**(度量 TSP):

$$\text{MST 权} \leq \text{最优 TSP} \leq 2 \times \text{MST 权}$$

## 💡 经典例题

### 例题 1:Kruskal 手工执行(含并查集状态)

> 6 个村庄:$A\!-\!B=4$,$A\!-\!C=2$,$B\!-\!C=1$,$B\!-\!D=5$,$C\!-\!D=8$,$C\!-\!E=10$,$D\!-\!E=2$,$D\!-\!F=6$,$E\!-\!F=3$。求连通所有村庄的最短缆线总长。

**第一步:边按权排序**:

| 边 | $B\!-\!C$ | $A\!-\!C$ | $D\!-\!E$ | $E\!-\!F$ | $A\!-\!B$ | $B\!-\!D$ | $D\!-\!F$ | $C\!-\!D$ | $C\!-\!E$ |
|----|----|----|----|----|----|----|----|----|----|
| 权 | 1 | 2 | 2 | 3 | 4 | 5 | 6 | 8 | 10 |

**第二步:依次考察**:

| 步 | 边 | 权 | 端点状态 | 决策 | 累计权 |
|----|----|----|---------|------|-------|
| 1 | $B\!-\!C$ | 1 | 不连通 | ✅ 加入 | 1 |
| 2 | $A\!-\!C$ | 2 | $A$ 未连 | ✅ 加入 | 3 |
| 3 | $D\!-\!E$ | 2 | 不连通 | ✅ 加入 | 5 |
| 4 | $E\!-\!F$ | 3 | $F$ 未连 | ✅ 加入 | 8 |
| 5 | $A\!-\!B$ | 4 | **已在同一集合**(经 $C$ 连通) | ❌ 跳过(成环 $A\!-\!B\!-\!C$) | 8 |
| 6 | $B\!-\!D$ | 5 | 两棵树间 | ✅ 加入 | 13 |

已加入 $6-1 = 5$ 条边,停止。**MST 总权 $\boxed{13}$**,边集 $\{B\!-\!C,\ A\!-\!C,\ D\!-\!E,\ E\!-\!F,\ B\!-\!D\}$。

**解析**:第 5 步是关键——$A\!-\!B$ 权 4 虽小,但两端已通过 $C$ 连通,加入必成环,而环上最大权边正是它自己(环性质),故舍弃。用 Prim 从 $A$ 出发会按 $A\!-\!C$、$C\!-\!B$、$B\!-\!D$、$D\!-\!E$、$E\!-\!F$ 的顺序得到**同样一棵树**(本题 MST 唯一);若图中存在等权边,MST 可能不唯一,但**最小总权值是唯一的**。

### 例题 2:TSP 的最近邻与 2-opt

> 4 城距离矩阵(对称):$d(0,1)=10,\ d(0,2)=15,\ d(0,3)=20,\ d(1,2)=35,\ d(1,3)=25,\ d(2,3)=30$。求 TSP 最优回路。

**最近邻(NN)启发式**:从 0 出发,每次都去最近的未访问城市:

$$0 \xrightarrow{10} 1 \xrightarrow{25} 3 \xrightarrow{30} 2 \xrightarrow{15} 0$$

回路 $0\!-\!1\!-\!3\!-\!2\!-\!0$,总长 $10 + 25 + 30 + 15 = 80$。

**验证最优性**(4 城全枚举,共 $3! / 2 = 3$ 条本质回路):

| 回路 | 长度 |
|------|------|
| $0\!-\!1\!-\!2\!-\!3\!-\!0$ | $10+35+30+20 = 95$ |
| $0\!-\!1\!-\!3\!-\!2\!-\!0$ | $10+25+30+15 = 80$ |
| $0\!-\!2\!-\!1\!-\!3\!-\!0$ | $15+35+25+20 = 95$ |

最优值 $\boxed{80}$(本例 NN 恰好找到最优)。

**2-opt 演示**:若从坏回路 $0\!-\!1\!-\!2\!-\!3\!-\!0$(95)出发,2-opt 尝试「删两条边、翻转子段」:删 $(1,2)$ 与 $(3,0)$,加 $(1,3)$ 与 $(2,0)$,得到 $0\!-\!1\!-\!3\!-\!2\!-\!0$:新长 $10+25+30+15 = 80 < 95$,改进成功,再无可改进交换,输出 80。

**解析**:NN 是「目光短浅」的贪心——大图里常被「拖入死胡同」,且最坏情况无常数近似比;2-opt 是局部搜索,能修复交叉边(欧氏平面里最优 TSP 回路必不交叉,2-opt 的每一步都在「解交叉」)。竞赛实战套路:NN 或随机生成初解 → 2-opt 改进 → 多起点重复取最好,并用 MST 下界评估离最优还有多远。

### 例题 3:建模辨析——铺网用 MST,配送用 TSP

> 场景一:为 20 个基站铺光缆,要求任意两站之间可通信,求最短总缆长。
> 场景二:一辆巡检车从车库出发,访问 20 个基站后返回,求最短路线。

**场景一 = MST**:连通性要求 + 总成本最小,没有「回路」「顺序」概念。建图:顶点 = 基站,边 = 可铺设的直连线路,权 = 距离。注意:若只要求「车库到各站」距离最短(树形广播),那是最短路径树;若要整体总长最小,才是 MST。

**场景二 = TSP**:访问顺序产生回路。若多辆车 → 车辆路径问题(VRP);若带时间窗 → VRPTW,参见《启发式算法综合实战》单元。

**解析**:两个场景的图可以一模一样,但问题本质不同:铺网 20 站只要 19 条边(树),巡检必须 20 条边(回路)。MST 的解不能直接当 TSP 的解用;反过来,TSP 回路删掉最长的一条边,得到一个**可行生成树**,其权 ≥ MST 权——这就是「MST 是 TSP 下界」的直观证明。

## ⚠️ 常见易错点

1. **MST 与最短路径树混为一谈**。反例:三角形 $A\!-\!B=2$,$B\!-\!C=2$,$A\!-\!C=3$。MST 取 $\{A\!-\!B, B\!-\!C\}$ 总权 4;以 $A$ 为根的最短路径树取 $\{A\!-\!B, A\!-\!C\}$ 总权 5。二者目标函数不同,不要拿 Dijkstra 求 MST
2. **Kruskal 不加并查集就判环**。排序后「肉眼判环」在小图上可行,但代码必须用并查集;忘记路径压缩在大数据上会超时
3. **负权边对 MST 无害,却坑死 Dijkstra**。MST 只关心「连通的最小总成本」,负权边只会让树更便宜;最短路遇到负权则贪心失效。两个问题对边权的敏感性完全不同
4. **忽略图不连通**。不连通图没有生成树;Kruskal 结束时若边数不足 $n-1$,应报告「无法全连通」,或引入 Steiner 点 / 无线中继等新决策
5. **TSP 用贪心解还宣称最优**。NN、2-opt 都只是启发式,结果可能离最优很远;论文里必须用 MST 下界(或小规模精确解)给出**最优性间隙**,而不是「我找到了最短路径」
6. **MST 不唯一时误判算法错误**。存在等权边时,不同算法(甚至不同排序)可能输出不同的 MST,但总权相同——比较时只比总权,不比边集

<details><summary>查看答案</summary>

边按权排序:$(1,4)=1$、$(1,2)=2$、$(1,3)=3$、$(2,3)=4$、$(2,4)=5$、$(3,4)=6$。

依次加入 $(1,4)$、$(1,2)$、$(1,3)$(此时 $(1,3)$ 两端连通?顶点 1、2、4 已同树,顶点 3 未连,故加入)。到 $(2,3)$ 时两端已连通(经 1),跳过。共 $4-1=3$ 条边,MST = $\{1\!-\!4,\ 1\!-\!2,\ 1\!-\!3\}$,总权 $1+2+3=6$。这是一棵「星形树」(以 1 为中心),虽然边 $(1,3)$ 权 3 比 $(2,3)$ 的 4 小,但加入顺序由排序决定,结果仍是全局最优。

</details>

**第 2 题(概念)**:为什么负权边不影响 MST 的正确性,却会破坏 Dijkstra?本质区别是什么?

<details><summary>查看答案</summary>

MST 的贪心由**割性质**支撑:横跨任意割的最小权边必属某棵 MST,该性质与边权正负无关——负权边只会让「最小」更突出,不会破坏结构。

Dijkstra 的贪心依赖「已确定距离不再变小」,而负权边可以通过「绕路」把已确定的距离改小,破坏贪心前提。本质区别:MST 是「从全局边集中无环地挑选」,每条边至多被考察一次;最短路是「沿路径累加」,代价顺序敏感,负权会颠覆次序。顺带一提,Bellman-Ford 能处理负权正是因为它放弃了「一旦确定就封死」的假设,反复松弛 $n-1$ 轮。

</details>

**第 3 题(判断)**:若所有边权互不相同,则 MST 一定唯一。对吗?

<details><summary>查看答案</summary>

**对**。所有边权互不相同时,MST 唯一。证明思路:若存在两棵不同的 MST $T_1, T_2$,取只属于 $T_1$ 的最小权边 $e$ 加入 $T_2$,形成环;环上必有一条不属于 $T_1$ 的边 $f$。由环性质与边的「最小性」讨论可知 $w(e) \leq w(f)$ 且 $w(f) \leq w(e)$,推出 $w(e) = w(f)$,与「互不相同」矛盾。反过来,存在等权边时 MST 可能不唯一(如全等权三角形)。

</details>

**第 4 题(应用)**:为 30 个城市求 TSP 解,你打算怎么设计算法并论证解的质量?

<details><summary>查看答案</summary>

30 城用 Held-Karp($O(n^2 2^n)$)不现实($30^2 \times 2^{30}$ 量级),标准方案是「启发式 + 下界论证」:①最近邻或随机初解,②2-opt(可加 Or-opt、3-opt)局部搜索至局部最优,③多起点(如 50 个随机起点)取最好;④用 Held-Karp 求**部分城市的精确解**或直接用 MST 下界 + Christofides 上界夹逼,报告「解 ≤ 1.5 倍下界」之类的保证;⑤用蚁群算法 / 模拟退火 / 遗传算法进一步优化(参见《启发式算法综合实战》单元)。论文里写清「启发式解 87.3,下界 79.1,间隙 9.4%」,比空口说「最短」严谨得多。

</details>

## 💻 代码实现

```python
import heapq, itertools
import numpy as np

# 1. Kruskal + 并查集 (例题 1: 0=A ... 5=F)
def kruskal(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # 路径压缩
            x = parent[x]
        return x
    mst, total = [], 0
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            mst.append((u, v, w))
            total += w
    return total, mst

E = [(4,0,1),(2,0,2),(1,1,2),(5,1,3),(8,2,3),(10,2,4),(2,3,4),(6,3,5),(3,4,5)]
print("MST 总权:", kruskal(6, E)[0])        # 13
print("MST 边:", kruskal(6, E)[1])          # [(1,2,1),(0,2,2),(3,4,2),(4,5,3),(1,3,5)]

# 2. Held-Karp: TSP 精确解 (例题 2)
def held_karp(D):
    n = len(D)
    memo = {}
    def dp(S, i):                            # 访问集合 S (位掩码) 后停在 i
        if S == 0:
            return D[0][i]
        if (S, i) in memo:
            return memo[(S, i)]
        best = min(dp(S ^ (1 << (j-1)), j) + D[j][i]
                   for j in range(1, n) if S >> (j-1) & 1)
        memo[(S, i)] = best
        return best
    return dp((1 << (n-1)) - 1, 0)

D = [[0,10,15,20],[10,0,35,25],[15,35,0,30],[20,25,30,0]]
print("Held-Karp 最优:", held_karp(D))       # 80

# 3. 最近邻 + 2-opt
def nn_tsp(D, start=0):
    n, cur, unvis = len(D), start, set(range(n)) - {start}
    path, L = [start], 0
    while unvis:
        nxt = min(unvis, key=lambda j: D[cur][j])
        L += D[cur][nxt]; path.append(nxt); unvis.remove(nxt); cur = nxt
    return path + [start], L + D[cur][start]

def two_opt(path, D):
    n = len(path) - 1
    improved = True
    while improved:
        improved = False
        for i in range(1, n-1):
            for j in range(i+1, n):
                old = D[path[i-1]][path[i]] + D[path[j]][path[j+1]]
                new = D[path[i-1]][path[j]] + D[path[i]][path[j+1]]
                if new < old - 1e-9:         # 翻转子段更优
                    path[i:j+1] = reversed(path[i:j+1])
                    improved = True
    return path, sum(D[path[i]][path[i+1]] for i in range(n))

print("最近邻:", nn_tsp(D))                  # ([0,1,3,2,0], 80)
print("2-opt 改进 0-1-2-3-0:", two_opt([0,1,2,3,0], D))   # ([0,1,3,2,0], 80)
```

> 输出与例题一致:MST 总权 13;Held-Karp、最近邻、2-opt 均得 80。Held-Karp 的 `memo` 用字典显式记忆化,把状态数从 $O(2^n)$ 的重复计算压到 $O(n2^n)$。

- **进阶关联**:学完本单元 → 接着学《最短路径与Dijkstra》(另一类图论优化,注意区分)→ 《蚁群算法(ACO)》(TSP 的元启发式求解)→ 《整数规划与分支定界》(TSP 的割平面 / 分支定界精确框架)

## 🧠 小结

1. MST 用 $n-1$ 条边连通全网、总权最小;Kruskal 排序加边 + 并查集判环,Prim 从点出发逐步扩张
2. 贪心正确性来自割性质(必选)与环性质(必弃)——这是「算法 + 证明」的标准范式
3. 三大易混:最小生成树(总成本)、最短路径树(单源距离)、Steiner 树(可加新点)
4. TSP 是 NP 困难:Held-Karp 精确解 $O(n^2 2^n)$;实战用 NN 初解 + 2-opt 改进 + 多起点,并用 MST 下界评估间隙
5. 建模第一步永远是归类:铺网是 MST,巡检回路是 TSP,多车是 VRP
