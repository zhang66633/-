## 📖 核心概念

### 1. 多目标问题的困境:没有「唯一最优」

$$\min\ \left(f_1(x), f_2(x), \dots, f_m(x)\right) \quad \text{s.t.} \quad x \in \mathcal{X}$$

当目标互相冲突(成本低 vs 质量高;收益大 vs 风险小)时,通常不存在一个解让所有目标同时最优。我们能给决策者的,是一族「各有取舍」的解——**Pareto 前沿**。

### 2. 支配、Pareto 最优与前沿

- **支配**:解 $A$ 支配解 $B$,若 $A$ 在所有目标上都不差于 $B$,且至少一个目标严格更好(最小化问题:$\forall k,\ f_k(A) \leq f_k(B)$ 且 $\exists k,\ f_k(A) < f_k(B)$)
- **Pareto 最优解**:不被任何其他可行解支配的解(也叫非支配解、有效解)
- **Pareto 前沿**:全部 Pareto 最优解在目标空间的像——竞赛论文里那张「前沿曲线图」画的就是它

辅助概念:**理想点** $z^*$(各目标单独最优组成的点,通常不可达)与 **nadir 点**(前沿上各目标的最差值),用于前沿图的坐标参考。

### 3. 标量化方法:把多目标变回单目标

- **加权和法**:$\min \sum_k \lambda_k f_k(x)$($\lambda_k \geq 0$, $\sum \lambda_k = 1$)。每取一组权重得前沿上**一个**点;**致命缺陷**:目标空间非凸时,前沿的凹陷部分永远取不到(见例题 2)
- **ε-约束法**:只保留一个目标,其余目标转成约束 $\min f_1(x)$ s.t. $f_k(x) \leq \varepsilon_k$。逐档调整 $\varepsilon_k$ 可覆盖**全部**前沿(包括凹陷),但每档都要解一次优化问题
- **分层序列法**:按目标重要度排序,先优化第一目标,在最优集合内优化第二目标,依次类推——体育比赛的「并列名次再比小分」逻辑

### 4. 多目标进化算法:一次运行给出一整片前沿

进化算法天然适合多目标:种群 = 一组解,只要给「支配」定义好排序规则,种群就会**整体向 Pareto 前沿移动并铺展开**。NSGA-II(Deb et al., 2002)是应用最广的代表。

## 🧮 公式与结论

### 拥挤度距离(Crowding Distance)

对同一前沿层的解按每个目标排序,第 $i$ 个解的拥挤度:

$$d_i = \sum_{k=1}^{m} \frac{f_k^{(i+1)} - f_k^{(i-1)}}{f_k^{\max} - f_k^{\min}}$$

两个端点解(排序后第 1 与最后 1 个)的拥挤度记作 $\infty$(永远优先保留)。拥挤度衡量「这个解周围有多挤」——同层之内,**拥挤度大的先选**,保证前沿分布均匀。

### NSGA-II 的四个组件

1. **快速非支配排序**:$O(mN^2)$ 给全体解分层(第 1 层 = 非支配解,去掉后第 2 层,依此类推)
2. **拥挤度距离**:同层内保多样性
3. **锦标赛选择**:先比层号(小者胜),同层比拥挤度(大者胜)——多目标版的「适应度」
4. **精英保留**:父代子代合并成 $2N$ 个解,统一排序后截取前 $N$——历史最优层**永不丢失**

### 前沿质量指标(论文必备)

- **IGD(反向世代距离)**:从真实前沿均匀采样参考点,求每个参考点到**所得前沿**的最近距离并平均。值越小越好,同时反映**收敛性**(靠得近)与**多样性**(覆盖全)——本文实验即用 IGD
- **HV(超体积)**:所得前沿与参考点围成的体积,越大越好;无需真实前沿,但随目标数增加计算量激增
- **Spacing**:只衡量解的分布均匀性,不衡量收敛——单报 Spacing 的论文是「选择性报告」

## 💡 经典例题

### 例题 1:非支配排序 + 拥挤度手算

> 4 个解在目标空间的坐标(最小化):$P_1(1,5)$、$P_2(2,3)$、$P_3(3,2)$、$P_4(4,4)$。分层并计算第 1 层的拥挤度。

**支配判断**(逐一比较):

- $P_1$ vs 其余:$1 < 2,3,4$ 但 $5 > 3,2,4$ → 互不支配
- $P_2(2,3)$ vs $P_3(3,2)$:互不支配;vs $P_4(4,4)$:$2<4$ 且 $3<4$ → **$P_2$ 支配 $P_4$**
- $P_3(3,2)$ vs $P_4(4,4)$:$3<4$ 且 $2<4$ → **$P_3$ 支配 $P_4$**

**分层**:第 1 层 $= \{P_1, P_2, P_3\}$(两两互不支配);第 2 层 $= \{P_4\}$。

**拥挤度**:按 $f_1$ 排序:$(1,5), (2,3), (3,2)$。端点 $P_1, P_3$ 的拥挤度记 $\infty$;中间点 $P_2$:

$$d(P_2) = \frac{3-1}{3-1} + \frac{5-2}{5-2} = 1 + 1 = 2$$

**解析**:注意支配与拥挤度作用于不同层面:支配决定「层」(谁更优),拥挤度只在**同一层内**比(谁更「疏」)。若从第 1 层 3 个解中只留 2 个,淘汰的是拥挤度最小的 $P_2$——虽然 $P_2$ 在三个解中间,但两端点永远优先保留,这正是前沿「展得开」的机制。

### 例题 2:加权和法的盲区(线性双目标)

> $\max\ f_1 = x_1,\ f_2 = x_2$,s.t. $x_1 + 2x_2 \leq 6,\ 2x_1 + x_2 \leq 6,\ x_1, x_2 \geq 0$。求 Pareto 前沿,并用加权和法检验。

**前沿求解**:可行域顶点 (3,0)、(0,3)、(2,2)。「一个目标不恶化,另一个目标就无法改善」的解集由两段组成:

$$\text{前沿} = \{(x_1, x_2):\ 2x_1 + x_2 = 6,\ 2 \leq x_1 \leq 3\} \cup \{(x_1, x_2):\ x_1 + 2x_2 = 6,\ 0 \leq x_1 \leq 2\}$$

即从 (3,0) 到 (2,2) 再到 (0,3) 的折线。检验 (1.5, 2.25):$1.5+4.5 = 6$ ✓,在前沿上。

**加权和检验**:$\max\ \lambda x_1 + (1-\lambda)x_2$:

- $\lambda = 0.75$:目标 $0.75x_1+0.25x_2$ → 最优 (3,0)(值 2.25 最大)
- $\lambda = 0.5$:目标 $0.5(x_1+x_2)$ → 最优 (2,2)(值 2 最大)
- $\lambda = 0.25$:→ 最优 (0,3)

**解析**:前沿上整整**两段连续的解**((3,0)-(2,2) 段与 (2,2)-(0,3) 段上的每一点)加权和法都取不到——线性目标的最优解总在可行域顶点,而折线内部不是顶点。结论:**加权和法只能覆盖凸前沿的支撑点**;要完整刻画前沿,用 ε-约束法(例题 3)或 NSGA-II 这类进化多目标方法。

### 例题 3:ε-约束法补全前沿

> 同一问题。决策者说「$f_1$ 至少要有 1.5,再尽量提高 $f_2$」,求该前沿点。

**建模**:保留 $f_2$ 为目标,把 $f_1$ 转成约束:

$$\max\ x_2 \quad \text{s.t.} \quad x_1 + 2x_2 \leq 6,\ 2x_1 + x_2 \leq 6,\ x_1 \geq 1.5,\ x_1, x_2 \geq 0$$

**求解**:$x_1 = 1.5$ 代入:$2x_2 \leq 4.5 \Rightarrow x_2 \leq 2.25$;$1.5 + x_2 \leq 6$ 不紧。得 $x_2^* = 2.25$,即前沿点 **(1.5, 2.25)**——与例题 2 的前沿表达式完全吻合 ✓。

**解析**:把 $\varepsilon = 1.5$ 换成 $[0, 3]$ 内的任意档,就能扫出整条前沿(包括加权和取不到的折线中段)。ε-约束法在竞赛中还有一个妙用:直接回答「给定期望水平下另一目标的最优值」这类**政策导向**问题,比给一片前沿更贴合题目要求。

### 例题 4:NSGA-II 求解 ZDT1(实验数据)

> ZDT1 标准测试问题(30 维变量、2 目标,真实前沿已知)。NSGA-II:种群 100、SBX 交叉 $\eta_c=20$、多项式变异 $\eta_m=20$、250 代。

**结果**:最终前沿的 **IGD = 0.0048**,前沿在 $f_1$ 轴覆盖 [0.000, 1.000]——与真实前沿 $f_2 = 1 - \sqrt{f_1}$ 几乎重合,且两端铺满。

**解析**:IGD 一个指标同时说明了两件事:值小 = 整条近似前沿贴着真实前沿(收敛),参考点全被覆盖 = 没有漏段(多样)。竞赛中若真实前沿未知,可报告 HV 或画前沿图做目视判断;若问题规模小,还可与 ε-约束法求出的参考前沿对比。

## ⚠️ 常见易错点

1. **支配方向搞反**。最小化问题中「更好」是**更小**;把 max/min 混用,非支配排序会整个颠倒。排序前先统一所有目标的方向(取负或倒数)
2. **加权和当「多目标求解器」用**。一组权重只给一个点,且非凸前沿有盲区(例题 2);只报告加权和解,等于把多目标问题偷偷退化成了单目标
3. **权重不归一化目标尺度**。$f_1$ 量级 1000、$f_2$ 量级 0.1 时,加权和完全被 $f_1$ 主导;加权前先归一化(除以各自极差),并在论文中说明
4. **拥挤度只在层内比**。跨层时层号优先(第 1 层哪怕最挤也优于第 2 层);实现时把排序键写成 `(层号, -拥挤度)` 就不会错
5. **前沿指标选择性报告**。只报 Spacing(分布)不报收敛,或只画图不报数值;规范做法是 IGD(有真实前沿)/HV(无真实前沿)+ 前沿图
6. **把「求前沿」当终点**。多目标优化的交付物是**方案集**,竞赛通常还差一步「从前沿选一个最终方案」(拐点法、TOPSIS 等)——参见《TOPSIS理想解逼近法》与《层次分析法(AHP)》单元,两段拼起来才是完整的多准则决策方法论

## ✏️ 自测练习

**第 1 题(计算)**:4 个解(最小化):A(2,3)、B(3,2)、C(2,4)、D(1,5)。谁支配谁?第 1 层是谁?

<details><summary>查看答案</summary>

A(2,3) 支配 C(2,4):$2 \leq 2$ 且 $3 < 4$ ✓。其余两两互不支配:A vs B(2<3 但 3>2)、A vs D(2>1 但 3<5)、B vs D、B vs C(3>2 但 2<4)、C vs D(2>1 但 4<5)。

第 1 层 = {A, B, D};第 2 层 = {C}(被 A 支配)。注意 A 与 C 的第一个目标相等、第二个更好,仍构成支配——「全部不差 + 一个严格好」是支配的完整定义。

</details>

**第 2 题(计算)**:同一前沿层 4 个解(最小化):(0,10)、(1,4)、(2,1)、(3,0)。求 (1,4) 的拥挤度。

<details><summary>查看答案</summary>

$d = \dfrac{2-0}{3-0} + \dfrac{10-1}{10-0} = \dfrac{2}{3} + \dfrac{9}{10} \approx 1.567$。

计算要点:①分子是**相邻两解**的目标差,分母是该目标在全层的极差;②两个端点 (0,10) 与 (3,0) 的拥挤度为 $\infty$;③每个目标归一化后相加——目标单位不同不影响结果,这正是拥挤度公式的分母设计。

</details>

**第 3 题(概念)**:加权和法在什么条件下能覆盖完整 Pareto 前沿?

<details><summary>查看答案</summary>

要求目标空间里的可行目标集是**凸集**(凸多目标问题):此时前沿上任一点都是某个加权和问题的解。反例即例题 2:线性约束下的线性双目标,前沿是折线(非凸),加权和只能取到折点。此外,离散问题(整数解)的前沿天然非凸,加权和必有漏点。

实践建议:线性多目标 → 用 ε-约束法或直接列前沿表达式;非线性/大尺度 → NSGA-II;加权和只适合「快速预览个别点」或作为论文的标量化辅助。

</details>

**第 4 题(概念)**:NSGA-II 的精英保留具体怎么实现?和 GA 的精英策略有何不同?

<details><summary>查看答案</summary>

NSGA-II 把第 $t$ 代父代 $P_t$(N 个)与子代 $Q_t$(N 个)**合并**成 $R_t = P_t \cup Q_t$(2N 个),对 $R_t$ 做非支配排序,按 (层号, -拥挤度) 依次选取 N 个进入下一代——上一代的好解不会因交叉变异而丢失,且选择压力来自「合并池」而非「父代内部」。

与 GA 精英策略的区别:GA 是「把历史最优 1–2 个原样塞回下一代」,NSGA-II 是「父代全体参与竞争、按 Pareto 层级整体截断」。前者保的是**单点**,后者保的是**整个最优层**(一整片前沿)。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:多目标优化在国赛/美赛题目中几乎无处不在——成本 vs 覆盖、收益 vs 风险、效率 vs 公平。凡出现「既要…又要…」的题面,就该警惕「单目标加权硬凑」的写法
- **论文加分点**:①明确写出支配定义与分层结果;②前沿图 + IGD/HV 数值;③ε-约束法逐档扫描与 NSGA-II 结果的**交叉验证**;④最终方案的选取方法(拐点/TOPSIS/AHP,参见《TOPSIS理想解逼近法》《层次分析法(AHP)》单元)
- **工程提醒**:NSGA-II 一次运行只有近似前沿;**竞赛中「近似前沿 + 决策选优」两段式结构**比只贴一张前沿图得分高得多

## 💻 代码实现

```python
import numpy as np

rng = np.random.default_rng(2026)

def zdt1(x):
    n = x.shape[1]
    f1 = x[:, 0]
    g = 1 + 9 * np.sum(x[:, 1:], axis=1) / (n - 1)
    f2 = g * (1 - np.sqrt(f1 / g))
    return np.stack([f1, f2], axis=1)

def nsga2(f, dim=10, pop=100, gens=250, pc=0.9, eta_c=20.0, eta_m=20.0):
    N = pop
    P = rng.random((N, dim))

    def dominates(a, b):
        return np.all(a <= b) and np.any(a < b)

    for _ in range(gens):
        # ---- SBX 交叉 + 多项式变异 ----
        Q = np.empty_like(P)
        for i in range(0, N, 2):
            p1, p2 = P[i], P[i + 1]
            u = rng.random(dim)
            beta = np.where(u <= 0.5, (2 * u) ** (1 / (eta_c + 1)),
                            (2 * (1 - u)) ** (-1 / (eta_c + 1)))
            if rng.random() < pc:
                c1 = 0.5 * ((1 + beta) * p1 + (1 - beta) * p2)
                c2 = 0.5 * ((1 - beta) * p1 + (1 + beta) * p2)
            else:
                c1, c2 = p1.copy(), p2.copy()
            mu, r = rng.random(dim), rng.random(dim)
            delta = np.where(mu < 0.5, (2 * mu) ** (1 / (eta_m + 1)) - 1,
                             1 - (2 * (1 - mu)) ** (1 / (eta_m + 1)))
            c1 = np.clip(c1 + (r < 1.0 / dim) * delta, 0, 1)
            c2 = np.clip(c2 + (r < 1.0 / dim) * delta, 0, 1)
            Q[i], Q[i + 1] = c1, c2
        # ---- 合并 + 非支配排序 + 拥挤度截断(精英保留) ----
        R = np.vstack([P, Q]); F = f(R)
        S = [[] for _ in range(2 * N)]; nn = [0] * (2 * N)
        fronts = []; f1_ = []
        for i in range(2 * N):
            for j in range(2 * N):
                if i == j: continue
                if dominates(F[i], F[j]): S[i].append(j)
                elif dominates(F[j], F[i]): nn[i] += 1
            if nn[i] == 0: f1_.append(i)
        fronts.append(f1_); k = 0
        while fronts[k]:
            nxt = []
            for i in fronts[k]:
                for j in S[i]:
                    nn[j] -= 1
                    if nn[j] == 0: nxt.append(j)
            k += 1; fronts.append(nxt)
        fronts.pop()
        sel = []
        for fr in fronts:
            if len(sel) + len(fr) <= N:
                sel += fr
            else:
                fr = np.array(fr)
                cds = np.zeros(len(fr))
                for m in range(F.shape[1]):
                    o = np.argsort(F[fr, m])
                    cds[o[0]] = cds[o[-1]] = np.inf
                    rng_ = F[fr[o[-1]], m] - F[fr[o[0]], m]
                    if rng_ > 0:
                        cds[o[1:-1]] += (F[fr[o[2:]], m] - F[fr[o[:-2]], m]) / rng_
                take = np.argsort(-cds)[:N - len(sel)]
                sel += [fr[t] for t in take]
                break
        P = R[sel]
    return f(P)

F = nsga2(zdt1)
ref = np.linspace(0, 1, 1000)
refF = np.stack([ref, 1 - np.sqrt(ref)], axis=1)     # ZDT1 真实前沿
igd = np.min(np.sqrt(((F[:, None] - refF[None]) ** 2).sum(-1)), axis=0).mean()
print("IGD = %.5f" % igd)          # ≈ 0.0048
print("前沿 f1 覆盖: [%.3f, %.3f]" % (F[:, 0].min(), F[:, 0].max()))
```

> 把 `zdt1` 换成你的目标函数即可复用;双目标以上建议换装 DEAP/pymoo 库,并改用超体积指标。

## 🧠 小结

1. 多目标问题没有唯一最优,交付物是 Pareto 前沿:支配关系定义「更优」,前沿上的解两两互不支配
2. 标量化三法:加权和(快但有非凸盲区)、ε-约束(完整但要逐档求解)、分层序列(有优先级时)
3. NSGA-II = 快速非支配排序(分层)+ 拥挤度(层内保多样)+ 锦标赛(层号→拥挤度)+ 精英保留(合并 2N 截 N)
4. 评估前沿:IGD(需真实前沿)、HV(无需)、Spacing(只看分布);单指标报告 = 选择性报告
5. 完整方法论 = 多目标优化得前沿 + 决策方法选最终方案(TOPSIS/AHP/拐点),两段都要在论文里出现
