## 📖 核心概念

### 1. ODE 建模的思维起点:把「变化率」翻译成方程

微分方程建模的全部奥秘在于一句话:**先写变化率的平衡式,再给初值**。

| 建模步骤 | 要问的问题 | 例子(人口) |
|---------|-----------|-----------|
| ① 选状态变量 | 什么量在变? | $N(t)$:时刻 $t$ 的人口数 |
| ② 写变化率 | 变化的来源与去向? | 出生 $-$ 死亡 |
| ③ 给规律 | 来源/去向依赖什么? | 出生率正比于 $N$,死亡受环境容量限制 |
| ④ 定初值 | 初始时刻的状态? | $N(0) = N_0$ |
| ⑤ 求解与检验 | 解析/数值?与数据吻合? | 见例题 2 |

> 💡 **建模心法**:凡题目中出现「增长速率」「冷却速率」「扩散速度」这类词,大概率是 ODE 题。把「速率」写在 $\dfrac{d}{dt}$ 的左边,把「与什么成正比」写在右边,方程就出来了。更一般的写法是:**变化率 = 流入 − 流出**(质量守恒在导数上的体现)。

### 2. 四个一阶经典模型(背下来,竞赛直接套)

- **马尔萨斯人口模型**:$\dfrac{dN}{dt} = rN$,解 $N(t) = N_0 e^{rt}$。适合短期、资源充足的情形;长期必然高估,是「为什么需要 Logistic」的引子
- **Logistic 模型**:$\dfrac{dN}{dt} = rN\left(1 - \dfrac{N}{K}\right)$,$K$ 为环境容量。S 形曲线,拐点在 $N = K/2$,增长先加速后减速
- **牛顿冷却定律**:$\dfrac{dT}{dt} = -k(T - T_a)$。温度变化率与「物体温度 $-$ 环境温度」成正比;$T - T_a$ 可正可负,负号自动把物体拉回环境温度
- **污染箱模型**:体积 $V$ 的湖泊,流入流量 $Q$、流入浓度 $c_{in}$,流出同流量:

$$\frac{dM}{dt} = Qc_{in} - \frac{Q}{V}M,\qquad M(0) = M_0$$

其中 $M = Vc$ 是污染物总质量。右边第一项是输入源,第二项是随流出带走的量(假设箱内充分混合,流出浓度等于箱内浓度 $M/V$)。时间常数 $V/Q$ 是「水体更新一遍」所需时间,是水质建模的核心参数。

### 3. 二阶方程:振动与机械系统

阻尼振动方程 $mx'' + cx' + kx = 0$,按判别式 $\Delta = c^2 - 4mk$ 分类:

- $\Delta > 0$:过阻尼,不振荡,缓慢回到平衡
- $\Delta = 0$:临界阻尼,最快回到平衡且不振荡
- $\Delta < 0$:欠阻尼,衰减振荡,角频率 $\omega = \dfrac{\sqrt{4mk - c^2}}{2m}$

若外加周期性驱动力,当驱动频率接近固有频率 $\omega_0 = \sqrt{k/m}$ 时发生**共振**,振幅剧增——桥梁振动、旋转机械、系泊系统建模的必考点。

### 4. 方程组:传染病与捕食者-猎物

- **SIR 模型**($S$ 易感、$I$ 感染、$R$ 移出):

$$\dot{S} = -\beta SI,\qquad \dot{I} = \beta SI - \gamma I,\qquad \dot{R} = \gamma I$$

双线性项 $\beta SI$ 的含义:单位时间新感染数正比于「易感者与感染者相遇的机会数」。$S + I + R = N$ 守恒,是检验数值解正确性的第一手段。

- **Lotka-Volterra 模型**:$\dot{x} = ax - bxy,\ \dot{y} = cxy - dy$。猎物 $x$ 自然增长、被捕食抑制;捕食者 $y$ 靠吃猎物增长、自然死亡。两物种做无阻尼周期振荡,详见公式节。

### 5. 平衡点、稳定性与相图

- **平衡点**:满足 $f(x^*) = 0$ 的点,状态不随时间变化,是「长期行为」的候选答案
- **线性化判据(一维)**:对 $\dot{x} = f(x)$,若 $f'(x^*) < 0$ 则 $x^*$ 渐进稳定;若 $f'(x^*) > 0$ 则不稳定;若 $f'(x^*) = 0$ 需要看高阶项
- **二维判据**:对平衡点处的雅可比矩阵 $J$,特征值实部全负 → 稳定结点/焦点;有正实部 → 不稳定;异号 → 鞍点;纯虚根 → 线性化失效,需用守恒量或李雅普诺夫函数判断
- **相图**:以状态变量为坐标轴的轨迹图,平衡点、周期轨道、鞍点分界线一目了然——论文里一张漂亮的相图顶得上半页文字

## 🧮 公式与结论

### Logistic 方程的解析解

分离变量 $\dfrac{dN}{N(1 - N/K)} = r\,dt$,部分分式后积分:

$$N(t) = \frac{K}{1 + \left(\frac{K}{N_0} - 1\right)e^{-rt}}$$

推论:$t \to \infty$ 时 $N \to K$;拐点(增长最快处)在 $N = K/2$,对应时刻 $t = \dfrac{1}{r}\ln\left(\dfrac{K}{N_0} - 1\right)$。

### 一维自治系统的稳定性判据

$$\dot{x} = f(x),\quad f(x^*)=0 \ \Rightarrow\ \begin{cases} f'(x^*)<0 & \text{渐进稳定}\\ f'(x^*)>0 & \text{不稳定}\\ f'(x^*)=0 & \text{需高阶判定} \end{cases}$$

例:$\dot{x} = rx(1 - x/K)$:$f'(0) = r > 0$(不稳定),$f'(K) = -r < 0$(稳定)。

### 二维系统的雅可比判据

$$\dot{\mathbf{x}} = \mathbf{F}(\mathbf{x}),\qquad J = \left.\frac{\partial \mathbf{F}}{\partial \mathbf{x}}\right|_{\mathbf{x}^*}$$

特征值 $\lambda_{1,2} = \dfrac{\mathrm{tr}J \pm \sqrt{(\mathrm{tr}J)^2 - 4\det J}}{2}$:实部均负 → 稳定;至少一个为正 → 不稳定;异号实根 → 鞍点。

Lotka-Volterra 的守恒量:取 $H = cx - d\ln x + by - a\ln y$,直接求导可验证 $\dfrac{dH}{dt} \equiv 0$,故相轨道是围绕内部平衡点 $(d/c,\ a/b)$ 的闭曲线族——种群做无阻尼周期振荡,内部平衡点是**中心**而非渐进稳定点。

### SIR 模型的关键结论

- **基本再生数**:$R_0 = \dfrac{\beta S_0}{\gamma}$($1/\gamma$ 是平均感染期)
- **阈值现象**:$R_0 > 1$ 疫情爆发,$R_0 \le 1$ 疫情自行消亡——隔离压低 $\beta$、治疗增大 $\gamma$,都能把 $R_0$ 压到 1 以下
- **终态规模**:由轨道方程 $\dfrac{dI}{dS} = -1 + \dfrac{\gamma}{\beta S}$ 积分,令 $I_\infty = 0$:

$$\ln\frac{S_\infty}{S_0} = \frac{\beta}{\gamma}\left(S_\infty - S_0 - I_0\right) \approx R_0\left(\frac{S_\infty}{N} - 1\right)$$

这是一元超越方程,迭代或二分法即可求解,直接给出疫情结束时的总感染比例 $1 - S_\infty/N$,是论文里最有分量的定量结论。

### 数值求解提示

- `solve_ivp` 默认使用 4/5 阶自适应 Runge-Kutta(RK45),对非刚性问题又快又准
- 若系统含快慢相差悬殊的时间尺度(刚性,如化学反应动力学),需 `method="BDF"` 或 `"Radau"`,否则步长被压到极小、算不动

## 💡 经典例题

### 例题 1:牛顿冷却定律——咖啡降温

> 一杯 90℃ 的咖啡放在 20℃ 的房间里,10 分钟后降到 55℃。问:咖啡降到 40℃ 需要多久?再过多久接近室温?

**建模**:设 $T(t)$ 为咖啡温度,牛顿冷却定律:

$$\frac{dT}{dt} = -k(T - 20),\qquad T(0) = 90$$

**求解**:令 $u = T - 20$,则 $\dfrac{du}{dt} = -ku$,$u(t) = 70 e^{-kt}$,即 $T(t) = 20 + 70 e^{-kt}$。

**定参数**:由 $T(10) = 55$:$70 e^{-10k} = 35 \Rightarrow e^{-10k} = 0.5 \Rightarrow k = \dfrac{\ln 2}{10} \approx 0.0693\ \text{min}^{-1}$。

**回答问题**:降到 40℃ 时 $70 e^{-kt} = 20 \Rightarrow e^{-kt} = \dfrac{2}{7} \Rightarrow t = \dfrac{\ln(7/2)}{k} = \dfrac{1.2528}{0.0693} \approx 18.1$ 分钟。

**解析**:注意三个细节——①环境温度 $T_a$ 是模型参数不是初值,先「平移」成温差 $u = T - T_a$ 再分离变量;②冷却系数 $k$ 由数据反推,这叫**参数辨识**,竞赛中「先建模、再用数据定参」是标准动作;③$t \to \infty$ 时 $T \to 20℃$,指数衰减「理论上永远差一点」,实际工程上温差小于 1℃ 即可认为到位,可算出「接近室温」的时间界限。

### 例题 2:Logistic 人口增长

> 某地区人口上限 $K = 1000$ 万,2010 年人口 $N_0 = 100$ 万,固有增长率 $r = 0.5$/年。问:人口何时达到 800 万?增长速度何时最快?

**求解**:代入 Logistic 解析解:

$$N(t) = \frac{1000}{1 + 9e^{-0.5t}}$$

达到 800 万:$800 = \dfrac{1000}{1 + 9e^{-0.5t}} \Rightarrow 1 + 9e^{-0.5t} = 1.25 \Rightarrow e^{-0.5t} = \dfrac{1}{36} \Rightarrow t = 2\ln 36 \approx 7.17$ 年。

增长速度最快:$N = K/2 = 500$ 万,$1 + 9e^{-0.5t} = 2 \Rightarrow t = 2\ln 9 \approx 4.39$ 年,对应 2014 年中期。

**解析**:本题展示了 Logistic 的两段节奏:人口从 100 万到 500 万用了 4.39 年,从 500 万到 800 万只用了 2.78 年,越接近 $K$ 增长越慢。判断增长极值不要对 $N(t)$ 求二阶导硬算,直接用「拐点在 $K/2$」这一结论。论文里可以用真实人口数据拟合 $r$ 与 $K$(最小二乘,参见《极大似然估计(MLE)》单元的同类思想),再预测拐点年份,「拐点已过/未过」是很有政策含义的结论。

### 例题 3:SIR 模型的终态规模

> 某传染病参数:$\beta = 4\times 10^{-4}$ 人$^{-1}$天$^{-1}$,$\gamma = 0.1$ 天$^{-1}$(平均感染期 10 天)。总人口 $N = 1000$,$S_0 = 999$,$I_0 = 1$。判断疫情是否爆发,并估算最终感染规模。

**第一步:算基本再生数**:

$$R_0 = \frac{\beta S_0}{\gamma} = \frac{4\times 10^{-4} \times 999}{0.1} = 3.996 \approx 4 > 1 \Rightarrow \text{疫情爆发}$$

**第二步:终态规模方程**。由轨道积分(见公式节),令 $I_\infty = 0$:

$$S_\infty = S_0 \exp\left[\frac{\beta}{\gamma}(S_\infty - S_0 - I_0)\right] = 999\, e^{0.004\,(S_\infty - 1000)}$$

**第三步:迭代求解**。取初值 $S_\infty^{(0)} = 100$,迭代 $S_\infty^{(n+1)} = 999 e^{0.004(S_\infty^{(n)} - 1000)}$:

- $n=1$:$999 e^{-3.6} = 999 \times 0.02732 = 27.3$
- $n=2$:$999 e^{0.004(27.3 - 1000)} = 999 e^{-3.8908} = 999 \times 0.02044 = 20.4$
- $n=3$:$999 e^{-3.9184} = 19.9$,收敛到 $S_\infty \approx 20$

**结论**:最终约 979 人感染(约 98%),仅约 20 人幸免。$R_0 = 4$ 对应的终态规模确实接近 98%,与公式节中 $\ln(S_\infty/N) \approx R_0(S_\infty/N - 1)$ 的解一致。

**解析**:本题展示了 SIR 的两大用法——阈值判定(算 $R_0$)与规模预估(终态方程)。竞赛中还可进一步:把 $R_0$ 写成控制变量的函数,讨论「戴口罩使 $\beta$ 降 50%」「隔离使 $\gamma$ 提高 2 倍」对终态规模的影响,就是一篇完整的政策分析。

## ⚠️ 常见易错点

1. **量纲不统一**。$r$ 用「年$^{-1}$」数据却用「天」求解,结果差 365 倍。建模第一步:统一时间单位,并把每个参数的物理单位写在论文里
2. **平衡点稳定性判据用错**。$f(x^*) = 0$ 只说明是平衡点,不代表稳定;还要看 $f'(x^*)$ 的符号。二维时 $f'(x^*) = 0$(特征值纯虚)更不能下结论,线性化失效,必须找守恒量或李雅普诺夫函数
3. **把离散数据直接当导数拟合**。$\dfrac{\Delta N}{\Delta t}$ 的差分噪声很大,直接拟合 $\Delta N/\Delta t$ 与 $N$ 的关系会非常难看;应拟合 $N(t)$ 的解析解或数值解(像例题 1、2 那样「用数据定参数」)
4. **SIR 双线性假设的适用性**。$\beta SI$ 要求群体充分混合、规模大,对封闭小群体或存在空间结构、超级传播者时不适用,需要网络或元胞自动机模型(参见《元胞自动机建模》单元)
5. **数值求解不设验证**。solve_ivp 解完就画图,不检查守恒量($S+I+R$ 是否为常数)、不对比解析解、不换步长做收敛性测试,数值爆掉了也发现不了
6. **混沌与长期预测**。某些非线性系统(如 Lorenz 方程)对初值极端敏感,长期预测无意义;论文中要明确给出「可预测时间范围」,而不是把 30 天后的曲线当精确值

## ✏️ 自测练习

**第 1 题(判断)**:一维自治系统 $\dot{x} = f(x)$ 的平衡点 $x^*$ 满足 $f(x^*) = 0$ 且 $f'(x^*) = 0$,能否断定 $x^*$ 稳定?

<details><summary>查看答案</summary>

**不能**。一阶导数信息不足,需看高阶项。反例:$\dot{x} = x^3$,平衡点 $x = 0$ 满足 $f'(0) = 0$,但 $x > 0$ 时解单调增大、$x < 0$ 时解单调减小(半稳定,不稳定);$\dot{x} = -x^3$ 则 $x = 0$ 渐进稳定。二者一阶导判据完全相同,结论相反。

</details>

**第 2 题(计算)**:判断 $\dot{x} = x(2 - x)$ 的所有平衡点及其稳定性。

<details><summary>查看答案</summary>

平衡点:$x(2-x) = 0 \Rightarrow x^* = 0$ 与 $x^* = 2$。$f'(x) = 2 - 2x$:

- $f'(0) = 2 > 0 \Rightarrow x = 0$ 不稳定(灭绝状态,微扰即增长)
- $f'(2) = -2 < 0 \Rightarrow x = 2$ 渐进稳定

这与 Logistic 方程 $r=2$、$K=2$ 的结论一致:任何正初值都收敛到环境容量 2。

</details>

**第 3 题(建模)**:某湖体积 $V = 10^6$ m³,入流与出流均为 $Q = 10^5$ m³/天,入流污染物浓度 $c_{in} = 0.05$ mg/L,湖内初始清洁。求:①污染物总质量满足的 ODE;②稳态浓度;③达到稳态浓度 95% 所需时间。

<details><summary>查看答案</summary>

① 设 $M(t)$ 为污染物总质量,$\dfrac{dM}{dt} = Qc_{in} - \dfrac{Q}{V}M$,初值 $M(0) = 0$。

② 稳态:$\dfrac{dM}{dt} = 0 \Rightarrow M^* = V c_{in} = 10^6 \times 0.05 = 5\times 10^4$ mg,稳态浓度 $c^* = M^*/V = 0.05$ mg/L(与入流浓度相同——箱模型充分混合的必然结果)。

③ 解为 $M(t) = M^*(1 - e^{-(Q/V)t})$,时间常数 $V/Q = 10$ 天。要求 $1 - e^{-t/10} = 0.95 \Rightarrow e^{-t/10} = 0.05 \Rightarrow t = 10\ln 20 \approx 30$ 天(约 3 个时间常数,通用结论:达到 95% 需 $3\tau$)。

</details>

**第 4 题(概念)**:解释 $R_0$ 的含义,并说明为何「隔离」与「治疗」都能遏制疫情。

<details><summary>查看答案</summary>

$R_0 = \beta S_0/\gamma$ 表示一个感染者在完全易感人群中平均传染的人数(传染率 $\times$ 易感人数 $\times$ 平均感染期)。$R_0 > 1$ 时感染人数指数增长,疫情爆发;$R_0 < 1$ 时逐代衰减。隔离降低接触率 $\beta$(减少相遇机会),治疗/康复加速提高 $\gamma$(缩短感染期 $1/\gamma$),两者都减小 $R_0$。当 $R_0$ 被压到 1 以下,疫情便自行消亡——这是所有传染病防控策略的数学本质。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:ODE 是国赛/美赛 A 题的常客——2019 国赛 A「高压油管」用微分方程刻画油管压力波动,2016 国赛 A「系泊系统」是力学平衡方程组,2003 国赛 A「SARS 传播」是 SIR 的经典应用,2015 美赛 A「Ebola」更是直接要求建立传染病模型并给出干预方案
- **论文加分点**:①建完模型**必做平衡点与稳定性分析**,说明系统的长期行为;②**用真实数据辨识参数**再预测,并给出拟合优度;③做**参数灵敏度分析**($R_0$ 对 $\beta$、$\gamma$ 的弹性),把数学结论翻译成政策建议;④数值解与解析解(或守恒量)交叉验证
- **工具**:`scipy.integrate.solve_ivp`(首选)、`scipy.integrate.odeint`(旧接口)、绘制相图用 `matplotlib` 的 `streamplot`

## 💻 代码实现

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# ---- 1. Logistic: 数值解 vs 解析解 ----
r, K, N0 = 0.5, 1000.0, 100.0

def logistic(t, N):
    return r * N * (1 - N / K)

sol = solve_ivp(logistic, [0, 15], [N0], dense_output=True)
t = np.linspace(0, 15, 100)
N_exact = K / (1 + (K / N0 - 1) * np.exp(-r * t))
print("t=15 数值解:", sol.sol(15)[0])
print("t=15 解析解:", N_exact[-1])
print("最大绝对误差:", np.max(np.abs(sol.sol(t)[0] - N_exact)))

# ---- 2. SIR 模型 + 守恒量检查 ----
def sir(t, y, beta, gamma):
    S, I, R = y
    return [-beta * S * I, beta * S * I - gamma * I, gamma * I]

beta, gamma = 4e-4, 0.1
sol2 = solve_ivp(sir, [0, 120], [999, 1, 0], args=(beta, gamma),
                 dense_output=True, t_eval=np.linspace(0, 120, 500))
print("R0 =", beta * 999 / gamma)
print("末期感染者 I(应为0):", sol2.y[1, -1])
print("末期未感染者 S:", sol2.y[0, -1], "(理论值约20)")
print("守恒检查 max|N-(S+I+R)|:", np.abs(1000 - sol2.y.sum(axis=0)).max())

plt.plot(sol2.t, sol2.y.T)
plt.legend(["S", "I", "R"])
plt.title("SIR 模型 (R0=4)")
plt.xlabel("天")
plt.show()
```

## 🧠 小结

1. ODE 建模四步:选状态变量 → 写变化率平衡(流入减流出)→ 定初值与参数 → 求解验证
2. 四个一阶模型(马尔萨斯、Logistic、牛顿冷却、污染箱)是竞赛套路的起点,Logistic 的拐点在 $K/2$ 可直接引用
3. 稳定性判据:一维看 $f'(x^*)$ 的符号,二维看雅可比特征值实部;纯虚根时线性化失效,需要守恒量(如 Lotka-Volterra 的 $H$)
4. SIR 的两大杀器:$R_0 = \beta S_0/\gamma$ 判阈值,终态规模方程算总感染数——传染病类题目的标准答案结构
5. 上机:solve_ivp 一行求解,但**守恒量检查 + 与解析解对比 + 步长收敛测试**三项验证,才能保证论文里的曲线可信
