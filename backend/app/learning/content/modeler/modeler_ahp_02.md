## 📖 核心概念

### 1. 为什么要「模糊」

经典 AHP 用精确数表达比较(「薪酬比前景重要 3 倍」)。但人的判断天然模糊:「稍微重要」和「明显重要」之间没有一道清晰的边界,而且不同专家对同一个「3」的理解也未必相同。模糊 AHP(Fuzzy AHP, FAHP)把成对比较值换成**模糊数**,用「大约是 3,可能在 2 到 4 之间」这样的区间信息替代点估计,更贴近真实判断。

### 2. 三角模糊数

一个三角模糊数记为 $\tilde{a} = (l, m, u)$,含义是:该值**最可能是 $m$**,取值落在 $[l, u]$ 内,隶属度呈三角形分布:

$$\mu_{\tilde{a}}(x) = \begin{cases} \dfrac{x-l}{m-l}, & l \le x \le m \\ \dfrac{u-x}{u-m}, & m \le x \le u \\ 0, & \text{其他} \end{cases}$$

基本运算法则($\tilde{a}=(l_1,m_1,u_1)$, $\tilde{b}=(l_2,m_2,u_2)$):

$$\tilde{a} \oplus \tilde{b} = (l_1+l_2,\ m_1+m_2,\ u_1+u_2), \qquad \tilde{a} \otimes \tilde{b} \approx (l_1 l_2,\ m_1 m_2,\ u_1 u_2)$$

$$\tilde{a}^{-1} \approx \left(\frac{1}{u_1},\ \frac{1}{m_1},\ \frac{1}{l_1}\right), \qquad k \cdot \tilde{a} = (kl_1,\ km_1,\ ku_1)$$

去模糊化常用**重心法** $\dfrac{l+m+u}{3}$ 或 **GMIR 法** $\dfrac{l+4m+u}{6}$(给最可能值更大权重)。

### 3. 模糊标度与模糊成对比较矩阵

把 Saaty 标度替换为三角模糊数(常用的一种模糊标度):

| 语义 | 经典 AHP | 模糊标度 $\tilde{a}_{ij}$ |
|------|----------|---------------------------|
| 同等重要 | 1 | (1, 1, 1) |
| 稍微重要 | 3 | (2, 3, 4) |
| 明显重要 | 5 | (4, 5, 6) |
| 强烈重要 | 7 | (6, 7, 8) |
| 极端重要 | 9 | (8, 9, 9) |

> 注:2、4、6、8 各档对应 (1,2,3)、(3,4,5) 等插值;不同文献的端点取值略有差异,论文中必须注明所用标度表。

模糊成对比较矩阵 $\tilde{A} = (\tilde{a}_{ij})$,主对角线为 $(1,1,1)$,下三角为上三角的模糊倒数。

### 4. 模糊权重求解的两条路线

- **Buckley 几何平均法**:对每行取几何平均,再按模糊数规则归一化,得到**模糊权重** $\tilde{w}_i$,最后去模糊化。直观、无信息丢失,推荐使用
- **Chang 程度分析法**:构造模糊综合程度值 $S_i$,用「程度可能度」$V(S_i \ge S_k)$ 求权重。它曾是论文中最常见的做法,但有著名的**零权重问题**(某因素被赋 0 权重,与直觉冲突,见例题 2 的对比)

### 5. 群体决策:多个专家怎么办

多人打分时,先对每个位置的模糊判断做**几何平均集结**,再做一次 FAHP:

$$\tilde{a}_{ij}^{G} = \left( \left(\prod_{k=1}^{K} l_{ij}^{(k)}\right)^{1/K},\ \left(\prod_{k=1}^{K} m_{ij}^{(k)}\right)^{1/K},\ \left(\prod_{k=1}^{K} u_{ij}^{(k)}\right)^{1/K} \right)$$

几何平均是正互反标度下唯一满足「一致性保序」的集结方式——经典 AHP 群决策同样适用这一原则。

### 6. 改进思路:0.1-0.9 模糊互补判断矩阵

经典 FAHP 仍要求专家回答「几倍重要」,认知负担不轻。另一种更易填写的格式是**模糊互补判断矩阵** $F = (f_{ij})$:只需回答「$i$ 比 $j$ 重要的程度」,取值在 0.1~0.9 之间:

- $f_{ij} + f_{ji} = 1$, $f_{ii} = 0.5$;$f_{ij} > 0.5$ 表示 $i$ 比 $j$ 重要,越接近 0.9 越重要
- **加法一致性**条件:$f_{ik} = f_{ij} + f_{jk} - 0.5$ 对所有 $i,j,k$ 成立
- 一致时权重有解析式:$w_i = \dfrac{2\sum_{j=1}^{n} f_{ij} - 1}{n(n-1)}$(见公式部分)

该法只需 $n(n-1)/2$ 次打分且不要求倒数运算,特别适合问卷式采集。

## 🧮 公式与结论

### Buckley 几何平均法(四步)

1. 模糊行几何平均:$\tilde{r}_i = \left(\prod_{j=1}^{n} \tilde{a}_{ij}\right)^{1/n} = \left(\big(\prod_j l_{ij}\big)^{1/n},\ \big(\prod_j m_{ij}\big)^{1/n},\ \big(\prod_j u_{ij}\big)^{1/n}\right)$
2. 模糊权重:$\tilde{w}_i = \tilde{r}_i \otimes \left(\sum_j \tilde{r}_j\right)^{-1}$,即

$$\tilde{w}_i = \left( \frac{l_i}{\sum_j u_j},\ \frac{m_i}{\sum_j m_j},\ \frac{u_i}{\sum_j l_j} \right)$$

3. 去模糊化:$\bar{w}_i = \dfrac{l_i + m_i + u_i}{3}$(或 GMIR),再归一化
4. 一致性粗检:取各元素的最可能值 $m_{ij}$ 组成普通矩阵,按经典 AHP 检验 $CR < 0.1$(模糊判断下严格一致性几乎不可能,粗检即可)

### Chang 程度分析法(公式)

模糊综合程度值:

$$S_i = \sum_{j=1}^{n} \tilde{a}_{ij} \otimes \left( \sum_{i=1}^{n}\sum_{j=1}^{n} \tilde{a}_{ij} \right)^{-1}, \qquad \sum_j \tilde{a}_{ij} = \left(\sum_j l_{ij},\ \sum_j m_{ij},\ \sum_j u_{ij}\right)$$

两个三角模糊数 $S_2 \ge S_1$ 的可能度:

$$V(S_2 \ge S_1) = \begin{cases} 1, & m_2 \ge m_1 \\ \dfrac{l_1 - u_2}{(m_2 - u_2) - (m_1 - l_1)}, & l_1 \le u_2 \\ 0, & \text{其他} \end{cases}$$

权重:$\ d_i = \min_{k \ne i} V(S_i \ge S_k)$,归一化得 $w$。注意该方法可能出现 $d_i = 0$(零权重)。

### 0.1-0.9 模糊互补矩阵权重

$$w_i = \frac{2\sum_{j=1}^{n} f_{ij} - 1}{n(n-1)}, \qquad \text{要求 } f_{ij} + f_{ji} = 1 \text{ 且加法一致}$$

一致性偏差可用全部三元组的平均绝对偏差衡量(三元组共 $C_n^3 = n(n-1)(n-2)/6$ 个):

$$\delta = \frac{6}{n(n-1)(n-2)}\sum_{i<j<k}\left|f_{ij} + f_{jk} - f_{ik} - 0.5\right|$$

$\delta$ 越接近 0 越一致;偏差大时应让专家复核。

## 💡 经典例题

### 例题 1:Buckley 法求模糊权重(完整计算)

> 三准则模糊成对比较:$\tilde{a}_{12} = (2,3,4)$($C_1$ 比 $C_2$ 稍微重要),$\tilde{a}_{13} = (4,5,6)$($C_1$ 比 $C_3$ 明显重要),$\tilde{a}_{23} = (1,2,3)$。下三角取倒数。求模糊权重。

模糊矩阵(上三角):

$$\tilde{A} = \begin{bmatrix} (1,1,1) & (2,3,4) & (4,5,6) \\ (1/4,1/3,1/2) & (1,1,1) & (1,2,3) \\ (1/6,1/5,1/4) & (1/3,1/2,1) & (1,1,1) \end{bmatrix}$$

**第一步:行几何平均。**

$$\begin{aligned} \tilde{r}_1 &= \big(8^{1/3},\ 15^{1/3},\ 24^{1/3}\big) = (2.000,\ 2.466,\ 2.884) \\ \tilde{r}_2 &= \big((1/4)^{1/3},\ (2/3)^{1/3},\ 1.5^{1/3}\big) = (0.630,\ 0.874,\ 1.145) \\ \tilde{r}_3 &= \big((1/18)^{1/3},\ 0.1^{1/3},\ 0.25^{1/3}\big) = (0.382,\ 0.464,\ 0.630) \end{aligned}$$

**第二步:模糊权重。** 三个分量和:$\sum l = 3.012$,$\sum m = 3.804$,$\sum u = 4.659$。

$$\tilde{w}_1 = \left(\frac{2.000}{4.659},\ \frac{2.466}{3.804},\ \frac{2.884}{3.012}\right) = (0.429,\ 0.648,\ 0.958)$$

$$\tilde{w}_2 = \left(\frac{0.630}{4.659},\ \frac{0.874}{3.804},\ \frac{1.145}{3.012}\right) = (0.135,\ 0.230,\ 0.380)$$

$$\tilde{w}_3 = \left(\frac{0.382}{4.659},\ \frac{0.464}{3.804},\ \frac{0.630}{3.012}\right) = (0.082,\ 0.122,\ 0.209)$$

**第三步:去模糊化。** 重心法 $\bar{w}_i = (l+m+u)/3$:$\bar{w} = (0.678,\ 0.248,\ 0.138)$,归一化($\sum = 1.064$)得

$$w = (0.637,\ 0.233,\ 0.129)$$

**解析**:注意模糊权重的**区间宽度本身携带信息**——$C_1$ 的权重从 0.429 到 0.958,不确定性最大(它参与了两次带模糊性的比较);若只需排序,区间大部分重叠时才需要谨慎下结论。用 $m$ 值矩阵 $\begin{bmatrix} 1 & 3 & 5 \\ 1/3 & 1 & 2 \\ 1/5 & 1/2 & 1 \end{bmatrix}$ 做粗检:$\lambda_{\max} = 3.004$,$CR = 0.003 < 0.1$ ✓。对比经典 AHP 直接按 $m$ 值计算得 $w = (0.648,\ 0.230,\ 0.122)$,与模糊结果排序一致。

### 例题 2:Chang 程度分析法与零权重问题

对同一矩阵用 Chang 法。先求行和:

$$\sum_j \tilde{a}_{1j} = (7,\ 9,\ 11), \quad \sum_j \tilde{a}_{2j} = (2.25,\ 3.333,\ 4.5), \quad \sum_j \tilde{a}_{3j} = (1.5,\ 1.7,\ 2.25)$$

总和 $\sum_i\sum_j \tilde{a}_{ij} = (10.75,\ 14.033,\ 17.75)$,其模糊倒数为 $(0.0563,\ 0.0713,\ 0.0930)$。于是

$$S_1 = (0.394,\ 0.641,\ 1.023), \quad S_2 = (0.127,\ 0.238,\ 0.419), \quad S_3 = (0.085,\ 0.121,\ 0.209)$$

程度可能度($m_1 > m_2 > m_3$,只需算 $S_2$、$S_3$ 相对 $S_1$ 的可能度):

$$\begin{aligned} V(S_2 \ge S_1) &= \frac{l_1 - u_2}{(m_2 - u_2) - (m_1 - l_1)} = \frac{0.394 - 0.419}{(0.238-0.419) - (0.641-0.394)} = \frac{-0.024}{-0.428} = 0.057 \\ V(S_3 \ge S_1) &= \frac{0.394 - 0.209}{(0.121-0.209) - (0.641-0.394)} = \frac{0.185}{-0.335} < 0 \ \Rightarrow\ 0 \end{aligned}$$

$d = (1,\ 0.057,\ 0)$,归一化得 $w = (0.946,\ 0.054,\ 0.000)$——**$C_3$ 被赋予 0 权重**!而 Buckley 法给出 0.129,经典 AHP 给出 0.122。这正是 Chang 法的著名缺陷:当某个因素的 $S$ 区间完全被压住时权重归零,与直观判断相悖。

**解析**:国赛论文中 Chang 法占比很高,但这个缺陷常被评委指出。建议:①改用 Buckley 法;②若用 Chang 法,对零权重做敏感性讨论;③在论文中明确说明所采用方法及理由。

### 例题 3:群体决策的几何平均集结

两位专家对 $\tilde{a}_{12}$ 分别给出 $(2,3,4)$ 与 $(1,2,3)$。集结:

$$\tilde{a}_{12}^{G} = \left( (2 \times 1)^{1/2},\ (3 \times 2)^{1/2},\ (4 \times 3)^{1/2} \right) = (1.414,\ 2.449,\ 3.464)$$

**解析**:集结结果位于两专家判断之间、更靠近中心,符合「求同」直觉。注意:若专家间分歧极大(如一个给 $(2,3,4)$、另一个给其倒数),说明对判断方向本身有争议,应先讨论统一,而不是机械平均。

### 例题 4:0.1-0.9 模糊互补矩阵

三方案打分:$f_{12} = 0.6$,$f_{13} = 0.7$,$f_{23} = 0.6$,主对角线 0.5,互补填下三角:

$$F = \begin{bmatrix} 0.5 & 0.6 & 0.7 \\ 0.4 & 0.5 & 0.6 \\ 0.3 & 0.4 & 0.5 \end{bmatrix}$$

加法一致性检验:$f_{13} = 0.7 = f_{12} + f_{23} - 0.5 = 0.6 + 0.6 - 0.5$ ✓,完全一致。权重:

$$w_1 = \frac{2(0.5+0.6+0.7) - 1}{3 \times 2} = \frac{2.6}{6} = 0.433, \quad w_2 = \frac{2(1.5)-1}{6} = 0.333, \quad w_3 = \frac{2(1.2)-1}{6} = 0.233$$

排序:$1 > 2 > 3$,且 $f_{ij} = 0.5 + (w_i - w_j)$ 逐项成立($0.6 = 0.5 + 0.1$ ✓ 等),权重与判断自洽。

## ⚠️ 常见易错点

1. **三角模糊数倒数取错**。$\tilde{a}^{-1} = (1/u,\ 1/m,\ 1/l)$,不是 $(1/l, 1/m, 1/u)$——区间端点的顺序会反转
2. **模糊权重不归一化直接排序**。Buckley 法的 $\tilde{w}_i$ 是模糊数,去模糊化后仍需归一化再比较(例题 1 中 $\sum \bar{w} = 1.064 \ne 1$)
3. **用 Chang 法拿到零权重不解释**。零权重是方法缺陷而非真实结论,必须说明或换方法,否则评委必扣分
4. **模糊标度与经典标度混用**。一个矩阵里既有精确数又有模糊数,或不同层用不同标度表却不注明
5. **群体决策时先平均权重再检验一致性**。应先对**判断**几何平均集结、再统一检验;先算各家权重再算术平均会破坏互反结构
6. **忽视区间重叠的排序风险**。模糊权重区间大范围重叠时,排序可能不稳健;此时应报告区间而非强行给出唯一排序

**第 1 题** 已知三角模糊数 $\tilde{a} = (2, 3, 4)$,另 $\tilde{b} = (1, 2, 3)$。求 $\tilde{a}^{-1}$ 与 $\tilde{a} \otimes \tilde{b}$。正确结果是:

A. $\tilde{a}^{-1} = (1/4,\ 1/3,\ 1/2)$;$\tilde{a} \otimes \tilde{b} = (2,\ 6,\ 12)$
B. $\tilde{a}^{-1} = (1/2,\ 1/3,\ 1/4)$;$\tilde{a} \otimes \tilde{b} = (2,\ 6,\ 12)$

D. $\tilde{a}^{-1} = (4,\ 3,\ 2)$;$\tilde{a} \otimes \tilde{b} = (2,\ 6,\ 12)$

<details><summary>查看答案与解析</summary>
**答案:A**。三角模糊数的倒数要把端点顺序反转:$\tilde{a}^{-1} = (1/u,\ 1/m,\ 1/l) = (1/4,\ 1/3,\ 1/2)$——因为 $u$ 是最大的端点,其倒数最小,必须放到 $l$ 的位置。选项 B 写 $(1/2, 1/3, 1/4)$ 是「区间端点顺序不反转」的典型错误,会得到一条方向颠倒的隶属区间。乘法按分量相乘:$\tilde{a} \otimes \tilde{b} = (2\times1,\ 3\times2,\ 4\times3) = (2,\ 6,\ 12)$;选项 C 把「乘」记成了「加」(得 $(3,5,7)$),选项 D 把倒数记成了「取反」(得 $(4,3,2)$)——区间端点顺序反转是模糊运算的第一考点。
</details>

**第 2 题** 用 Chang 程度分析法求模糊 AHP 权重时,某因素的权重计算结果为 0(零权重问题)。下列做法**正确**的是:

A. 这是 Chang 法的已知缺陷(该因素的 $S$ 区间被完全压住),应改用 Buckley 几何平均法,或在论文中明确说明并做敏感性讨论
B. 这说明该因素确实毫不重要,应如实报告零权重,并把它从指标体系中删除
C. 这说明计算过程一定出了错误,应反复调整判断矩阵直到所有权重都大于 0
D. 零权重不影响因素间的相对排序,直接按所得权重报告结论即可

<details><summary>查看答案与解析</summary>
**答案:A**。Chang 程度分析法在某个因素的模糊综合程度值区间被其他因素完全压住时,可能度 $V(S_i \ge S_k)$ 全部为 0,权重被赋 0——这是**方法缺陷**而非真实结论。同一数据用 Buckley 法可得 0.129、经典 AHP 得 0.122,可见该因素并非毫无分量。正确应对:首选改用 Buckley 法;若坚持用 Chang 法,必须对零权重做解释与敏感性讨论。选项 B「删除指标」把方法缺陷当成了真实结论;选项 C 机械调数据等于为方法辩护而牺牲专家原始判断;选项 D 的问题在于零权重会直接改变排序(该因素被彻底踢出),不是「不影响」。
</details>

**第 3 题** 用 0.1-0.9 标度得到模糊互补判断矩阵

$$F = \begin{bmatrix} 0.5 & 0.6 & 0.7 \\ 0.4 & 0.5 & 0.6 \\ 0.3 & 0.4 & 0.5 \end{bmatrix}$$

经检验其满足加法一致性($f_{ik} = f_{ij} + f_{jk} - 0.5$)。求各方案权重:

A. $w = (0.433,\ 0.333,\ 0.233)$
B. $w = (0.6,\ 0.5,\ 0.4)$
C. $w = (0.233,\ 0.333,\ 0.433)$
D. $w = (0.4,\ 0.333,\ 0.267)$

<details><summary>查看答案与解析</summary>
**答案:A**。加法一致时权重有解析式 $w_i = \frac{2\sum_{j=1}^{n} f_{ij} - 1}{n(n-1)}$。行和依次为 $1.8,\ 1.5,\ 1.2$,故 $w_1 = \frac{2\times1.8-1}{3\times2} = 0.433$、$w_2 = \frac{3-1}{6} = 0.333$、$w_3 = \frac{2.4-1}{6} = 0.233$。三个干扰项对应三种真实错误:选项 B 忘了公式里的「$2\sum f - 1$」结构(直接 $2\sum f/6$,和不为 1);选项 C 把权重顺序完全颠倒(方向写反);选项 D 直接把行和归一化(把公式换成了普通归一化)。验证:权重满足 $f_{ij} = 0.5 + (w_i - w_j)$ 逐项成立,与判断自洽。
</details>

- **出镜频率**:国赛评价类论文中,「模糊 AHP + 模糊综合评价」是高频组合,特别适合专家打分、问卷数据、定性指标多的题目
- **论文加分点**:①注明模糊标度表与去模糊化方法(重心法还是 GMIR);②报告 $m$ 值矩阵的 CR 粗检;③群体决策说明集结方式与专家人数、背景;④用 Buckley 法避开 Chang 零权重陷阱,或在文中对比两法结果
- **常见翻车点**:公式只抄不验算,出现 $\tilde{w}$ 不归一化、Chang 法零权重不解释、标度表前后不一致——都是评委一眼看穿的硬伤
- **工具**:python 元组即可实现三角模糊数运算,无需专用库

## 💻 代码实现

```python
import numpy as np
from math import prod


def tf_inv(a):
    return (1 / a[2], 1 / a[1], 1 / a[0])


# 上三角模糊判断 (i,j) -> (l,m,u),主对角线 (1,1,1)
F = {(1, 2): (2, 3, 4), (1, 3): (4, 5, 6), (2, 3): (1, 2, 3)}
n = 3
M = [[(1.0, 1.0, 1.0)] * n for _ in range(n)]
for (i, j), v in F.items():
    M[i - 1][j - 1] = v
    M[j - 1][i - 1] = tf_inv(v)

# Buckley 几何平均法
geo = [tuple(prod(M[i][k][t] for k in range(n)) ** (1 / n) for t in range(3)) for i in range(n)]
l_sum = sum(g[0] for g in geo)
m_sum = sum(g[1] for g in geo)
u_sum = sum(g[2] for g in geo)
w_fuzzy = [(g[0] / u_sum, g[1] / m_sum, g[2] / l_sum) for g in geo]

# 去模糊化(重心法)并归一化
w = np.array([(l + m + u) / 3 for l, m, u in w_fuzzy])
w = w / w.sum()
print("模糊权重:", [tuple(round(x, 3) for x in t) for t in w_fuzzy])
# [(0.429, 0.648, 0.958), (0.135, 0.23, 0.38), (0.082, 0.122, 0.209)]
print("去模糊化权重:", np.round(w, 3))  # [0.637 0.233 0.129]

# 0.1-0.9 模糊互补矩阵
Fm = np.array([[0.5, 0.6, 0.7], [0.4, 0.5, 0.6], [0.3, 0.4, 0.5]])
w2 = (2 * Fm.sum(axis=1) - 1) / (n * (n - 1))
print("模糊互补矩阵权重:", np.round(w2, 3))  # [0.433 0.333 0.233]
```

## 🧠 小结

1. 模糊 AHP 把点估计换成三角模糊数 $(l,m,u)$,区间宽度刻画判断不确定性,更适合主观性强、专家分歧大的场景
2. Buckley 几何平均法四步走:行几何平均 → 模糊归一化 → 去模糊化 → $m$ 值矩阵 CR 粗检;结果可靠且易于解释
3. Chang 程度分析法公式漂亮但有零权重硬伤,竞赛中使用前想清楚应对策略(换法或解释)
4. 群体决策先对判断做几何平均集结,再统一求解与检验
5. 0.1-0.9 模糊互补矩阵是低认知负担的替代方案,一致时权重有解析式,适合问卷采集
