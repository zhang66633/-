## 📖 核心概念

### 1. CA 的五要素

| 要素 | 说明 | 例子(交通流) |
|------|------|-------------|
| **格点** | 规则网格,一维或二维 | 车道划分为 7.5 m 的格子 |
| **状态** | 每个元胞的有限状态集 | 空 / 有车(速度 $0 \sim v_{\max}$) |
| **邻域** | 影响更新的是谁 | von Neumann(上下左右 4 格)或 Moore(8 格) |
| **规则** | 局部更新函数 | 加速、减速、随机慢化、移动 |
| **时间** | 离散同步更新 | 每步 1 秒,全体同时刷新 |

> 💡 **建模心法**:CA 的价值在于「**微观规则简单,宏观现象丰富**」——每辆车只做四步傻操作,整体却自发出现拥堵波;每个细胞只数邻居,整体却涌现出滑翔机。凡是「个体行为规则清楚、整体行为难以直接写出」的问题(交通、疏散、火灾、谣言、城市扩张),都值得先试 CA。

### 2. 初等元胞自动机与 Wolfram 编号

一维 CA:两状态(0/1)、三邻居(左/中/右),共 $2^3 = 8$ 种邻域模式,每种模式指定一个输出,故有 $2^8 = 256$ 种规则。**编号方法**:把 8 种模式按二进制从 111 到 000 排列,输出串看作二进制数转十进制:

$$\text{Rule} = (o_{111}\,o_{110}\,o_{101}\,o_{100}\,o_{011}\,o_{010}\,o_{001}\,o_{000})_2$$

两个竞赛常客:

- **Rule 90**($01011010_2 = 90$):新状态 = 左右邻居异或。从单点初值出发,演化图形恰好是 **Pascal 三角形模 2**(奇数格),呈现出 Sierpinski 分形——「确定性规则产生自相似结构」的经典演示
- **Rule 184**($10111000_2 = 184$):车辆向右移动的「一车一格」简化交通模型,是 NaSch 的雏形

### 3. 生命游戏(Game of Life)

二维、两状态(活/死)、Moore 邻域,规则只有两条:

- **存活**:活细胞有 2 或 3 个活邻居 → 继续活,否则死亡(孤独或拥挤)
- **出生**:死细胞恰好有 3 个活邻居 → 变为活

三类基本模式:静物(如方块,不随时间变化)、振荡子(如**信号灯 blinker**,竖直三格与水平三格交替,周期 2)、移动体(如**滑翔机 glider**,5 个细胞,4 步平移一格,周期 4)。生命游戏证明了一个深刻事实:极简局部规则可以产生**图灵完备**的计算能力——这也是「涌现」一词最好的注脚。

### 4. NaSch 交通流模型(竞赛最常用)

一维格点,每格最多一辆车,每辆车有离散速度 $v \in \{0, 1, \dots, v_{\max}\}$。每步四段操作(顺序不能换):

1. **加速**:$v \to \min(v+1, v_{\max})$(司机想开快)
2. **减速**:$v \to \min(v, d)$($d$ 为前方空格数,防止撞车)
3. **随机慢化**:以概率 $p$ 令 $v \to \max(v-1, 0)$(反应延迟、路况干扰)
4. **移动**:$x \to x + v$(按新速度前进)

**基本图**(流量-密度关系)是交通建模的核心输出:车流密度低时自由行驶,流量随密度线性上升;超过临界密度后,随机慢化使「走走停停」的拥堵波自发出现,流量反而下降——**没有红绿灯、没有事故,纯均匀道路上也会自发拥堵**,这就是涌现。

### 5. 从交通到疏散:floor field 模型

疏散模拟把 CA 推广到二维:每个元胞是行人或空,行人按「离出口的**静态场**势(到出口的最短距离)+ 前人走过的**动态场**痕迹 + 随机扰动」三个因素选择下一步。静态场提供方向感,动态场模拟「跟随人流」,两条规则叠加就能复现出口拱形拥堵、瓶颈摆动等真实现象。

## 🧮 公式与结论

### 初等 CA 的编号(必须会算)

把 8 种邻域模式(111, 110, 101, 100, 011, 010, 001, 000)对应的输出写成 8 位二进制,转十进制:

- Rule 90:输出串 $01011010_2 = 64 + 16 + 8 + 2 = 90$(即「左右异或」:左=右=1 时输出 0,恰一为 1 时输出 1)
- Rule 184:输出串 $10111000_2 = 128 + 32 + 16 + 8 = 184$

### NaSch 的基本图($p = 0$ 时,可手算)

- 低密度自由流:车间距足够大,每辆车都保持 $v_{\max}$,$J = v_{\max}\rho$
- 高密度拥堵流:车辆被迫一辆跟一辆,前方每空一格就前进一步,$J = 1 - \rho$
- 两段交点即临界密度与最大流量:

$$\rho^* = \frac{1}{v_{\max} + 1},\qquad J_{\max} = \frac{v_{\max}}{v_{\max} + 1},\qquad J(\rho) = \min\big(v_{\max}\rho,\ 1-\rho\big)$$

例:$v_{\max} = 2$ 时,$\rho^* = 1/3$,$J_{\max} = 2/3$。$p > 0$ 时最大流量下降,拥堵在更低密度就出现,基本图需仿真统计。

### 生命游戏与疏散模型的量化要点

- 生命游戏更新函数:$s' = 1 \iff (s = 1 \land n \in \{2,3\}) \lor (s = 0 \land n = 3)$,$n$ 为 Moore 邻域活细胞数
- 疏散模型的行人转移概率(简化版,静态场 $S$ + 动态场 $D$ + 噪声):

$$P_{ij} \propto \exp\big(k_S S_{ij} + k_D D_{ij}\big)$$

- CA 结果必须**统计化**:疏散时间、总流量、拥堵时空图的平均值与标准差,单次模拟的画面只用于插图,不用于结论

## 💡 经典例题

### 例题 1:Rule 90 手算三步(验证「Pascal 三角形模 2」)

> 一维无限长(或周期)格点,只有中心一个 1,按 Rule 90 演化三步,写出每一行的格局。

**规则回顾**:Rule 90 = 左右邻居异或:新值 = 左 XOR 右。

**手算**($\cdot$ 表示 0):

- $t=0$:$\cdots\cdot\cdot\cdot 1 \cdot\cdot\cdot\cdots$(只有位置 0 是 1)
- $t=1$:每个位置的输出由两侧决定。位置 $-1$:两侧 $0,1$ → 1;位置 $1$:两侧 $1,0$ → 1;其余两侧都为 0 → 0。得 $\cdots\cdot\cdot 1\cdot 1\cdot\cdot\cdots$
- $t=2$:位置 $-2$:两侧 $0,1$ → 1;位置 $2$:两侧 $1,0$ → 1;位置 $0$:两侧 $1,1$ → 0。得 $\cdots\cdot 1\cdot\cdot\cdot 1\cdot\cdots$
- $t=3$:位置 $-3,-1,1,3$ 两侧恰一为 1 → 1,其余为 0。得 $\cdots 1\cdot 1\cdot 1\cdot 1\cdots$

**验证**:二项式系数第 $n$ 行是 $(1+1)^n$ 的系数,Pascal 三角形前几行为 $1;\ 1,1;\ 1,2,1;\ 1,3,3,1$;模 2(奇偶)后为 $1;\ 1,1;\ 1,0,1;\ 1,1,1,1$——与手算结果**逐行一致**。

**解析**:这个例子的意义不在计算本身,而在它展示了 CA 的两个特征:①**局部规则 + 迭代 = 全局模式**,简单异或长出了 Sierpinski 分形;②确定性规则也能验证——把 CA 结果与已知数学结构(Pascal 三角形)对照,是论文里证明「程序没有 bug」的漂亮手段。

### 例题 2:生命游戏的手算模式(blinker 与 glider)

> 验证:竖直三连(blinker)在生命游戏下周期为 2;滑翔机(glider)周期为 4 且整体平移一格。

**blinker 验证**:竖直三格,设上下两格的活邻居:每格只有中间格 1 个活邻居 + 周围死格 → 上、下格各有 1 个活邻居(<2)→ 死亡;中间格有 2 个活邻居 → 存活;而水平方向与上、下格相邻的两个死格,各有 3 个活邻居(竖直三格中相邻的两个 + 中间格)→ 出生。于是竖直三格变成**水平三格**。对称地,下一步又变回竖直——周期 2 振荡 ✓。

**glider 验证**(可用程序或按格数邻居,结论性描述):滑翔机由 5 个活细胞组成(形如 ⌐ 的折线),每 4 步整体向右下平移一格,方向不变——它是「会移动的稳定模式」。验证要点:按每格的 Moore 邻居数逐一核对两步后仍是同一形状,即可确认周期 4。

**解析**:模式分类(静物/振荡子/移动体)是生命游戏的标准语汇。竞赛中用生命游戏框架做**谣言传播、疾病空间扩散、城市蔓延**时,「识别涌现出的稳定结构并解释其含义」远比「放一段动画」有说服力。

### 例题 3:NaSch 模型的手算与基本图

> 单车道 NaSch 模型,$v_{\max} = 2$,随机慢化概率 $p = 0$(先看确定性情形)。①一辆车从格子 0 出发,给出前 3 步的位置与速度;②求基本图与最大流量。

**①单车演化**:

- $t=0$:位置 0,速度 0
- 第 1 步:加速 $v=1$,前方无车不减速,移动 → 位置 1
- 第 2 步:加速 $v=2$,移动 → 位置 3
- 第 3 步:已到 $v_{\max}$ 保持 $v=2$,移动 → 位置 5

速度序列 $0, 1, 2, 2, \dots$,位置 $0, 1, 3, 5, \dots$——每步 2 格,匀速行驶。

**②基本图**($p=0$):低密度时 $J = v_{\max}\rho = 2\rho$;高密度时 $J = 1 - \rho$。交点:

$$2\rho = 1 - \rho \ \Rightarrow\ \rho^* = \frac{1}{3},\qquad J_{\max} = \frac{2}{3}$$

即每格平均 1/3 辆车时流量最大,为每步 2/3 辆。密度超过 1/3 后,车距不足,车辆被迫减速,流量下降;密度 1(全满)时谁也动不了,$J = 0$。

**解析**:$p > 0$ 时手算不再可行,必须仿真:随机慢化像「蝴蝶效应」的种子,在车队中逐车放大,形成向上游传播的走走停停波——这是**没有红绿灯的自发拥堵**,也是 2016 国赛 B「小区开放对道路通行的影响」类题目的核心机制。论文写法:先给规则表,再给基本图(多次模拟平均 + 误差棒),再对比不同 $p$、$v_{\max}$ 的敏感性。

## ⚠️ 常见易错点

1. **同步更新写成顺序更新**。第 $i$ 个细胞更新后立刻影响第 $i+1$ 个细胞的邻居计数,结果完全不同。正确做法:先算全部新状态存入新数组,再一次性替换(双缓冲)
2. **边界条件不声明**。周期边界、截断边界、反射边界对结果影响巨大(交通流中周期边界相当于环线);论文必须写明用哪种,并说明与实际问题(如开放式道路)的对应
3. **单次模拟下结论**。NaSch 有随机慢化、疏散模型有随机转移,一次模拟只是随机过程的一个样本;结论必须来自多次独立模拟的均值与标准差
4. **格子不标定**。CA 的格子长、时间步必须有物理单位(如车道格长 7.5 m、步长 1 s),否则「流量 0.6/步」无法与实测车流对比,论文结论悬空
5. **只有动画没有指标**。演示再炫也不是结论;需要统计指标(流量-密度图、平均疏散时间、过火面积)以及随参数的敏感性曲线
6. **把 CA 当唯一方法**。CA 适合「离散个体、局部规则」问题;连续场问题应对比 PDE(参见《偏微分方程与有限差分》单元),宏观规律问题应对比 ODE——两种框架互相验证是加分项

**第 1 题(判断)**:Rule 90 从单个 1 出发的演化图形,与 Pascal 三角形各元素按奇偶(模 2)染色的图形相同。对吗?

<details><summary>查看答案</summary>

**对**。Rule 90 的新值 = 左右邻居异或,恰好等于 $\binom{n-1}{k-1} + \binom{n-1}{k} = \binom{n}{k}$ 的奇偶性(二进制不进位加法),所以第 $t$ 行的格局就是二项式系数第 $t$ 行的奇偶分布,呈现 Sierpinski 分形。例题 1 已手算验证前三行。

</details>

**第 2 题(计算)**:生命游戏中,一个活细胞有 4 个活邻居,下一时刻的状态是什么?一个死细胞有 3 个活邻居呢?

<details><summary>查看答案</summary>

活细胞 + 4 个活邻居 → **死亡**(过度拥挤,规则要求活细胞必须有 2 或 3 个活邻居才存活);死细胞 + 3 个活邻居 → **出生**(恰好 3 个活邻居是唯一的出生条件)。「2-3 存活、3 出生」这条规则要背到条件反射:邻居太少孤独死,太多拥挤死,不多不少恰 3 个则新生。

</details>

**第 3 题(计算)**:NaSch 模型,$p = 0$,$v_{\max} = 3$。求基本图的临界密度与最大流量。

<details><summary>查看答案</summary>

$$\rho^* = \frac{1}{v_{\max}+1} = \frac{1}{4},\qquad J_{\max} = \frac{v_{\max}}{v_{\max}+1} = \frac{3}{4}$$

低密度段 $J = 3\rho$,高密度段 $J = 1-\rho$,交点 $(1/4, 3/4)$。密度超过 1/4 即进入拥堵区,比 $v_{\max}=2$ 时($\rho^*=1/3$)更早拥堵——速度上限越高,「每辆车需要的空间」越大,临界密度越低。

</details>

**第 4 题(概念)**:疏散模拟中「静态场」与「动态场」各起什么作用?为什么要同时使用?

<details><summary>查看答案</summary>

**静态场**:由「到出口的最短距离」构造的势场,提供全局方向感——行人总倾向往离出口更近的格子走,相当于「看地图」;**动态场**:记录格子被行人踩过的痕迹(随时间衰减),提供局部跟随倾向——相当于「跟着人流走」。只用静态场,行人全走同一条最短路,瓶颈过度拥堵且不真实;加上动态场后,部分行人绕行,出现真实的出口摆动与分流。两者加噪声扰动,即 floor field 模型的标准结构。

</details>

## 💻 代码实现

```python
import numpy as np
from scipy.signal import convolve2d
import matplotlib.pyplot as plt

# ---- 生命游戏(同步更新 + Moore 邻域计数) ----
def life_step(grid):
    n = convolve2d(grid, np.ones((3, 3)), mode="same") - grid
    return ((n == 3) | ((n == 2) & grid)).astype(int)

grid = np.zeros((30, 30), dtype=int)
grid[15:18, 15:18] = 1       # 3x3 方块(静物)
grid[3, 3:6] = 1             # blinker(周期 2 振荡子)
grid[10:13, 10:12] = 1
grid[12, 12] = 1             # glider 雏形
for t in range(4):
    plt.subplot(1, 4, t + 1)
    plt.imshow(grid, cmap="binary")
    plt.title(f"t={t}")
    grid = life_step(grid)
plt.show()

# ---- NaSch 交通流与基本图 ----
def nasch_flow(L, N, vmax, p, warmup=300, avg=1000, seed=0):
    rng = np.random.default_rng(seed)
    pos = np.sort(rng.choice(L, N, replace=False))
    v = np.zeros(N, dtype=int)
    total = 0
    for t in range(warmup + avg):
        gaps = (np.roll(pos, -1) - pos) % L - 1     # 前方空格数
        v = np.minimum(v + 1, vmax)                 # 1. 加速
        v = np.minimum(v, gaps)                     # 2. 减速
        v = np.maximum(v - (rng.random(N) < p), 0)  # 3. 随机慢化
        pos = (pos + v) % L                         # 4. 移动
        pos.sort()
        if t >= warmup:
            total += v.sum()
    return total / (avg * L)                        # 流量 J = ρ·v̄

L, vmax, p = 200, 5, 0.3
rhos = np.arange(0.02, 0.6, 0.04)
Js = [nasch_flow(L, int(rho * L), vmax, p) for rho in rhos]
plt.figure()
plt.plot(rhos, Js, "o-")
plt.plot(rhos, np.minimum(vmax * rhos, 1 - rhos), "--", label="p=0 理论值")
plt.xlabel("密度 ρ"); plt.ylabel("流量 J")
plt.legend(); plt.title("NaSch 基本图 (p=0.3)")
plt.show()
```
