## 📖 核心概念

### 1. 灰色系统理论:小样本的无奈与智慧

灰色系统理论由邓聚龙教授于 1982 年提出。**灰色 = 部分信息已知、部分未知**。与统计方法的定位差异:统计模型默认「大样本 + 典型分布」,灰色模型从 **4–10 个数据点**中挖掘指数规律。国赛题目常给 5–10 年数据要求预测未来 3–5 年——这个样本量下回归、ARIMA 都很勉强,GM(1,1) 恰好擅长,因此成为国赛预测题最高频的模型之一。

### 2. 适用条件:三个「必须」

1. **样本量小**:4–10 个数据点(典型 5–8 个)
2. **非负且单调**:递增或递减,近似指数增长效果最好
3. **只做短期预测**:一般 3 步以内,国赛常见 5 步以内,但必须附精度检验说明

**级比检验**给出量化判据。定义级比:

$$\sigma(k) = \frac{x^{(0)}(k-1)}{x^{(0)}(k)}, \qquad k = 2, 3, \dots, n$$

若所有级比都落在**可容覆盖** $\left(e^{-2/(n+1)},\ e^{2/(n+1)}\right)$ 内,数据适合 GM(1,1);否则应先做数据变换(见下文「数据预处理」)。

### 3. 累加生成(AGO):把噪声「抹平」的核心操作

$$x^{(1)}(k) = \sum_{i=1}^k x^{(0)}(i), \qquad k = 1, 2, \dots, n$$

- 一次累加后的序列 $x^{(1)}$ 单调递增,比原始序列平滑得多,随机波动被削弱
- 若原始序列本身近似指数增长,累加序列仍是指数型——这正是 GM(1,1) 用一阶微分方程描述它的原因
- 预测完成后必须**累减还原(IAGO)**:$\hat x^{(0)}(k) = \hat x^{(1)}(k) - \hat x^{(1)}(k-1)$,否则预测值是「累计量」而非原始量纲

### 4. GM(1,1) 的两个方程

**灰微分方程**(离散数据层面,用于估计参数):

$$x^{(0)}(k) + a\, z^{(1)}(k) = b, \qquad k = 2, 3, \dots, n$$

其中 $z^{(1)}(k) = 0.5\big(x^{(1)}(k) + x^{(1)}(k-1)\big)$ 称为**紧邻均值(背景值)**。

**白化方程**(连续层面,用于求解预测公式):

$$\frac{dx^{(1)}}{dt} + a x^{(1)} = b$$

- $a$:**发展系数**,刻画序列的增长态势,$a < 0$ 表示递增,$a > 0$ 表示递减
- $b$:**灰作用量**,反映外部输入
- 名字 GM(1,1) 的含义:1 阶微分方程、1 个变量

### 5. 精度检验:三件套

- **相对误差检验**:逐点相对误差与平均相对误差(经验:平均 < 5% 优,< 10% 合格)
- **后验差比值 C**:$C = S_2 / S_1$,残差标准差比原始序列标准差,C 越小越好
- **小误差概率 P**:残差落在「可接受带」内的比例,P 越大越好

精度等级表(刘思峰):

| 等级 | 后验差比值 C | 小误差概率 P |
|------|--------------|--------------|
| 一级(优) | $C < 0.35$ | $P > 0.95$ |
| 二级(合格) | $C < 0.50$ | $P > 0.80$ |
| 三级(勉强) | $C < 0.65$ | $P > 0.70$ |
| 四级(不合格) | $C \geq 0.65$ | $P \leq 0.70$ |

### 6. 数据预处理(不满足条件时)

- **级比超界(增长过快)**:做整体平移 $y^{(0)}(k) = x^{(0)}(k) + c$,选 $c$ 使级比落入可容覆盖,预测后减回
- **波动较大**:取对数 $\ln x^{(0)}(k)$ 使增长更接近指数,建模后取指数还原
- **非单调/震荡**:GM(1,1) 只能拟合指数型趋势,震荡数据改用 ARIMA(参见《时间序列与ARIMA模型》单元),不要硬套

## 🧮 公式与结论

### 参数估计(最小二乘)

把灰微分方程对 $k = 2, \dots, n$ 展开,写成矩阵形式 $Y = B\hat u$:

$$B = \begin{bmatrix} -z^{(1)}(2) & 1 \\ -z^{(1)}(3) & 1 \\ \vdots & \vdots \\ -z^{(1)}(n) & 1 \end{bmatrix}, \qquad Y = \begin{bmatrix} x^{(0)}(2) \\ x^{(0)}(3) \\ \vdots \\ x^{(0)}(n) \end{bmatrix}, \qquad \hat u = \begin{bmatrix} a \\ b \end{bmatrix}$$

最小二乘解(最小化 $\|Y - B\hat u\|^2$):

$$\hat u = (B^TB)^{-1}B^TY$$

### 时间响应式与累减还原

以 $x^{(0)}(1)$ 为初值解白化方程,得**时间响应式**:

$$\hat x^{(1)}(k+1) = \left(x^{(0)}(1) - \frac{b}{a}\right)e^{-ak} + \frac{b}{a}, \qquad k = 0, 1, 2, \dots$$

累减还原得原始序列的预测公式:

$$\hat x^{(0)}(k+1) = \hat x^{(1)}(k+1) - \hat x^{(1)}(k) = (1 - e^a)\left(x^{(0)}(1) - \frac{b}{a}\right)e^{-ak}$$

- 第一点恒有 $\hat x^{(0)}(1) = x^{(0)}(1)$(初值条件所致),其残差恒为 0
- 拟合时 $k = 0, \dots, n-1$;预测时取 $k \geq n$

### 精度检验公式

$$S_1 = \sqrt{\frac1n\sum_{k=1}^n \big(x^{(0)}(k) - \bar x\big)^2}, \qquad S_2 = \sqrt{\frac1n\sum_{k=1}^n \big(\varepsilon(k) - \bar\varepsilon\big)^2}, \qquad C = \frac{S_2}{S_1}$$

$$P = \frac1n\,\#\Big\{ k : \big|\varepsilon(k) - \bar\varepsilon\big| < 0.6745\, S_1 \Big\}$$

其中 $\varepsilon(k) = x^{(0)}(k) - \hat x^{(0)}(k)$ 为残差序列($0.6745\, S_1$ 约等于正态分布的四分位差带)。

### 发展系数的适用范围(刘思峰经验准则)

| $-a$ 范围 | 适用性 |
|-----------|--------|
| $-a \leq 0.3$ | 可用于中长期预测 |
| $0.3 < -a \leq 0.5$ | 短期预测 |
| $0.5 < -a \leq 0.8$ | 短期预测须谨慎 |
| $0.8 < -a \leq 1$ | 应做残差修正 |
| $-a > 1$ | 不宜使用 GM(1,1) |

## 💡 经典例题

### 例题 1:GM(1,1) 完整手算(核心例题)

> 某地新能源汽车保有量(万辆):$x^{(0)} = (5, 7, 10, 14)$。建立 GM(1,1),检验精度,并预测第 5 期。

**第一步:级比检验**。

$$\sigma = \left(\frac57, \frac{7}{10}, \frac{10}{14}\right) = (0.714, 0.700, 0.714)$$

$n = 4$,可容覆盖 $\left(e^{-2/5}, e^{2/5}\right) = (0.670, 1.492)$。全部级比落入界内 → 数据适合 GM(1,1) ✓。

**第二步:累加生成(AGO)与紧邻均值**。

$$x^{(1)} = (5,\ 12,\ 22,\ 36), \qquad z^{(1)} = (8.5,\ 17,\ 29)$$

**第三步:最小二乘估计**。构造矩阵:

$$B = \begin{bmatrix} -8.5 & 1 \\ -17 & 1 \\ -29 & 1 \end{bmatrix}, \qquad Y = \begin{bmatrix} 7 \\ 10 \\ 14 \end{bmatrix}$$

$$B^TB = \begin{bmatrix} 1202.25 & -54.5 \\ -54.5 & 3 \end{bmatrix}, \qquad B^TY = \begin{bmatrix} -635.5 \\ 31 \end{bmatrix}$$

$$\hat u = (B^TB)^{-1}B^TY = \frac{1}{636.5}\begin{bmatrix} 3 & 54.5 \\ 54.5 & 1202.25 \end{bmatrix}\begin{bmatrix} -635.5 \\ 31 \end{bmatrix} = \begin{bmatrix} -0.3409 \\ 4.1398 \end{bmatrix}$$

即 $a = -0.3409$,$b = 4.1398$。发展系数 $-a = 0.34 \in (0.3, 0.5]$ → 适合短期预测。

**第四步:时间响应式**。$b/a = -12.1429$,$x^{(0)}(1) - b/a = 17.1429$:

$$\hat x^{(1)}(k+1) = 17.1429\, e^{0.3409\,k} - 12.1429$$

**第五步:拟合与还原**。

| $k$ | $\hat x^{(1)}(k+1)$ | $\hat x^{(0)}(k+1)$ | 实际 $x^{(0)}(k+1)$ | 相对误差 |
|-----|---------------------|---------------------|---------------------|----------|
| 1 | 11.964 | 6.964 | 7 | 0.5% |
| 2 | 21.758 | 9.793 | 10 | 2.1% |
| 3 | 35.530 | 13.772 | 14 | 1.6% |
| 4(预测) | 54.897 | **19.367** | — | — |

平均相对误差 $= (0.5\% + 2.1\% + 1.6\%)/3 = 1.4\%$,拟合精度很高。

**第六步:后验差检验**。残差 $\varepsilon = (0, 0.036, 0.206, 0.228)$:

$$S_1 = 3.391, \qquad S_2 = 0.101, \qquad C = \frac{S_2}{S_1} = 0.030 < 0.35$$

$0.6745\, S_1 = 2.287$,全部 $|\varepsilon(k) - \bar\varepsilon| = (0.118, 0.082, 0.089, 0.110)$ 均小于它 → $P = 1 > 0.95$。

**结论**:$C$、$P$ 均达一级(优),模型可用于短期预测,第 5 期保有量预测为 **19.37 万辆**。

**解析**:这是 GM(1,1) 的完整骨架,国赛论文按这六步写就是满分结构。注意两个细节:①参数 $a, b$ 由**灰微分方程**的最小二乘得到,预测公式来自**白化方程**的解——两者之间存在离散化误差,所以拟合值并非精确等于实测;②预测值 19.37 与序列的指数外推一致($14 \times 1.4 \approx 19.6$),但 GM 给出的增长略慢,这是模型对短期波动「抹平」的结果。

### 例题 2:级比检验与适用性判断

> 两个序列:A = (30, 20, 28, 18, 26)(震荡),B = (40, 44, 48.5, 53.5, 59)(稳定增长)。判断哪个适合 GM(1,1)。

**序列 A** 的级比:$(30/20, 20/28, 28/18, 18/26) = (1.5, 0.714, 1.556, 0.692)$。$n = 5$,可容覆盖 $\left(e^{-2/6}, e^{2/6}\right) = (0.717, 1.396)$。$1.5$ 与 $1.556$ 越界 → 不通过;且序列非单调,指数曲线无从拟合。

**序列 B** 的级比:$(0.909, 0.907, 0.907, 0.907)$,全部在界内 → 通过。

**解析**:级比检验的本质是检查「相邻增长率是否稳定在一个不太离谱的范围」。B 的增长因子约 1.10,GM 的指数骨架能追上;A 上下跳动 50%,超出模型能力。**先用级比和散点图判断形态,再选模型**——这是竞赛里常被跳过的第一步,也是评委最看重的一步。

### 例题 3:GM(1,1) vs 一元线性回归(小样本对比)

> 用例题 1 的 4 个点 (5, 7, 10, 14)($t = 1..4$)分别做 GM(1,1) 与线性回归,比较拟合误差。

**GM(1,1)**:拟合值 (5, 6.96, 9.79, 13.77),平均相对误差 1.4%(例题 1 已算)。

**线性回归**:$\hat\beta_1 = 3$,$\hat\beta_0 = 1.5$,拟合值 (4.5, 7.5, 10.5, 13.5),逐点相对误差 (10.0%, 7.1%, 5.0%, 3.6%),平均 6.4%。

**解析**:指数型增长的序列,线性回归系统性低估早期、高估后期,平均误差是 GM 的 4.6 倍。且 $n = 4$ 时回归自由度只有 2,估计极不稳定;GM(1,1) 同样只估 2 个参数,却抓住了指数骨架。这就是国赛小样本预测题偏爱 GM(1,1) 的原因。**反过来**,若数据是线性趋势,GM(1,1) 也会失配(它只能拟合指数)——模型选择永远先于模型求解。

## ⚠️ 常见易错点

1. **不检查适用条件硬套**。负值数据无法支撑指数拟合,震荡数据必失败;先做级比检验与散点图,不过关就预处理或换模型
2. **忘记累减还原**。直接拿 $\hat x^{(1)}$ 的预测值当最终结果——差一个「累计」,量纲与数量级全错
3. **精度检验只报一个指标**。C 与 P 可能一个优一个勉强,两个都要报,再对照等级表下综合结论;平均相对误差也一起列出
4. **预测步数过多**。GM(1,1) 是指数外推,步数越多误差越大;竞赛中预测 3–5 期,并用级比/精度检验声明可信范围
5. **算完不看发展系数**。$-a > 0.5$ 还硬做中长期预测是硬伤;对照经验准则,必要时做残差修正或缩短预测期
6. **背景值用错**。灰微分方程里必须用紧邻均值 $z^{(1)}(k) = 0.5(x^{(1)}(k) + x^{(1)}(k-1))$,直接代入 $x^{(1)}(k)$ 是公式级错误

## ✏️ 自测练习

**第 1 题(推导)**:写出 GM(1,1) 中矩阵 $B$、$Y$ 的构造方式,并说明 $\hat u = (B^TB)^{-1}B^TY$ 最小化的是什么量。

<details><summary>查看答案</summary>

$B$ 的第 $k-1$ 行是 $\big(-z^{(1)}(k),\ 1\big)$,其中 $z^{(1)}(k) = 0.5(x^{(1)}(k) + x^{(1)}(k-1))$;$Y$ 的第 $k-1$ 个元素是 $x^{(0)}(k)$,$k = 2, \dots, n$。最小二乘解最小化的是残差平方和 $\|Y - B\hat u\|^2 = \sum_{k=2}^n \big(x^{(0)}(k) + a z^{(1)}(k) - b\big)^2$,即让灰微分方程在数据点上「尽量成立」。

</details>

**第 2 题(计算)**:对纯几何序列 $x^{(0)} = (3, 6, 12, 24)$(即 $x(k) = 3 \cdot 2^{k-1}$)做累加生成,写出 $x^{(1)}$ 与 $z^{(1)}$;若进一步估计得 $a = -2/3$,$b = 2$,与真实增长率 $\ln 2 \approx 0.693$ 相比说明了什么?

<details><summary>查看答案</summary>

$x^{(1)} = (3, 9, 21, 45)$,$z^{(1)} = (6, 15, 33)$。估计的发展系数 $-a = 2/3 \approx 0.667$,比真实增长率 $\ln 2 \approx 0.693$ 低约 4%;拟合值 (3, 5.69, 11.08, 21.57) 逐点相对误差 (5.2%, 7.7%, 10.1%) 逐渐增大。说明**即使数据是完美指数序列,GM(1,1) 也因灰微分方程与白化方程之间的离散化误差而无法精确还原**,误差随 $k$ 累积——这正是限制预测步数的原理性原因。

</details>

**第 3 题(判断)**:某模型检验得 $C = 0.30$,$P = 0.90$,平均相对误差 4.5%。综合精度属于什么等级?

<details><summary>查看答案</summary>

**二级(合格)**。$C = 0.30 < 0.35$ 达到一级标准,但 $P = 0.90$ 只达到 $P > 0.80$ 的二级标准(一级要求 $P > 0.95$)。等级判定应取**较差的指标**:综合为二级(合格)。这个陷阱考的是「两指标都要看」。

</details>

**第 4 题(概念)**:为什么 GM(1,1) 要求数据非负且单调?不满足时有哪些补救?

<details><summary>查看答案</summary>

GM(1,1) 用一阶线性微分方程描述累加序列,其解是指数型单调曲线,因此原始数据必须呈现单调的指数/近似指数形态;累加序列需要参与紧邻均值和指数运算,负值或正负交错会使估计失真。补救:增长过快做平移变换;波动大取对数;震荡数据改用 ARIMA 或灰色 Verhulst;预测目标本身非单调时,GM(1,1) 不是合适工具。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:国赛「预测」类题目最高频模型。典型场景:人口、用水量、能耗、污染物浓度、销量预测,题目只给 5–10 年数据
- **论文写法(模板级)**:①适用性论证(级比检验表)→ ②建模(AGO → 构造 B/Y → 最小二乘,公式写全)→ ③精度检验(C、P、平均相对误差三个指标,对照等级表)→ ④预测 3–5 期 → ⑤与 ARIMA/回归对比,说明为什么选 GM
- **加分点**:①**新陈代谢 GM(1,1)**:每预测一期就把最新实测值加入序列、去掉最老数据滚动重估,可显著提高多步预测精度,是国赛论文的经典亮点;②**残差 GM(1,1) 修正**:对残差序列再建一个 GM,处理 $-a$ 偏大的情形;③画出原始数据与拟合曲线的对比图,直观展示精度
- **注意**:评委对「只用一个 GM(1,1)」的论文已有审美疲劳。把 GM 作为**基准模型之一**,再上 ARIMA、回归、神经网络做对比,论文更立体

## 💻 代码实现

```python
import numpy as np

def gm11(x0, steps=3):
    """GM(1,1) 建模:输入非负单调序列 x0,返回参数、拟合值、预测值与精度指标。"""
    x0 = np.asarray(x0, dtype=float)
    x1 = np.cumsum(x0)                          # 累加生成 AGO
    z = 0.5 * (x1[1:] + x1[:-1])                # 紧邻均值(背景值)
    B = np.column_stack([-z, np.ones_like(z)])
    Y = x0[1:]
    a, b = np.linalg.lstsq(B, Y, rcond=None)[0] # 最小二乘 (a, b)

    k = np.arange(0, len(x0) + steps)
    x1_hat = (x0[0] - b / a) * np.exp(-a * k) + b / a   # 时间响应式
    x0_hat = np.diff(np.r_[x0[0], x1_hat])              # 累减还原

    fit, pred = x0_hat[:len(x0)], x0_hat[len(x0):]
    res = x0 - fit
    S1 = x0.std(); S2 = res.std()
    C = S2 / S1
    P = (np.abs(res - res.mean()) < 0.6745 * S1).mean()
    rel = np.abs(res[1:]) / x0[1:]              # 第一点残差恒为 0,不参与
    return a, b, fit, pred, C, P, rel.mean()

a, b, fit, pred, C, P, mape = gm11([5, 7, 10, 14], steps=3)
print(f"a = {a:.4f}, b = {b:.4f}")             # a=-0.3409, b=4.1398
print(f"拟合 = {fit.round(3)}  预测 = {pred.round(3)}")   # 预测 19.367, ...
print(f"C = {C:.3f}  P = {P:.3f}  平均相对误差 = {mape*100:.2f}%")
```

> 使用注意:①输入必须为正且单调;②输出是**累减还原后**的原始量纲;③预测步数超过 3 时,考虑用「新陈代谢」方式滚动更新数据再预测。

## 🧠 小结

1. GM(1,1) 的价值在小样本:4–10 个数据点、单调趋势、短期预测,三个条件缺一不可
2. 流程六步:级比检验 → 累加生成 → 构造 B/Y 最小二乘估 $(a,b)$ → 时间响应式 → 累减还原 → 精度检验
3. 精度检验报全:C、P、平均相对误差三件套,对照等级表综合下结论(取较差指标)
4. 发展系数是「体检报告」:$-a \leq 0.3$ 放心做,$-a > 0.5$ 要谨慎或残差修正
5. 国赛使用姿势:GM(1,1) 打底 + 新陈代谢滚动 + 与 ARIMA/回归对比,论文结构完整、结论可信
