## 📖 核心概念

### 1. 为什么要组合:单模型总有短板

| 单模型的典型短板 | 组合的思路 |
|----------------|-----------|
| 机理模型精度不足(参数难定) | 用数据驱动模型修正残差 |
| 统计模型外推能力弱 | 用机理模型约束长期趋势 |
| 单一模型对局部结构不敏感 | 多个局部模型分而治之 |
| 单次拟合方差大、不稳定 | 多个独立估计取平均 |

> 💡 **建模心法**:组合的前提是**基模型之间互补**——一个擅长全局、一个擅长局部,一个偏机理、一个偏数据,一个快、一个准。两个几乎相同的模型取平均,几乎不会带来任何改进(公式节给出定量证明)。

### 2. 三种组合模式

- **串联(流水线)**:模型 A 的输出 → 模型 B 的输入。经典例:灰色预测 GM(1,1) 把握长期趋势 → ARIMA 对残差再建模(参见《灰色预测》《时间序列与ARIMA》单元);需求预测 → 排队/调度优化(预测出的 $\lambda$ 直接决定开几个窗口)。风险是**误差沿链条传播放大**
- **并联(集成)**:多个模型对同一对象独立预测 → 加权平均或投票。经典例:熵权法确定权重的多模型综合评价;时间序列多模型平均;机器学习中的 Bagging。收益来自**方差下降**,前提是误差相关性低
- **嵌套**:一个模型的参数由另一个模型确定。经典例:机理模型(如热传导 PDE)的参数由智能算法标定(参见《遗传算法(GA)》单元);优化模型的约束由预测模型提供

### 3. 误差分解:MSE = 偏差² + 方差

$$\text{MSE} = \mathbb{E}\big[(\hat{y} - y)^2\big] = \underbrace{(\mathbb{E}[\hat{y}] - y)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}\big[(\hat{y} - \mathbb{E}[\hat{y}])^2\big]}_{\text{Variance}}$$

- **偏差**:模型的平均预测离真值多远——「准不准」
- **方差**:每次拟合结果波动多大——「稳不稳」
- **组合(平均)几乎不改变偏差,但能压方差**——这是并联集成的全部数学依据;Boosting 则反过来,串行修正偏差

### 4. 机器学习集成与竞赛组合的对应

| 集成方法 | 思路 | 数学建模场景 |
|---------|------|-------------|
| **Bagging** | 自助采样训练多个模型 → 平均 | 多次采样拟合取均值,压方差 |
| **Boosting** | 串行训练,后者修正前者残差 | 「预测 + 残差修正」串联结构 |
| **Stacking** | 基模型输出 → 元模型融合 | 用留出集训练最优权重 |

注意:竞赛论文不必堆术语,关键是把「为什么这么组合、组合后指标改善多少」讲清楚;套用集成思想解决赛题问题,比报一堆算法名字有价值得多。

## 🧮 公式与结论

### 等权平均的方差公式(组合有效性的判据)

两个误差方差分别为 $\sigma_1^2, \sigma_2^2$、相关系数为 $\rho$ 的无偏模型,等权平均的方差:

$$\mathrm{Var}\left(\frac{\hat{y}_1 + \hat{y}_2}{2}\right) = \frac{\sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2}{4}$$

- $\rho = 0$ 且 $\sigma_1 = \sigma_2 = \sigma$:方差降为 $\sigma^2/2$——**两个独立模型平均,方差减半**
- $\rho = 1$(两个相同模型):方差不变——**同质模型组合无效**
- 一般结论:相关性越低、方差越接近,组合收益越大

### 并联的最优权重(逆方差加权)

误差互不相关的 $m$ 个模型,权重 $w_i \ge 0$、$\sum w_i = 1$,使组合方差最小的权重:

$$w_i = \frac{1/\sigma_i^2}{\sum_{j} 1/\sigma_j^2} \propto \frac{1}{\sigma_i^2}$$

即**方差越小的模型权重越大**。若误差相关,需用协方差矩阵 $\Sigma$ 求一般解:

$$w^* = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^T\Sigma^{-1}\mathbf{1}},\qquad \sigma_{\min}^2 = \frac{1}{\mathbf{1}^T\Sigma^{-1}\mathbf{1}}$$

(推导:拉格朗日乘子法最小化 $w^T\Sigma w$ 约束 $\mathbf{1}^T w = 1$。)

### Stacking 的线性元模型

基模型预测 $f_1(x), \dots, f_m(x)$,元模型取线性加权 $\hat{y} = \sum_{k=1}^{m} w_k f_k(x)$,**权重必须在基模型没见过的留出集上训练**(或用交叉验证),否则元模型会「奖励过拟合的基模型」。

### 串联结构的误差传播

若模型 B 的输入是模型 A 的输出,且 B 对输入敏感,则 A 的误差会被 B 放大。最简单的定量刻画(一阶近似):

$$\Delta y_B \approx \left|\frac{dy_B}{dx_A}\right|\cdot \Delta x_A$$

因此串联链条必须做**鲁棒性分析**:上游输入上下浮动 ±10%/±20%,看下游决策是否改变。

## 💡 经典例题

### 例题 1:并联平均的误差分析(何时组合有效)

> 两个预测模型误差独立,但特性不同:模型 A 偏差 2、方差 1;模型 B 偏差 1、方差 3。单独使用与等权平均,哪种误差最小?若两模型误差相关系数 $\rho = 0.9$,结论还成立吗?

**第一步:单独使用的 MSE**。由 MSE = Bias² + Var:

- 模型 A:MSE = $2^2 + 1 = 5$
- 模型 B:MSE = $1^2 + 3 = 4$(单独用 B 更好)

**第二步:等权平均**($\rho = 0$)。平均模型的偏差 = 两偏差的平均 = 1.5;方差:

$$\mathrm{Var} = \frac{1 + 3 + 0}{4} = 1 \ \Rightarrow\ \text{MSE} = 1.5^2 + 1 = 3.25 < 4$$

**结论**:组合模型 MSE 3.25,优于两个单模型——尽管 A 单独看比 B 差,组合仍受益,因为方差从 3 压到了 1。

**第三步:高相关情形**($\rho = 0.9$):

$$\mathrm{Var} = \frac{1 + 3 + 2\times 0.9\times\sqrt{3}}{4} = \frac{4 + 3.118}{4} = 1.779 \ \Rightarrow\ \text{MSE} = 2.25 + 1.779 = 4.03 > 4$$

**结论反转**:相关性太高时,组合的 MSE(4.03)反而**比单独用 B(4)更差**。

**解析**:这道题给出一正一反两个判据:组合收益来自「方差下降」,而方差下降的前提是「误差不太相关」。竞赛中检验基模型误差的相关性(散点图 + 相关系数),是决定「该不该组合、怎么组合」的第一步,也是论文里最有力的论证。

### 例题 2:串联组合与误差传播(预测 → 排队 → 决策)

> 某医院计划按「需求预测 → 排队优化」串联建模:先用时间序列预测上午高峰就诊到达率 $\hat{\lambda} = 60$ 人/小时,再由排队论(参见《排队论建模》单元)确定窗口数。每个窗口服务率 $\mu = 25$ 人/小时,窗口成本 5 元/小时/台,顾客等待成本 10 元/小时/人。①求最优窗口数;②若预测偏差 ±20%,最优决策变不变?

**①基准情形**($\lambda = 60$):由排队论单元例题 3 的 M/M/c 计算:

| 窗口数 $c$ | 3 | 4 | 5 |
|-----------|---|---|---|
| 总成本 $C(c) = 5c + 10L$ | 64.9 | **48.3** | 50.0 |

最优 $c^* = 4$。

**②鲁棒性检验**:$\lambda = 72$(高估 20%情形):同法计算,得 $C(4) = 60.6$,$C(5) = 56.6$,最优变为 $c^* = 5$;$\lambda = 48$(低估 20%情形):$C(3) = 33.9$,$C(4) = 34.1$,$C(5) = 36.2$,最优变为 $c^* = 3$。

**结论**:预测偏差 ±20% 都会改变最优窗口数——串联链条对上游误差敏感,「预测错了窗口就白开了」。

**解析**:串联建模的完整论证结构:①上游模型给出输出(带置信区间);②下游模型在最优点附近做**敏感性/鲁棒性分析**;③给出「当 $\lambda$ 落在哪个区间,应开几个窗口」的分段决策表。这道题也演示了「机理 + 数据」的组合范式:预测解决「多少人会来」,排队论解决「该配多少资源」,各司其职。

### 例题 3:Stacking 的最小数值示例(手算权重)

> 回归任务:基模型 A 预测为 $[2.0,\ 3.0,\ 4.0]$,基模型 B 预测为 $[2.8,\ 2.9,\ 3.0]$,真实值为 $[2.4,\ 2.8,\ 3.2]$。①求等权平均的 MSE;②在留出集上求最优线性权重 $w$($\hat{y} = w\hat{y}_A + (1-w)\hat{y}_B$)与对应 MSE。

**①等权平均**:预测 $[2.4,\ 2.95,\ 3.5]$,误差 $[0,\ 0.15,\ 0.3]$:

$$\text{MSE} = \frac{0^2 + 0.15^2 + 0.3^2}{3} = \frac{0.0225 + 0.09}{3} = 0.0375$$

(单独 A 的 MSE 为 0.28,B 为 0.07——等权平均 0.0375 已优于两者。)

**②最优权重**:组合预测 $\hat{y} = w\hat{y}_A + (1-w)\hat{y}_B$ 的误差平方和:

$$\text{SSE}(w) = (0.4 - 0.8w)^2 + (0.1 + 0.1w)^2 + (w - 0.2)^2$$

展开:$0.21 - 1.02w + 1.65w^2$。令导数为零:$-1.02 + 3.3w = 0 \Rightarrow w^* = 0.3091$。

$$\text{MSE}(w^*) = \frac{0.0524}{3} = 0.0175 < 0.0375$$

**结论**:元模型把 MSE 从 0.0375 进一步压到 0.0175。权重 $w^* = 0.309$ 说明 B(方差小)获得更大权重,与逆方差加权的方向一致。

**解析**:必须强调——这个 $w^*$ 是在**同一个小样本**上调出来的,真实竞赛中调权必须用基模型未见过的留出集,否则元模型只是「记住了这几个点的噪声」,泛化能力反而更差(本题样本若换成新的三点,$w^*$ 会漂移)。Stacking 的正确姿势:数据切三块——训练基模型、留出集训练元模型、测试集评估。

## ⚠️ 常见易错点

1. **基模型同质,组合无效**。两个同类型、同数据、同假设的模型(如两个线性回归)误差高度相关,平均几乎无收益——例题 1 的 $\rho = 0.9$ 情形甚至更差;先做误差相关性分析再决定是否组合
2. **用训练集误差调权重**。在基模型见过的数据上选最优权重 = 泄漏 = 过拟合;必须留出集或交叉验证,否则「组合模型在训练集上无敌、测试集上翻车」
3. **串联链条不做误差传播分析**。上游预测差 20%,下游决策可能翻盘(例题 2);论文必须给出分段决策表或鲁棒性区间,而不是一个孤零零的点估计
4. **堆砌模型讲不清逻辑**。「我们用了灰色预测 + BP 神经网络 + ARIMA + 随机森林的组合」而不解释互补性,评委只会认为在凑字数;每个基模型要写明「负责哪一部分」(趋势/细节/非线性/残差)
5. **评价指标不统一**。基模型用 RMSE、组合模型用 MAPE、最后又报 $R^2$,无法公平对比;全程统一指标,并给组合前后对比表
6. **忽略数据划分的一致性**。基模型训练、元模型训练、测试必须用同一套划分;不同基模型用了不同划分,权重比较就失去了公平基础

**第 1 题** 把同一个模型在同一份数据上拟合两次,再取平均,预测误差会减半吗?

A. 不会。同模型同数据的两次拟合误差相关系数 $\rho \approx 1$,由方差公式 $\mathrm{Var} = \dfrac{\sigma^2 + \sigma^2 + 2\sigma^2}{4} = \sigma^2$,方差不变
B. 会。两次独立拟合取平均,方差降为 $\sigma^2/2$
C. 会。平均两次方差降为 $\sigma^2/4$,平均次数越多降得越多
D. 会。只要拟合次数足够多,方差可以任意接近 0

<details><summary>查看答案与解析</summary>
**答案:A**。组合收益来自基模型**有差异且误差不相关**:等权平均方差 $\mathrm{Var} = \frac{\sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2}{4}$,同模型同数据时 $\rho \approx 1$、$\sigma_1 = \sigma_2$,代入得 $\frac{\sigma^2+\sigma^2+2\sigma^2}{4} = \sigma^2$——**方差纹丝不动**。选项 B 把「误差独立」的前提套到了「同模型」上($\rho=0$ 公式);选项 C 是「平均两次减半、再平均再减半」的想当然;选项 D 更极端——同质模型平均一万次也还是同一个估计,方差不会趋零(趋零的前提是**独立**的估计,而 Bagging 之所以有效,正是因为自助采样使各基模型产生了差异)。竞赛中的第一步永远是检验基模型误差的相关性(散点图 + 相关系数),再决定「该不该组合、怎么组合」。
</details>

**第 2 题** 两个无偏预测模型,误差方差都是 $\sigma^2$。等权平均后的方差是(记两模型误差相关系数为 $\rho$):

A. $\rho = 0$ 时 $\dfrac{\sigma^2}{2}$;$\rho = 0.5$ 时 $\dfrac{3\sigma^2}{4}$
B. $\rho = 0$ 时 $\dfrac{\sigma^2}{4}$;$\rho = 0.5$ 时 $\dfrac{\sigma^2}{2}$
C. $\rho = 0$ 时 $\dfrac{\sigma^2}{2}$;$\rho = 0.5$ 时仍是 $\dfrac{\sigma^2}{2}$(相关性不影响平均方差)
D. $\rho = 0$ 时 $\sigma^2$;$\rho = 0.5$ 时 $1.25\sigma^2$(平均反而更差)

<details><summary>查看答案与解析</summary>
**答案:A**。等权平均方差公式 $\mathrm{Var} = \frac{\sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2}{4}$,代入 $\sigma_1 = \sigma_2 = \sigma$:$\rho = 0$ 时 $\mathrm{Var} = \frac{\sigma^2 + \sigma^2}{4} = \frac{\sigma^2}{2}$;$\rho = 0.5$ 时 $\mathrm{Var} = \frac{\sigma^2 + \sigma^2 + \sigma^2}{4} = \frac{3\sigma^2}{4}$。两个**独立**模型平均方差减半(标准差降为 $1/\sqrt{2}$);相关度 0.5 时只降 25%——相关性吃掉了组合收益的一半。选项 B 忘了分母是 4(把「方差减半」又减半了一次);选项 C 忽略了交叉项 $2\rho\sigma_1\sigma_2$ 的贡献;选项 D 把 $\rho=0$ 的公式也算错,且「平均更差」只会在 $\rho$ 很高且方差悬殊时出现(如两个方差相同的模型,$\rho < 1$ 时平均方差恒不大于 $\sigma^2$)。一般结论:相关性越低、方差越接近,组合收益越大。
</details>

**第 3 题** 三个误差互不相关的预测模型,误差方差分别为 $\sigma_1^2 = 4$、$\sigma_2^2 = 9$、$\sigma_3^2 = 16$。按逆方差加权的最优权重是:

A. $w = \left(\dfrac{36}{61},\ \dfrac{16}{61},\ \dfrac{9}{61}\right) \approx (0.590,\ 0.262,\ 0.148)$——方差越小的模型权重越大
B. $w = \left(\dfrac{9}{61},\ \dfrac{16}{61},\ \dfrac{36}{61}\right) \approx (0.148,\ 0.262,\ 0.590)$
C. $w \approx (0.461,\ 0.308,\ 0.231)$
D. $w = (1/3,\ 1/3,\ 1/3)$

<details><summary>查看答案与解析</summary>
**答案:A**。误差互不相关时,使组合方差最小的权重为 $w_i \propto \frac{1}{\sigma_i^2}$:$\frac{1}{4} + \frac{1}{9} + \frac{1}{16} = \frac{36+16+9}{144} = \frac{61}{144}$,故 $w_1 = \frac{1/4}{61/144} = \frac{36}{61} \approx 0.590$、$w_2 = \frac{16}{61} \approx 0.262$、$w_3 = \frac{9}{61} \approx 0.148$。权重和为 1,方差最小的模型(σ²=4)拿到最大权重——「谁的误差小,就多听谁的」。选项 B 把「方差小权重大」的方向搞反;选项 C 是**按标准差倒数**加权($1/2, 1/3, 1/4$ 归一化)的结果,把最优公式里的方差换成了标准差;选项 D 是等权——等权只在各方差相等时才是最优。若误差相关,需用协方差矩阵的一般解 $w^* = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^T\Sigma^{-1}\mathbf{1}}$;权重必须在基模型没见过的**留出集**上估计,否则会奖励过拟合的基模型。
</details>

## 💻 代码实现

```python
import numpy as np

# ---- 并联最优权重(误差协方差已知) ----
Sigma = np.array([[1.0, 0.5], [0.5, 3.0]])   # 方差 1 和 3,协方差 0.5
ones = np.ones(2)
w = np.linalg.inv(Sigma) @ ones / (ones @ np.linalg.inv(Sigma) @ ones)
print("最优权重:", np.round(w, 3))
print("最优方差:", 1 / (ones @ np.linalg.inv(Sigma) @ ones))
w_eq = np.array([0.5, 0.5])
print("等权方差:", w_eq @ Sigma @ w_eq)

# ---- 例题3: Stacking 最小示例(留出集上求线性元模型权重) ----
A = np.array([2.0, 3.0, 4.0])
B = np.array([2.8, 2.9, 3.0])
y = np.array([2.4, 2.8, 3.2])

# SSE(w) = ||w*A + (1-w)*B - y||^2,展开为 aw^2 + bw + c
a = np.sum((A - B)**2)
b = 2 * np.sum((A - B) * (B - y))
w_star = -b / (2 * a)
pred = w_star * A + (1 - w_star) * B
print(f"最优权重 w* = {w_star:.4f}")
print("等权 MSE:", np.mean((0.5*A + 0.5*B - y)**2))
print("Stacking MSE:", np.mean((pred - y)**2))

# ---- 误差相关性与方差下降的关系 ----
sigma2 = 1.0
for rho in [0.0, 0.3, 0.6, 0.9, 1.0]:
    var_avg = sigma2 * (1 + rho) / 2
    print(f"rho={rho}: 平均后方差 = {var_avg:.3f} (单模型 1.0)")
```

## 🧠 小结

1. 组合三模式:串联(流水线,注意误差传播)、并联(集成,收益来自方差下降)、嵌套(参数互馈)
2. 组合有效性的两个判据:MSE = Bias² + Var 说明平均压方差;方差公式里的 $\rho$ 说明**相关性低才有收益**,同质模型组合白费力气
3. 并联最优权重 = 逆方差加权;误差相关时用协方差矩阵的二次型解(公式已给,可直接写进论文)
4. Stacking 的关键纪律:基模型、元模型、测试集**三段数据划分**,权重绝不可以在基模型的训练集上调
5. 串联链条必做鲁棒性分析:上游 ±20%,下游决策变不变?给出分段决策表,比单一结论高一个档次
