## 📖 核心概念

### 1. 选型第一步:问自己五个问题

拿到优化问题,先**别想算法**,先回答:

1. **变量是连续还是离散?** 连续 → PSO/DE/SA;组合 → GA/ACO/SA/禁忌搜索
2. **有没有已知的精确算法?** 指派/运输/网络流 → 匈牙利/单纯形(见《0-1规划与指派问题》单元);中小规模 MIP → `milp`。**精确算法能用就不要上启发式**
3. **目标几个?** 多目标 → NSGA-II(见《多目标优化与NSGA-II》单元)
4. **问题结构特殊吗?** 路径/排序类组合 → 蚁群有天然优势;可微 → 优先梯度方法
5. **规模与时限?** 预算内能跑多少评估次数,决定种群/迭代规模

### 2. 算法速查表

| 问题特征 | 推荐算法 | 理由 |
|----------|----------|------|
| TSP / 路径类组合 | ACO(首选)、GA | ACO 的正反馈专为「边选择」设计 |
| 调度、排序、装箱 | GA、禁忌搜索 | 编码灵活、可嵌局部搜索 |
| 连续低维光滑 | PSO、DE | 收敛快、实现简单 |
| 连续高维/深多峰 | DE、GA(实数编码) | PSO 高维易早熟,SA 步长难调 |
| 多目标 | NSGA-II | 精英保留 + 拥挤度,一次得整片前沿 |
| 大规模 + 复杂约束 | GA + 罚函数/修复 | 编码天然容纳约束,种群并行 |
| 需要最优性证明 | 分支定界 / milp | 启发式给不了证明 |

> 💡 **无免费午餐(NFL)定理**:对所有问题平均而言,任何算法的表现都一样。所以「我的算法最好」永远是伪命题——正确说法是「**在这类问题上**,A 算法优于 B」。这句话就是本单元全部内容的一句话总结。

### 3. 公平对比五条军规

1. **统一预算**:比较按「评估次数」或「CPU 时间」计,不是按「迭代数」(一次 GA 迭代 = 100 次评估,一次 SA 迭代 = 1 次评估,直接比迭代数必输无疑)
2. **统一调优工作量**:要么双方都用默认参数,要么双方都花同样的调参时间;只调自己算法的参数 = 作弊
3. **多次独立运行**:20–30 次起,报告均值 ± 标准差 + 最优/最差;单次运行是轶事,不是实验
4. **统计检验**:成对比较用 Wilcoxon 符号秩检验(不要求正态),给出 p 值与显著性水平
5. **参照物**:有精确解就比 gap;没有就比「各算法相互对照 + 已知下界」

### 4. 约束处理三件套

- **罚函数**:目标 $f$ 改为 $f + \lambda \sum_k \max(0, g_k(x))^2$。实现最简单,但 $\lambda$ 难调:太小 → 不可行解泛滥;太大 → 可行域被「罚墙」扭曲,好解进不去。改进:动态罚($\lambda$ 随代数增大)、自适应罚(按种群可行率调节)
- **修复**:把不可行解修回可行域(如背包超重就按性价比依次剔除)。保持「解总是可行」,但修复过程本身要算进评估成本
- **编码保可行**:设计编码与算子让解永不越界(排列编码 + PMX 交叉),从源头消灭不可行解——**优先级最高**的方案

## 🧮 公式与结论

### 罚函数的标准形式

$$\min\ F(x) = f(x) + \lambda\left[\sum_k \max(0, g_k(x))^2 + \sum_l h_l(x)^2\right]$$

- 不等式违例 $g_k(x) > 0$ 与等式违例 $h_l(x) \neq 0$ 统一折成平方惩罚
- **动态罚**思路:初期 $\lambda$ 小(允许探索不可行区,可能有捷径),后期 $\lambda$ 大(强制收敛到可行域);竞赛中「自适应罚」更好写论文

### 报告模板(照抄级)

| 算法 | 预算 | 均值 ± 标准差 | 最优 | 最差 | 达标率 |
|------|------|---------------|------|------|--------|
| ACO | 1000 evals | $0.00\% \pm 0.00\%$ | 0.00% | 0.00% | 10/10 |

再加三张图:收敛曲线(均值带 ± 1 标准差阴影)、最终解分布箱线图、可行率曲线(带罚函数时)。**「达标率」= 达到预设精度(如 gap ≤ 1%)的运行占比**,比均值更能说明算法的「可靠性」。

## 💡 经典例题

### 例题 1:选型决策练习(四个场景)

> 按「五个问题」流程为以下场景选算法并说明理由。

| 场景 | 分析 | 选择 |
|------|------|------|
| ① 1000×1000 指派,要最优解 | 指派全幺模,匈牙利 $O(n^3) \approx 10^9$ 勉强可算 | 匈牙利算法,不上启发式 |
| ② 50 城 TSP,求 1 小时内最好解 | 组合、路径类,精确解不现实 | ACO 或 GA + 2-opt 局部搜索 |
| ③ 10 维不可微函数参数拟合 | 连续、无梯度可用 | PSO 或 DE |
| ④ 选址问题:成本低 + 覆盖广 | 双目标冲突 | NSGA-II 求前沿 + TOPSIS 选方案 |

**解析**:四个场景的**否决逻辑**依次是:①「有精确算法」(否决所有启发式);②「路径结构」(倾向 ACO);③「不可微」(否决梯度法);④「多目标」(否决一切单目标算法)。先列否决项,再在剩余候选中按实现成本选——这就是选型的完整思维链。

### 例题 2:TSP 对比实验(真实数据,组合优化战场)

> 15 城 TSP(精确最优 3.5184,由 Held-Karp 算法求得)。三算法同台:ACO(10 蚁 × 100 轮,预算 1000 次评估)、GA(种群 50 × 100 代,预算 4650)、SA(swap 邻域,预算 5000)。各独立运行 10 次:

| 算法 | 预算(评估数) | 平均 gap | 最小 gap | 达 1% 精度所需评估数(中位) |
|------|-------------|----------|----------|---------------------------|
| ACO | 1000 | **0.00%** | 0.00% | **205** |
| GA | 4650 | 6.47% | 0.00% | 3477 |
| SA(swap) | 5000 | 9.62% | 0.00% | 1116 |

**解析**:结论链:①ACO 平均 gap 为 0 且预算最小——**均值和可靠性双胜**;②GA/SA 的最好成绩也能中 0.00%,但均值暴露了它们的方差——**只看最好成绩会得出「三算法打平」的错误结论**;③SA 的短板在邻域(swap 破坏 4 条边),换 2-opt 后另测(体现「公平 + 诚实」)。论文里这张表 + 三行解析,比十页算法流程描述都值钱。

### 例题 3:连续函数对比(真实数据,换战场再看)

> 10 维 Ackley 与 Rastrigin,PSO(50 粒子)vs SA(高斯扰动),统一预算 50000 次评估,各 30 次独立运行:

| 测试函数 | PSO 均值 ± 标准差 | SA 均值 ± 标准差 | 结论 |
|----------|-------------------|------------------|------|
| Ackley($f^*=0$) | **0.0000 ± 0.0000** | 3.53 ± 0.21 | PSO 碾压 |
| Rastrigin($f^*=0$) | **4.15 ± 1.91** | 48.2 ± 6.6 | PSO 胜,但两败俱伤 |

**解析**:连续光滑问题上 PSO 完胜——粒子群的梯度式牵引正好匹配 Ackley 的单峰盆地结构。但到了深多峰 Rastrigin,**两个算法都远离最优**,PSO 只是「输得好看」。结论:①选型必须看问题特征,「赢一次不代表永远赢」;②深多峰问题上别恋战,换 DE、多种群或混合算法,并在论文里承认当前方法的局限(诚实反而是加分项)。

## ⚠️ 常见易错点

1. **按迭代数而非评估数对比**。GA 一代 = 种群数 × 评估;SA/PSO 一步 = 1 次评估。不换算预算,对比结论全错
2. **只报最好成绩**。随机算法的最好成绩 ≈ 运气;均值 ± 标准差 + 达标率才是「算法能力」的度量
3. **只调自己的参数**。对比双方要么都用默认参数,要么声明调参工作量相同;「我的算法精调过,对手用默认」是典型的论文硬伤
4. **没给精确解或下界,就宣称「求得最优」**。没有参照物只能写「与已知最优/其它算法的相对表现」;有精确解就报 gap
5. **罚系数拍脑袋且不报告**。$\lambda$ 是罚函数法的核心参数,应给出取值依据(动态策略或敏感性分析);$\lambda$ 过大过小都会毁掉搜索
6. **先选算法后看问题**。套用「上一届论文用的 GA」是最常见的错误;先答五个问题、先查精确算法,选型理由要写进论文

## ✏️ 自测练习(选择题)

**第 1 题**20 城 TSP,要求在 1 小时内给出尽可能好的解。最合适的算法选型是:

A. 匈牙利算法(多项式时间精确求解)
B. ACO 或 GA + 2-opt 局部搜索(组合路径类,精确解不现实)
C. 梯度下降(路径问题可微)
D. 单纯形法(LP 建模求解)

<details><summary>查看答案与解析</summary>
**答案:B**。选型五问第一问:有没有已知的精确算法?TSP 的精确算法(Held-Karp 动态规划)在 $n=20$ 时约 $2^{20}$ 量级,勉强可算但只用于验证启发式,1 小时内求精确解不现实。TSP 是路径类组合问题,ACO 的正反馈天然契合「边选择」,GA + 2-opt 也是成熟方案。匈牙利算法只适用于指派问题,不能解 TSP;路径问题不可微,梯度下降无从谈起;TSP 不是线性规划,单纯形法不适用。精确算法能用就不要上启发式;精确算法不现实时,选对问题结构的启发式。
</details>

**第 2 题**对比 GA 与 SA 求解同一问题时,为什么不能直接比较「迭代数」?

A. 因为 GA 的收敛曲线不是单调的,SA 是单调的
B. 因为 SA 的迭代含随机性,GA 不含
C. 因为一次 GA 迭代 = 种群规模次目标评估,一次 SA 迭代 = 1 次评估,预算口径不同
D. 因为 GA 每代都有交叉变异,SA 没有

<details><summary>查看答案与解析</summary>
**答案:C**。一次 GA 迭代要评估整个种群(如 100 个个体),而 SA/PSO 一步只评估 1 个解——直接比迭代数,GA 必输无疑。公平对比要统一预算:按**评估次数**或 CPU 时间计。另两条军规:统一调参工作量(只调自己算法的参数等于作弊)、多次独立运行 + 均值 ± 标准差 + 统计检验(Wilcoxon 等)。「收敛曲线单调性」「随机性有无」都不是预算口径问题的答案。
</details>

**第 3 题**用 GA 求解带约束优化问题时,处理约束的三种手段中,优先级最高(应最先考虑)的是:

A. 设计编码与算子,使解从源头保持可行(如排列编码 + PMX 交叉)
B. 罚函数:目标加 $\lambda \sum \max(0, g_k(x))^2$
C. 修复:把不可行解修回可行域
D. 忽略约束,最后在可行解中挑一个

<details><summary>查看答案与解析</summary>
**答案:A**。优先级:编码保可行 > 修复 > 罚函数。编码保可行从源头消灭不可行解,没有额外评估成本,是最干净的方案;修复保持「解总是可行」,但修复过程要计入评估成本;罚函数实现最简单,但 $\lambda$ 难调——太小不可行解泛滥,太大可行域被「罚墙」扭曲。「忽略约束最后再挑」是最危险的做法:搜索过程被不可行区带偏,最后往往没有可行解可挑。
</details>

## 🏆 竞赛实战链接

- **评分逻辑**:评委看的是「**为什么选这个算法**」与「**怎么证明它好**」,而不是算法代码多长。选型理由(五个问题)+ 公平对比表 + 统计检验,是实验章节的三段论
- **高频组合技**:①启发式求初始解 → 精确算法(如 milp)用热启动求最优/gap;②GA 全局 + SA/2-opt 局部(Memetic);③多算法求前沿对比 → NSGA-II

## 💻 代码实现

```python
import numpy as np
rng = np.random.default_rng(2026)
D, POP, BUDGET, RUNS = 10, 50, 50000, 10   # 统一预算,统一运行次数

def ackley(x):
    d = len(x)
    return (-20 * np.exp(-0.2 * np.sqrt(np.sum(x * x) / d))
            - np.exp(np.sum(np.cos(2 * np.pi * x)) / d) + 20 + np.e)

def pso_once():
    lo, hi = -32.768, 32.768
    x = rng.uniform(lo, hi, (POP, D)); v = np.zeros((POP, D))
    fx = np.array([ackley(xi) for xi in x])
    pbest, pbv = x.copy(), fx.copy()
    g = int(np.argmin(pbv)); gbv = pbv[g]; evals = POP
    while evals < BUDGET:
        w = 0.9 - 0.5 * evals / BUDGET
        r1, r2 = rng.random((POP, D)), rng.random((POP, D))
        v = w * v + 1.4945 * r1 * (pbest - x) + 1.4945 * r2 * (pbest[g] - x)
        v = np.clip(v, -32.768, 32.768)
        x = np.clip(x + v, lo, hi)
        fx = np.array([ackley(xi) for xi in x])
        bt = fx < pbv
        pbest[bt], pbv[bt] = x[bt], fx[bt]
        g = int(np.argmin(pbv)); gbv = min(gbv, pbv[g])
        evals += POP
    return gbv

def sa_once():
    x = rng.uniform(-32.768, 32.768, D)
    fx = ackley(x); best = fx
    T, alpha, evals = 50.0, 0.995, 1
    while evals < BUDGET:
        xp = np.clip(x + rng.normal(0, 2.0, D), -32.768, 32.768)
        fp = ackley(xp)
        if fp < fx or rng.random() < np.exp((fx - fp) / T):
            x, fx = xp, fp
        best = min(best, fp)
        evals += 1; T *= alpha
    return best

p = [pso_once() for _ in range(RUNS)]       # 各 10 次独立运行
s = [sa_once() for _ in range(RUNS)]
print("PSO  mean=%.4f std=%.4f" % (np.mean(p), np.std(p)))
print("SA   mean=%.4f std=%.4f" % (np.mean(s), np.std(s)))
# 典型输出:PSO mean=0.0000 std=0.0000 ; SA mean≈3.5 std≈0.2
```

> 这就是例题 3 的实验生成器:**同一预算、同一运行次数、同一随机流起点**,对比结论才站得住。把函数换成你的目标即可复用。

## 🧠 小结

1. 选型五问:连续/离散、有无精确算法、目标个数、问题结构、规模时限;精确算法永远优先尝试
2. 无免费午餐:算法的优劣只在「特定问题类」上有意义,论文结论必须限定范围
3. 公平对比五军规:统一预算(按评估数)、统一调参工作量、多次运行、统计检验、有参照物
4. 约束三件套:编码保可行 > 修复 > 罚函数;罚系数要动态/自适应并报告取值依据
5. 报告模板:均值 ± 标准差 + 达标率 + 收敛曲线 + 箱线图 + Wilcoxon 检验——这一套下来,评委想不给你分都难
