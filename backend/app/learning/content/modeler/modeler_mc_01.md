## 📖 核心概念

### 1. 核心思想:用随机性解确定性问题

蒙特卡洛方法回答的问题是:**如果一个量难以解析计算,但可以被写成某个随机变量的期望,那就大量抽样、用样本均值去逼近它**。典型句式:

$$\text{要算的量} = E[g(X)] \approx \frac{1}{N}\sum_{i=1}^{N} g(X_i)$$

其中 $X_i$ 是独立同分布的随机样本。由**大数定律**,样本均值几乎必然收敛到期望;由**中心极限定理**,误差的分布近似正态,可以定量刻画。

> 💡 **建模心法**:拿到一个「难算的量」,先问自己:能不能把它改写成期望?定积分是 $E[g(U)]$、概率是 $E[\mathbf{1}\{事件\}]$、排队指标是随机路径的平均——改写成期望,MC 就上场了。

### 2. 经典示例:投点法估计 $\pi$

在边长为 1 的正方形内均匀撒 $N$ 个点,统计落在内切四分之一圆内的比例。每个点是一个伯努利试验,命中概率恰为圆面积比:

$$P(\text{命中}) = \frac{\pi/4}{1} = \frac{\pi}{4} \quad \Rightarrow \quad \hat{\pi} = 4 \times \frac{\text{命中数}}{N}$$

### 3. 定积分与一般期望

对定积分 $I = \int_a^b f(x)\, dx$:

$$I = (b-a)\cdot E[f(U)],\ U \sim U(a,b) \quad \Rightarrow \quad \hat{I} = \frac{b-a}{N}\sum_{i=1}^N f(x_i)$$

高维积分同样适用,而且**误差与维数无关**(对比梯形法在 $d$ 维的误差是 $O(N^{-2/d})$,MC 恒为 $O(N^{-1/2})$)——维数灾难恰恰是 MC 的主场。

### 4. 误差分析与样本量确定

单次抽样 $g(X)$ 的方差记为 $\sigma^2$,则 $N$ 次样本均值的标准误为:

$$\mathrm{SE} = \frac{\sigma}{\sqrt{N}}, \qquad \hat{I} \pm \frac{z_{\alpha/2}\,\hat{\sigma}}{\sqrt{N}}$$

反解得到给定精度 $\varepsilon$ 与置信水平所需的样本量:

$$N \approx \left(\frac{z_{\alpha/2}\,\sigma}{\varepsilon}\right)^2$$

> 关键认知:精度提高 10 倍,样本量要增大 100 倍。MC 是「笨方法」,靠的是大数定律的耐心;所以在竞赛中,**方差缩减**往往比盲目加大 $N$ 更聪明。

### 5. 方差缩减四件套

| 技术 | 做法 | 原理 |
|------|------|------|
| **对偶变量** | 成对使用 $U$ 与 $1-U$ | 负相关的误差互相抵消 |
| **控制变量** | 减去一个与 $g$ 相关且期望已知的量 | 只模拟「剩余波动」 |
| **分层抽样** | 把抽样域分层,每层按比例抽 | 消去层间差异,只留层内方差 |
| **重要抽样** | 在「重要区域」多抽样,用似然比修正 | 稀有事件也能采到样本 |

重要抽样的修正公式(从 $q$ 抽样估计 $p$ 下的期望):

$$E_p[g(X)] = E_q\!\left[g(X)\frac{p(X)}{q(X)}\right] \approx \frac{1}{N}\sum_{i=1}^N g(X_i)\frac{p(X_i)}{q(X_i)}$$

### 6. 随机数:伪随机与种子

计算机产生的是**伪随机数**(如 Mersenne Twister、PCG64)——由确定性递推生成,但通过统计检验。设**随机种子**(`np.random.default_rng(42)`)使整个实验**可复现**,这是竞赛论文「结果可重现」的基本要求。要生成非均匀分布时,常用**逆变换法**:$X = F^{-1}(U)$。

## 🧮 公式与结论

**积分估计与误差**:

$$\hat{I} = \frac{b-a}{N}\sum_{i=1}^N f(x_i), \qquad \mathrm{Var}(\hat{I}) = \frac{\sigma_f^2}{N}, \qquad \text{误差} \propto \frac{1}{\sqrt{N}}$$

**$\pi$ 估计的标准误**(伯努利,$p = \pi/4$):

$$\mathrm{SE}[\hat{\pi}] = 4\sqrt{\frac{p(1-p)}{N}} = \frac{4}{N}\sqrt{\frac{\pi}{4}\left(1-\frac{\pi}{4}\right)N} \approx \frac{1.642}{\sqrt{N}}$$

**对偶变量**($U \sim U(0,1)$):

$$\hat{I}_{\text{anti}} = \frac{1}{N}\sum_{i=1}^N \frac{f(U_i) + f(1-U_i)}{2}, \qquad \mathrm{Var}(\hat{I}_{\text{anti}}) = \frac{\sigma_f^2 + \mathrm{Cov}(f(U), f(1-U))}{2N}$$

**重要抽样恒等式**:

$$E_p[g(X)] = \int g(x)\frac{p(x)}{q(x)}\, q(x)\, dx = E_q\!\left[g(X)\,\frac{p(X)}{q(X)}\right]$$

## 💡 经典例题

### 例题 1:投点法估计 $\pi$

> 用 100 万个随机点估计 $\pi$,并给出误差评估。

**模拟**(`numpy`,种子 42):

$$\hat{\pi} = 4 \times \frac{785609}{1000000} = 3.142436$$

**误差评估**:每个点命中概率 $p = \pi/4 \approx 0.7854$,命中比例的标准误为

$$\sqrt{\frac{p(1-p)}{N}} = \sqrt{\frac{0.7854 \times 0.2146}{10^6}} \approx 0.000411$$

乘 4 后,$\hat{\pi}$ 的标准误 $\mathrm{SE} \approx 0.001642$。实际误差 $|3.142436 - 3.141593| = 0.000843$,约为 $0.5$ 个标准误,落在 $\pm 3\,\mathrm{SE}$ 的常规波动范围内,结果正常。

**解析**:100 万个点给出 3.1424(误差 $8 \times 10^{-4}$),若想再精确一位(误差 $10^{-4}$ 量级),按 $1/\sqrt{N}$ 的收敛速度需约 1 亿个点——样本量 ×100,精度只 ×10,这就是 MC 的代价与规律。

### 例题 2:定积分与对偶变量

> 计算 $I = \int_0^1 x^2\, dx$(真值 $1/3 \approx 0.3333$),对比朴素 MC 与对偶变量法。

**朴素 MC**($N = 10^5$,种子 42):$\hat{I} = \frac{1}{N}\sum U_i^2 = 0.333869$

**对偶变量法**:每抽一个 $U_i$,配对使用 $1-U_i$:

$$\hat{I}_{\text{anti}} = \frac{1}{N}\sum_{i=1}^N \frac{U_i^2 + (1-U_i)^2}{2} = 0.333244$$

**理论方差对比**(单个样本):

$$\mathrm{Var}(U^2) = E[U^4] - (E[U^2])^2 = \frac{1}{5} - \frac{1}{9} = \frac{4}{45} \approx 0.0889$$

$$\mathrm{Var}\!\left(\frac{U^2 + (1-U)^2}{2}\right) = \mathrm{Var}\!\left(U^2 - U + \frac{1}{2}\right) = \mathrm{Var}(U^2) + \mathrm{Var}(U) - 2\,\mathrm{Cov}(U^2, U)$$

$$= \frac{4}{45} + \frac{1}{12} - 2 \times \frac{1}{12} = \frac{4}{45} - \frac{1}{12} = \frac{16-15}{180} = \frac{1}{180} \approx 0.00556$$

**方差缩减 $\dfrac{4/45}{1/180} = 16$ 倍**——同样的样本量,误差只有原来的 1/4。实测方差比 $0.088782 / 0.005564 \approx 15.96$,与理论完全吻合。

**解析**:$f(U)$ 与 $f(1-U)$ 关于中点对称、强负相关,成对使用让误差互相抵消。对偶变量适合「单调性明显」的被积函数;若函数关于区间中点不相关,则收益甚微。

### 例题 3:桥式网络的可靠性(概率类问题)

> 桥式网络有 5 条边(见代码),每条边以 $p = 0.9$ 的概率正常工作且相互独立。求源点 s 到汇点 t 连通的概率。

**精确解**(枚举 $2^5 = 32$ 种状态):$P = 0.97848$

**蒙特卡洛**(种子 42,$N = 10000$ 次抽样,每次独立掷 5 枚「边硬币」,用并查集判断连通):

$$\hat{P} = \frac{9790}{10000} = 0.97900$$

**误差评估**:$\mathrm{SE} = \sqrt{0.97848 \times 0.02152 / 10000} \approx 0.00145$,估计值与真值差 0.00052,约 0.36 个标准误,非常理想。

**解析**:这正是 MC 的价值——桥式网络这种「串并联混合」结构,解析计算要枚举或做容斥,而 MC 只需重复「掷硬币 + 判连通」两步。网络再复杂(几十条边、相关失效),代码几乎不用改。

## ⚠️ 常见易错点

1. **不设随机种子**。不设种子意味着每次运行结果都不同,论文数据不可复现、审稿人无法验证;`np.random.default_rng(42)` 一行即可解决
2. **把 MC 误差当成确定上界**。「$|\hat{I} - I| \leq 3\mathrm{SE}$」只是约 99.7% 概率成立,不是数学保证;报告时写「95% 置信区间」而非「误差不超过」
3. **忘记 MC 误差只按 $1/\sqrt{N}$ 下降**。想把精度提高一位小数,样本量要 ×100;直接砸 $N = 10^9$ 不如先做方差缩减
4. **重要抽样忘记乘似然比**。从 $q$ 抽样却不乘 $p/q$ 修正,估计的是错误期望;似然比本身也是误差来源,建议分布要选好
5. **稀有事件用朴素 MC 硬算**。事件概率 $10^{-7}$ 时,平均 1000 万次抽样才命中 1 次,估计几乎必为 0;应改用重要抽样或条件化
6. **混淆「伪随机」与「真随机」**。伪随机数由递推生成、周期有限,但足够建模使用;密码学等场景才需要真随机源,竞赛中不必纠结

## ✏️ 自测练习

**第 1 题(判断)**:MC 积分的误差是 $O(1/\sqrt{N})$,与积分维数无关。对吗?高维时它比梯形法好在哪?

<details><summary>查看答案</summary>

**对**。MC 误差只取决于被积函数的标准差与 $\sqrt{N}$,与维数 $d$ 无关;而梯形法等确定性数值积分在 $d$ 维空间的误差是 $O(N^{-2/d})$,维数越高退化越严重。所以 $d \geq 4$ 左右时,MC 几乎是一般光滑被积函数唯一实用的选择——「维数灾难」正是 MC 的主场。

</details>

**第 2 题(计算)**:用对偶变量法估计 $E[e^U]$($U \sim U(0,1)$,真值 $e - 1 \approx 1.7183$)。对偶变量能把方差缩减多少?

<details><summary>查看答案</summary>

估计量:$\frac{1}{N}\sum_{i=1}^N \frac{e^{U_i} + e^{1-U_i}}{2}$。例如 $N = 10^5$、种子 42 时得 1.7182,与真值 1.7183 几乎重合。

方差对比(单样本):$\mathrm{Var}(e^U) = E[e^{2U}] - (e-1)^2 = \frac{e^2-1}{2} - (e-1)^2 \approx 0.242$;对偶后 $\mathrm{Var}\!\left(\frac{e^U + e^{1-U}}{2}\right) \approx 0.0039$。缩减约 **62 倍**(实测 61.7)。原理:$e^U$ 单调,$U$ 与 $1-U$ 的配对使两组误差强负相关、相互抵消。

</details>

**第 3 题(概念)**:分层抽样为什么能减小方差?把 $[0,1]$ 均分成 10 层、总样本量不变时,估计 $\int_0^1 x^2\, dx$ 的方差约为朴素方法的多少?

<details><summary>查看答案</summary>

分层抽样把总方差分解为「层间方差 + 层内方差」,并**消去了层间方差**:每层单独抽样,层与层之间没有随机性,只剩各层内部的波动。对光滑函数,每层内函数值接近常数,层内方差远小于整体方差;层数 $K$ 增加时方差约按 $1/K^2$ 下降(远快于朴素法的 $1/N$)。

对 $\int_0^1 x^2\, dx$:10 层、总样本量 $10^5$ 时,分层估计的方差约 $1.1 \times 10^{-8}$,朴素方法约 $8.9 \times 10^{-7}$,**缩减约 80 倍**。分层的关键是「每层都要有样本」,层数太多而每层样本太少时反而得不偿失。

</details>

**第 4 题(应用)**:估计 $P(X > 5)$,其中 $X \sim N(0,1)$。为什么朴素 MC 几乎注定失败?如何用重要抽样解决?

<details><summary>查看答案</summary>

真值 $P(X > 5) = 1 - \Phi(5) \approx 2.87 \times 10^{-7}$。朴素 MC 平均约 350 万次抽样才命中一次,做 10 万次抽样几乎必然得到 0 次命中、估计为 0,完全无用。

重要抽样:改从建议分布 $Y \sim N(5, 1)$ 抽样(把采样中心移到感兴趣的区域),用似然比修正:

$$P(X>5) = E_Y\!\left[\mathbf{1}\{Y>5\}\,\frac{\varphi(Y)}{\varphi(Y-5)}\right] \approx \frac{1}{N}\sum_{i=1}^N \mathbf{1}\{Y_i>5\}\,\frac{\varphi(Y_i)}{\varphi(Y_i-5)}$$

其中 $\varphi$ 是标准正态密度。此时约一半样本落在 $Y > 5$,估计值稳定在 $10^{-7}$ 量级,与真值同阶。稀有事件模拟必须「把样本搬到事件附近」,再靠似然比修正偏置。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:美赛(尤其 ICM)最爱 MC——供应链扰动、天气风险、排队拥堵、市场模拟都靠它;国赛则常用于**验证解析/数值解的正确性**,以及含随机因素的场景(交通流、库存)
- **论文加分点**:①固定随机种子并声明,附「不同种子结果稳定」的敏感性说明;②给出**置信区间或标准误**,而不是报一个孤零零的数字;③做**方差缩减**(哪怕只加对偶变量),并报告缩减倍数——这比无脑加大 $N$ 高一个档次;④MC 结果与解析解对照,自证正确性
- **工具**:`numpy.random`(基础)、`scipy.stats`(各类分布抽样)、复杂系统可用 `simpy`(离散事件模拟)

## 💻 代码实现

```python
import numpy as np

# 1. 投点法估计 pi (例题 1)
rng = np.random.default_rng(42)
N = 1_000_000
x, y = rng.random(N), rng.random(N)
pi_hat = 4 * ((x**2 + y**2) <= 1).mean()
se = 4 * np.sqrt((np.pi/4) * (1 - np.pi/4) / N)          # 理论标准误
print(f"pi_hat = {pi_hat:.6f} (真值 3.141593), SE = {se:.6f}")   # 3.142436

# 2. 定积分 ∫x^2: 朴素 vs 对偶变量 (例题 2)
rng = np.random.default_rng(42)
u = rng.random(100_000)
plain = u**2
anti = (u**2 + (1 - u)**2) / 2
print(f"朴素 = {plain.mean():.6f}, 对偶 = {anti.mean():.6f} (真值 0.333333)")
print(f"方差比 = {plain.var(ddof=1) / anti.var(ddof=1):.1f} (理论 16)")

# 3. 桥式网络可靠性 (例题 3): 5 条边, 每条以 p=0.9 独立正常工作
p = 0.9
edges = [(0, 1), (0, 2), (1, 2), (1, 3), (2, 3)]         # 0=s, 1=a, 2=b, 3=t

def connected(alive):
    parent = list(range(4))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    for i, (a, b) in enumerate(edges):
        if alive[i]:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[ra] = rb
    return find(0) == find(3)

rng = np.random.default_rng(42)
M = 10_000
hits = sum(connected([rng.random() < p for _ in range(5)]) for _ in range(M))
print(f"可靠性 MC = {hits/M:.5f} (精确值 0.97848)")
```

> 运行结果与例题一致:$\hat{\pi} = 3.142436$;积分朴素 0.333869、对偶 0.333244,方差比约 16;可靠性 0.97900 对 0.97848。把 `N`、`M` 调大,估计会更靠近真值,但波动符合 $\pm 3\mathrm{SE}$ 规律。

## 🧠 小结

1. MC 一句话:**把难算的量写成期望,再用样本均值逼近**;大数定律保证收敛,中心极限定理量化误差
2. 误差永远是 $\sigma/\sqrt{N}$:精度 ×10 = 样本量 ×100,且与维数无关——高维积分是 MC 的主场
3. 方差缩减四件套:对偶(负相关抵消)、控制(减已知期望)、分层(消层间方差)、重要抽样(稀有事件必备)
4. 随机种子 = 可复现 = 论文可信度;报告结果永远带标准误或置信区间
5. 应用面:估计 $\pi$、积分、概率、排队指标、可靠性——任何「随机系统 + 统计问题」的组合
