## 📖 核心概念

### 1. 集成学习:三个臭皮匠的统计学依据

单模型误差可以分解为 偏差² + 方差 + 不可约噪声。集成学习通过组合多个学习器压低其中一项:

- **Bagging**:并行训练,平均输出 → **降方差**(适用于高方差的决策树)
- **Boosting**:串行训练,后一个修正前一个的残差 → **降偏差**(XGBoost/LightGBM 属于此列)

随机森林属于 Bagging 家族,是竞赛中最「开箱即用」的模型之一。

### 2. Bootstrap 与 Bagging

- **Bootstrap**:从 $n$ 个样本中**有放回**抽 $n$ 个,构成一个训练集。某样本一次都不被抽中的概率为 $(1 - 1/n)^n \to 1/e \approx 0.368$——约 36.8% 的样本「落选」,称为**袋外样本(OOB)**
- **Bagging**(Bootstrap Aggregating):抽 $B$ 个 bootstrap 样本,各训练一棵树,回归取平均、分类投票
- 平均为什么好:若 $B$ 棵树误差方差为 $\sigma^2$、两两相关为 $\rho$,则平均模型的方差 = $\rho\sigma^2 + (1-\rho)\sigma^2/B$。树越多,方差趋近下限 $\rho\sigma^2$——**相关性是收益的天花板**,所以 Bagging 的关键不是树多,而是树「不相关」
- **OOB 妙用**:每棵树只用自己「没抽中」的 OOB 样本评估,OOB 误差近似交叉验证,**省去单独切验证集**——小样本竞赛题尤其宝贵

### 3. 随机森林:双重随机

随机森林 = Bagging + **特征随机**:

1. **样本随机**:每棵树一个 bootstrap 样本
2. **特征随机**:每次分裂只从随机抽出的 $m$ 个特征中挑最优(回归默认 $m = p/3$,分类默认 $\sqrt p$)

机制:若每次分裂都用全部特征,最强的那几个特征会统治所有分裂,树与树高度相似 → $\rho$ 高,方差降不下去;特征随机强制树「各学各的」,相关性下降 → 方差显著降低。

### 4. 决策树为什么适合做基学习器

- 树是**高方差**模型:数据微扰,结构巨变——Bagging 降方差正好对症
- 树天然处理:非线性、混合类型特征、缺失值、异常值(切分只依赖排序,对尺度免疫)
- **不需要标准化、不需要假设线性**——「开箱即用」,是竞赛基线之王

### 5. 特征重要性:两种算法与各自的坑

- **不纯度下降(MDI)**:累加每个特征在所有分裂中减少的方差(回归)或基尼不纯度(分类),按树平均。sklearn 的 `feature_importances_` 就是这个。坑:①偏向**高基数**特征(取值多的特征分裂机会多);②**共线特征互相分摊**重要性,单个都被低估
- **置换重要性(Permutation)**:随机打乱某个特征,看预测误差恶化多少。坑:共线特征打乱一个,另一个能「替补」,同样低估
- 共同局限:重要性描述的是「模型用了多少」,**不是因果**(参见《多元回归与变量选择》单元)

### 6. 随机森林的边界:外推为零

树模型的预测是**训练样本预测值的分段常数平均**——对超出训练范围的输入,所有叶子都只能给出「边缘」样本的平均值,预测被压回训练区间。因此:

- **数据范围内拟合**:强
- **趋势外推**(如按指数增长预测未来):**零能力**,应改用回归、灰色预测或 ARIMA(参见《灰色预测GM(1,1)》《时间序列与ARIMA模型》单元)
- 时间序列的长期预测要特别小心;「本题为什么不用随机森林」是竞赛论文里值得写的一段

## 🧮 公式与结论

### Bagging 方差分解

$$\mathrm{Var}(\bar f) = \rho\sigma^2 + \frac{1-\rho}{B}\,\sigma^2$$

- $B \to \infty$:第二项消失,方差降至下限 $\rho\sigma^2$
- $\rho \to 0$:方差 $\to \sigma^2/B$,理想平均;$\rho \to 1$:方差 $\to \sigma^2$,Bagging 白做
- 数值感($B = 100$,$\sigma^2 = 1$):$\rho = 0.5$ → 0.505;$\rho = 0.1$ → 0.109。**把相关性从 0.5 降到 0.1 的收益,远大于把树从 100 加到 1000**——降低相关性优先于增加树数

### OOB 比例

$$P(\text{样本落选}) = \left(1 - \frac1n\right)^n \ \xrightarrow{n \to \infty}\ \frac1e \approx 0.368$$

$n = 100$ 时 $(0.99)^{100} = 0.366$,$n = 200$ 时 0.367——几十个样本就非常接近 $1/e$ 了。

### 回归预测

$$\hat f(x) = \frac1B\sum_{b=1}^B T_b(x)$$

$T_b$ 是第 $b$ 棵树。注意是对**预测值**求平均,不是对树的结构求平均。

### 关键超参数

| 参数 | 作用 | 经验起点 |
|------|------|----------|
| n_estimators | 树的数量 | 100–500,误差曲线平台即止 |
| max_features | 每次分裂的特征数 | 回归 $p/3$,分类 $\sqrt p$ |
| max_depth | 树深(防过拟合) | 先不限制,过拟合再收紧 |
| min_samples_leaf | 叶子最少样本数 | 回归 1–5,样本少时加大 |

## 💡 经典例题

### 例题 1:OOB 比例手算

> $n = 100$ 的训练集,每棵树做 bootstrap 抽样。问:①某样本落入一棵树的训练集的概率?②约有百分之多少样本可作为该树的 OOB?③100 棵树的森林,某样本平均被多少棵树用作 OOB?

① 落入概率 $= 1 - (1 - 1/100)^{100} = 1 - 0.366 = 0.634$。
② OOB 比例 $= (1 - 1/100)^{100} = 0.366 \approx 36.6\%$(与 $1/e = 0.368$ 仅差 0.002)。
③ $100 \times 0.366 \approx 36.6$ 棵。

**解析**:③意味着每个样本平均有约 37 棵树「没见过它」,这些树的预测平均就是这个样本的 **OOB 预测**——整个森林一次训练就能得到免费的验证集评估。数据只有几百条时,不用再切验证集,训练数据全部用上,这是随机森林对小样本竞赛题的巨大优势。

### 例题 2:Bagging 方差公式的数值计算

> 树间相关性 $\rho = 0.5$,单树方差 $\sigma^2 = 1$。求 $B = 1, 10, 100, 1000$ 时森林的方差。

$\mathrm{Var} = 0.5 + 0.5/B$:

| $B$ | 1 | 10 | 100 | 1000 |
|-----|-----|-----|------|------|
| 方差 | 1.0(= 单树) | 0.55 | 0.505 | 0.5005 |

树从 10 加到 100,方差降 0.045;从 100 加到 1000,只降 0.0045——**边际收益锐减,且下限 0.5 被相关性锁定**。若通过特征随机把 $\rho$ 降到 0.1:$B = 100$ 时方差 $= 0.1 + 0.9/100 = 0.109$,直接再降近 5 倍。

**解析**:这个公式解释了随机森林的两件事:①为什么几乎不会「过拟合加深」——方差有下限,树越多越稳;②为什么「降相关性 > 加树数」。竞赛里把树从 100 加到 1000 只是浪费时间,调 `max_features`、`max_depth` 才有实质收益。

### 例题 3:单树 vs 随机森林(真实数据实测)

> sklearn 糖尿病数据集($n = 442$,10 个特征,目标是病情进展指标)。70% 训练、30% 测试(固定 `random_state=42`,结果可复现),对比单棵决策树(深度 4)与随机森林(100 棵树、深度 4、OOB 开启):

| 模型 | 测试集 $R^2$ |
|------|--------------|
| 单棵决策树(max_depth=4) | 0.324 |
| 随机森林(100 棵,max_depth=4) | 0.492 |
| 随机森林 OOB 得分 | 0.424 |

**解析**:同样的树、同样的深度,「种一片」比「种一棵」$R^2$ 高出约 0.17。OOB 得分 0.424 与测试集 0.492 同量级——OOB 是可靠的离线评估。特征重要性(不纯度下降)前三位:**bmi 0.526、s5 0.193、bp 0.091**,bmi 一家独大,提示「体质指数是病情进展的最强预测因子」——这类由特征重要性导出的业务结论,可以直接写进论文的模型解读章节。

## ⚠️ 常见易错点

1. **拿随机森林做外推**。预测超出训练范围的值会被压平到训练区间边缘——趋势外推类题目(人口、GDP、销量长期预测)必须换模型,或先做差分/去趋势
2. **时间序列随机交叉验证**。打乱切分 → 未来信息泄露;评估时序数据要用按时间切分或 walk-forward(参见《时间序列与ARIMA模型》单元)
3. **把特征重要性当因果**。重要性高 ≠ 因果强,共线特征还会互相分摊;归因任务先看 VIF 与业务逻辑,预测任务才看重要性
4. **树无限深不约束**。`max_depth=None` 的树会背数据,单棵树过拟合严重;先限深或调 `min_samples_leaf`(决策树单元有详解)
5. **认为树越多越好**。方差下限 $\rho\sigma^2$ 锁死收益,几百棵树后再加只增加计算时间
6. **分类问题直接比较标签**。随机森林分类输出**概率**更有信息,阈值选取应结合业务成本(如漏报代价高则降低判定阈值),而不是默认 0.5

## ✏️ 自测练习(选择题)

**第 1 题**Bagging 方差公式 $\mathrm{Var} = \rho\sigma^2 + (1-\rho)\sigma^2/B$。取 $\sigma^2 = 1$,$B = 100$:树间相关性 $\rho = 0.8$ 与 $\rho = 0.2$ 时,森林方差分别为:

A. 0.8 与 0.2
B. 1.0 与 0.5
C. 0.802 与 0.208
D. 0.802 与 0.208,但说明应继续把树加到 1000 才能压方差

<details><summary>查看答案与解析</summary>
**答案:C**。$\rho = 0.8$:$\mathrm{Var} = 0.8 + 0.2/100 = 0.802$——平均 100 棵几乎没降方差(单树为 1.0),Bagging 接近白做;$\rho = 0.2$:$\mathrm{Var} = 0.2 + 0.8/100 = 0.208$,降了约 5 倍。结论:**降低相关性(特征随机、限制树深)远胜增加树数**——方差下限 $\rho\sigma^2$ 被相关性锁死,树从 100 加到 1000 边际收益只有 0.0045。「0.8 与 0.2」漏掉了 $B$ 有限时的那一项。
</details>

**第 2 题**随机森林对 $n = 50$ 的训练集做 bootstrap 抽样(有放回抽 $n$ 个),某样本一次都不被抽中、可作为袋外(OOB)样本的概率约为:

A. 36.4%
B. 50%
C. 63.6%
D. 2%

<details><summary>查看答案与解析</summary>
**答案:A**。落选概率 $= (1 - 1/50)^{50} = 0.3642 \approx 36.4\%$,已经非常接近极限 $1/e \approx 0.368$。63.6% 是「被抽中」的概率 $1 - 0.364$,方向搞反;50% 是「一半一半」的直觉;2% 是 $1/50$ 的直接套用。OOB 的妙用:每棵树只用「没抽中」的样本评估自己,OOB 误差近似交叉验证,省去单独切验证集——小样本竞赛题尤其宝贵。
</details>

**第 3 题**模型报告特征重要性最高的是 $x_3$,能否在论文中写「$x_3$ 是导致 $y$ 变化的原因」?

A. 能,重要性就是变量对结果的影响力
B. 不能,但改用置换重要性之后就可以下因果结论
C. 能,只要重要性数值超过 0.5
D. 不能,重要性描述的是模型对 $x_3$ 的使用程度,不是因果关系;应写「$x_3$ 是预测贡献最大的特征」

<details><summary>查看答案与解析</summary>
**答案:D**。特征重要性(不纯度下降或置换)度量「模型在预测中依赖该特征的程度」,**不是因果**。它可能因共线分摊、高基数偏差、混杂变量(温度同时驱动冰淇淋销量与溺水人数)而虚高或虚低。置换重要性解决的是评估口径问题,同样不能导出因果——因果结论需要实验设计或因果推断方法支撑。论文正确写法:「$x_3$ 是模型预测贡献最大的特征」,并给业务解释留余地。
</details>

## 🏆 竞赛实战链接

- **出镜场景**:国赛 2021 B(乙醇偶合制备 C4 烯烃,多特征非线性拟合)、2023 C(蔬菜销量预测,多特征回归)都是随机森林的高光场景;美赛 C 题大数据题中,随机森林常作为强基线与其他模型对比
- **论文加分点**:①说明 **OOB 误差替代交叉验证**的理由;②**置换重要性与 MDI 双表对比**;③由特征重要性排序引出业务结论;④与线性回归、神经网络的对比实验(从精度、可解释性、外推能力三方面讨论)
- **纪律**:数据几百条以内,先跑随机森林拿基线,再决定要不要上神经网络——「随机森林基线 + 模型对比」是评委熟悉且认可的套路

## 💻 代码实现

```python
import numpy as np
from sklearn.datasets import load_diabetes
from sklearn.ensemble import RandomForestRegressor
from sklearn.tree import DecisionTreeRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import r2_score
from sklearn.inspection import permutation_importance

X, y = load_diabetes(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=42)

# 单树基线
tree = DecisionTreeRegressor(max_depth=4, random_state=42).fit(X_tr, y_tr)
print("单树 R²:", round(r2_score(y_te, tree.predict(X_te)), 3))      # 0.324

# 随机森林(开启 OOB)
rf = RandomForestRegressor(n_estimators=100, max_depth=4,
                           oob_score=True, random_state=42).fit(X_tr, y_tr)
print("RF 测试 R²:", round(r2_score(y_te, rf.predict(X_te)), 3))     # 0.492
print("RF OOB  R²:", round(rf.oob_score_, 3))                        # 0.424

# 特征重要性(MDI)
names = load_diabetes().feature_names
for i in np.argsort(rf.feature_importances_)[::-1]:
    print(f"  {names[i]}: {rf.feature_importances_[i]:.3f}")

# 置换重要性(在测试集上评估)
pi = permutation_importance(rf, X_te, y_te, n_repeats=10, random_state=0)
print("置换重要性前 3:", [names[i] for i in np.argsort(pi.importances_mean)[::-1][:3]])
```

> 时间序列数据:`train_test_split(..., shuffle=False)` 按时间切分;报告预测精度时用 walk-forward 回测,而不是随机交叉验证。

## 🧠 小结

1. Bagging 降方差:平均模型方差 $= \rho\sigma^2 + (1-\rho)\sigma^2/B$,**相关性是收益天花板**
2. 随机森林 = bootstrap 样本 + 随机特征子集,双重随机降低树间相关性,是「开箱即用」的竞赛基线
3. OOB 样本约占 36.8%,OOB 误差免费替代交叉验证,小样本尤其好用
4. 特征重要性分不纯度下降与置换两种,都要报;它们描述「使用量」而非因果
5. 随机森林的边界是外推:树只能输出训练范围内预测值的平均,趋势外推题换模型
