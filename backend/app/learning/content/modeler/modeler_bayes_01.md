## 🎯 学习目标

学完本单元,你应该能够:

- 讲清频率学派与贝叶斯学派的根本分歧:参数到底是不是随机变量
- 熟练使用「后验 ∝ 先验 × 似然」,并能用全概率公式完成归一化
- 掌握 Beta–二项、正态–正态、Gamma–泊松三组共轭关系,闭式写出后验分布
- 理解先验强度(伪样本数)与样本量的博弈,会做先验敏感性分析
- 知道后验不可解析时用 MCMC(Metropolis–Hastings / Gibbs)采样的思路

## 📖 核心概念

### 1. 两大学派的分歧

频率学派把参数 $\theta$ 看作**未知的常数**,估计量是随机变量(因为样本随机),结论以「置信区间、p 值」的形式出现;贝叶斯学派把 $\theta$ 本身看作**随机变量**——我们对它的认识用概率分布刻画,数据到来前是**先验分布**,看到数据后更新为**后验分布**。

> 直觉:频率学派问「如果重复实验无数次,这个区间有多大比例覆盖真值?」;贝叶斯学派问「看到这批数据后,真值落在哪个区间里的把握有多大?」后者往往更接近竞赛论文里你真正想回答的问题。

### 2. 贝叶斯公式与三要素

$$\underbrace{P(\theta \mid D)}_{\text{后验}} = \frac{\overbrace{P(D \mid \theta)}^{\text{似然}} \cdot \overbrace{P(\theta)}^{\text{先验}}}{\underbrace{P(D)}_{\text{归一化常数}}}$$

- **先验** $P(\theta)$:看到数据之前对参数的信念,来自历史经验、专家知识或物理约束
- **似然** $P(D \mid \theta)$:给定参数时数据出现的概率——与《极大似然估计》单元里的似然完全相同
- **后验** $P(\theta \mid D)$:综合数据与先验之后的更新信念,是贝叶斯推断的全部输出
- **归一化常数** $P(D) = \int P(D \mid \theta) P(\theta)\, d\theta$:与 $\theta$ 无关,计算时常用比例关系略去:

$$\text{后验} \propto \text{似然} \times \text{先验}$$

### 3. 共轭先验

若先验与后验属于**同一分布族**,称该先验为似然的**共轭先验**。共轭的好处是后验闭式可写,不需要数值积分。三组最常用的共轭关系:

| 似然(数据) | 共轭先验 | 后验 |
|-----------|---------|------|
| 二项 $k / n$ 次成功 | $\text{Beta}(\alpha, \beta)$ | $\text{Beta}(\alpha + k,\ \beta + n - k)$ |
| 正态均值($\sigma^2$ 已知) | $N(\mu_0, \tau^2)$ | 正态(见公式) |
| 泊松观测 $\sum x_i$ | $\text{Gamma}(\alpha, \beta)$ | $\text{Gamma}(\alpha + \sum x_i,\ \beta + n)$ |

> 解读超参数:Beta$(\alpha, \beta)$ 等价于「还没做实验前,已经见过 $\alpha$ 次成功、$\beta$ 次失败」,所以 $\alpha + \beta$ 叫**伪样本数**——先验越强,推翻它需要的数据越多。

### 4. 后验推断的三件套

- **点估计**:后验均值 $E[\theta \mid D]$(最小化平方损失),或后验众数 MAP(最大后验估计,与 MLE 的区别只在于乘了一个先验)
- **区间估计**:95% **可信区间**(credible interval),等尾区间取后验的 2.5% 与 97.5% 分位数;更紧凑的是**最高后验密度区间(HPDI)**
- **预测**:后验预测分布 $P(y \mid D) = \int P(y \mid \theta) P(\theta \mid D)\, d\theta$,平均了所有可能的参数取值

### 5. MCMC 的思想

当后验没有解析形式(多参数、非共轭)时,不必求公式,改为**从后验分布采样**:用一条以后验为平稳分布的马尔可夫链产生样本 $\theta^{(1)}, \dots, \theta^{(N)}$,再用样本均值、样本分位数近似后验均值与可信区间。

- **Metropolis–Hastings(MH)**:从提议分布 $q(\cdot \mid \theta^{(t)})$ 抽候选 $\theta^{*}$,以概率 $\min\left(1, \dfrac{p(\theta^{*}) q(\theta^{(t)} \mid \theta^{*})}{p(\theta^{(t)}) q(\theta^{*} \mid \theta^{(t)})}\right)$ 接受,否则留在原地
- **Gibbs 抽样**:MH 的特例——依次从每个参数的**完全条件分布** $p(\theta_j \mid \theta_{-j}, D)$ 采样,接受率恒为 1

> 采样结果要**扔掉前段暖身期(burn-in)**再统计,并检查轨迹图是否混合良好;后验均值 $\neq$ 后验众数,报告时写清是哪个。

## 🧮 公式与结论

**后验更新核心式**:

$$P(\theta \mid D) \propto P(\theta) \cdot P(D \mid \theta)$$

**Beta–二项**(成功概率 $\theta$):

$$\theta \sim \text{Beta}(\alpha, \beta) \ \Rightarrow\ \theta \mid D \sim \text{Beta}(\alpha + k,\ \beta + n - k), \qquad E[\theta \mid D] = \frac{\alpha + k}{\alpha + \beta + n}$$

**正态–正态**($\sigma^2$ 已知,先验 $\mu \sim N(\mu_0, \tau^2)$,样本均值 $\bar{x}$):

$$\mu \mid D \sim N\!\left(\frac{\frac{\mu_0}{\tau^2} + \frac{n \bar{x}}{\sigma^2}}{\frac{1}{\tau^2} + \frac{n}{\sigma^2}},\ \frac{1}{\frac{1}{\tau^2} + \frac{n}{\sigma^2}}\right)$$

即后验均值 = **精度加权平均**(先验精度 $\times$ 先验均值 + 数据精度 $\times$ 样本均值),后验精度 = 两精度之和。

**Gamma–泊松**($\lambda \sim \text{Gamma}(\alpha, \beta)$,密度 $\propto \lambda^{\alpha-1} e^{-\beta\lambda}$):

$$\lambda \mid D \sim \text{Gamma}\!\left(\alpha + \sum_{i=1}^n x_i,\ \beta + n\right), \qquad E[\lambda \mid D] = \frac{\alpha + \sum x_i}{\beta + n}$$

**MH 接受概率**(目标分布 $p$,提议 $q$):

$$\alpha = \min\left(1,\ \frac{p(\theta^{*})\, q(\theta^{(t)} \mid \theta^{*})}{p(\theta^{(t)})\, q(\theta^{*} \mid \theta^{(t)})}\right)$$

## 💡 经典例题

### 例题 1:疾病检测——阳性结果意味着什么?

> 某疾病患病率 1%,检测方法对患者呈阳性的概率(灵敏度)为 99%,对健康人误报阳性的概率为 5%。一人检测呈阳性,他患病的概率是多少?

**套贝叶斯公式**。设 $D$ = 患病,$T^+$ = 阳性:

$$P(D \mid T^+) = \frac{P(T^+ \mid D)\, P(D)}{P(T^+ \mid D) P(D) + P(T^+ \mid \bar{D}) P(\bar{D})} = \frac{0.99 \times 0.01}{0.99 \times 0.01 + 0.05 \times 0.99}$$

$$= \frac{0.0099}{0.0099 + 0.0495} = \frac{0.0099}{0.0594} = \frac{1}{6} \approx 16.7\%$$

**解析**:灵敏度高达 99%,但阳性后患病概率只有 16.7%——因为健康人基数大,5% 的误报制造了大量假阳性。这就是著名的**基础比率谬误**:直觉只看灵敏度,正确的推理必须把先验(患病率)乘进去。若患病率降到 0.1%,同样的检测:

$$P(D \mid T^+) = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999} = \frac{0.00099}{0.05094} \approx 1.9\%$$

阳性后患病概率进一步暴跌到约 1.9%。竞赛中凡涉及筛查、识别、预警的问题,这个算式的骨架都可以直接套用。

### 例题 2:Beta–二项共轭——先验如何被数据更新

> 抛硬币前,你根据经验认为正面概率大概率在 0.5 附近,取先验 $\theta \sim \text{Beta}(2, 2)$(伪样本:2 正 2 反)。抛 10 次得 7 正 3 反。求后验分布与 95% 可信区间。

**共轭更新**:似然为 $p^7(1-p)^3$,先验核为 $p^{2-1}(1-p)^{2-1}$:

$$\text{后验} \propto p^{7}(1-p)^{3} \cdot p^{1}(1-p)^{1} = p^{8}(1-p)^{4} \quad \Rightarrow \quad \theta \mid D \sim \text{Beta}(9, 5)$$

**后验均值**:

$$E[\theta \mid D] = \frac{9}{9+5} = \frac{9}{14} \approx 0.643$$

**95% 等尾可信区间**(Beta(9,5) 的 2.5% 与 97.5% 分位数):

$$[0.386,\ 0.861]$$

**解析**:先验均值是 0.5(相当于 4 个伪样本),数据是 10 次抛掷;后验均值 $0.643$ 介于先验 0.5 与 MLE 0.7 之间、偏向数据一侧——后验是两者的**精度加权折中**。若先验取 Beta(20, 20)(40 个伪样本),后验 Beta(27, 23) 的均值只有 $27/50 = 0.54$,数据几乎拉不动强先验;若先验取 Beta(1, 1)(均匀,无信息),后验 Beta(8, 4) 均值 $0.667$ 接近 MLE——这就是**先验敏感性分析**:换几组先验重算,结论稳定才算稳。

### 例题 3:正态–正态——精度加权平均

> 某仪器测量精度 $\sigma^2 = 1$ 已知。历史经验认为被测值 $\mu$ 服从 $N(0, 4)$。今测 10 次,均值 $\bar{x} = 0.6$。求 $\mu$ 的后验分布与 95% 可信区间。

**套精度加权公式**($\tau^2 = 4,\ n = 10,\ \sigma^2 = 1$):

$$\text{后验精度} = \frac{1}{4} + \frac{10}{1} = 10.25, \qquad \text{后验方差} = \frac{1}{10.25} \approx 0.0976$$

$$\text{后验均值} = \frac{\frac{0}{4} + \frac{10 \times 0.6}{1}}{10.25} = \frac{6}{10.25} \approx 0.585$$

**95% 可信区间**:

$$0.585 \pm 1.96 \times \sqrt{0.0976} = [-0.027,\ 1.198]$$

**解析**:先验说「0 附近、标准差 2」,数据说「0.6 附近、标准差 $1/\sqrt{10} \approx 0.316$」。后验均值 0.585 落在两者之间、靠近数据——因为数据精度(10)远大于先验精度(0.25)。区间宽度从先验的 $\pm 3.92$ 缩到 $\pm 0.61$,这正是贝叶斯学习的过程:每来一条新数据,信念就更新一次、变窄一次。

## ⚠️ 常见易错点

1. **把 $P(T^+ \mid D)$ 与 $P(D \mid T^+)$ 当成一回事**。前者是灵敏度(检测器的属性),后者是阳性预测值(还依赖患病率);只有患病率 50% 时二者数值相等
2. **忘记归一化,把「似然 × 先验」直接当后验用**。比例关系只能用来找众数(分子与 $\theta$ 有关的部分),算均值、分位数必须归一化
3. **先验强度讲不清**。Beta(2, 2) 是「2 正 2 反」共 4 个伪样本,而不是 2 个;论文里写「取 Beta(2,2) 作为弱信息先验」时,这个数字关系是评审常问的点
4. **强先验主导结论却不做敏感性分析**。同一问题换 2~3 组先验(弱、中、强)重算后验,结论一致才敢下断言
5. **用「置信区间」的语言解读可信区间**。95% 可信区间的正确说法是「给定数据与先验,参数落在这个区间的概率为 95%」;而置信区间是频率性质,不针对具体一次实验
6. **MCMC 不暖身、不诊断**。前几千次迭代的样本还带着初始值的影响,必须丢弃 burn-in 段;报告前看轨迹图与自相关图,而不是直接对整条链取平均

## ✏️ 自测练习

**第 1 题(计算)**:某邮件系统垃圾邮件占比 20%。垃圾邮件中出现「中奖」的概率为 90%,正常邮件为 10%。一封含「中奖」的邮件是垃圾邮件的概率是多少?

<details><summary>查看答案</summary>

$$P(\text{垃圾} \mid \text{含词}) = \frac{0.9 \times 0.2}{0.9 \times 0.2 + 0.1 \times 0.8} = \frac{0.18}{0.26} = \frac{9}{13} \approx 69.2\%$$

单个词的证据远不足以定罪(先验只有 20%),朴素贝叶斯分类器会把多个词的似然连乘,使后验快速趋近 0 或 1。

</details>

**第 2 题(计算)**:某路口事故数服从 Poisson($\lambda$),历史经验取先验 $\lambda \sim \text{Gamma}(2, 1)$(均值 2)。今年观测 1 年发生 3 起事故。求 $\lambda$ 的后验分布与后验均值。

<details><summary>查看答案</summary>

由 Gamma–泊松共轭:后验为 $\text{Gamma}(2 + 3,\ 1 + 1) = \text{Gamma}(5, 2)$。

后验均值 $= 5/2 = 2.5$——介于先验均值 2 与观测值 3 之间。若用 MLE 则直接取 3,完全不吸收历史信息,这正是贝叶斯在小样本场景的优势:样本量 $n$ 越大,后验均值越接近 $\bar{x}$。

</details>

**第 3 题(判断)**:随着样本量增大,先验对后验的影响会消失。对吗?

<details><summary>查看答案</summary>

**对**。以正态–正态为例,后验均值 $= \frac{\mu_0/\tau^2 + n\bar{x}/\sigma^2}{1/\tau^2 + n/\sigma^2} \to \bar{x}$,后验方差 $= \frac{1}{1/\tau^2 + n/\sigma^2} \to 0$(当 $n \to \infty$)。只要先验不取「角点」式的极端分布,数据量足够大时后验几乎完全由数据决定——这就是常说的「数据终将压过先验」,也是频率学派与贝叶斯学派在大样本下结论趋同的原因。

</details>

**第 4 题(概念)**:95% 可信区间与 95% 置信区间有何区别?竞赛论文里各该怎么表述?

<details><summary>查看答案</summary>

置信区间是频率学派的工具:区间端点随样本变化,长期重复抽样下有 95% 的实验「区间覆盖真值」,但对眼前这一次实验,不能说「真值有 95% 概率在区间里」。可信区间是贝叶斯学派的工具:给定先验与这批数据,后验分布上 95% 的质量集中在区间内,因此可以直说「参数有 95% 概率落在该区间」。论文表述:频率方法写「在 95% 置信水平下,区间为 …」;贝叶斯方法写「参数的后验 95% 可信区间为 …,即给定数据与先验,参数落入该区间的概率为 0.95」。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:国赛 C 题(评价、预测、信用评分)、美赛流行病与可靠性类题目中,贝叶斯是处理「数据少、先验知识多」场景的王牌;朴素贝叶斯分类器也是文本类题目(如投诉分类)的基线模型
- **论文加分点**:①画出**先验 → 似然 → 后验**三线同图,直观展示数据如何更新信念;②**先验敏感性分析**——换 2~3 组先验说明结论稳健;③需要数值积分或 MCMC 时,报告 burn-in、轨迹图与后验摘要表(均值 / 标准差 / 95% 可信区间)
- **工具**:解析共轭用 `scipy.stats`;任意模型用 PyMC(语法最友好)或 Stan;轻量采样可用 `emcee`;核密度估计画后验用 `scipy.stats.gaussian_kde`

## 💻 代码实现

```python
import numpy as np
from scipy.stats import beta, norm

# 1. 疾病检测 (例题 1)
p = 0.99 * 0.01 / (0.99 * 0.01 + 0.05 * 0.99)
print(f"患病率 1% 时 P(D|T+) = {p:.4f}")                       # 0.1667 = 1/6
p2 = 0.99 * 0.001 / (0.99 * 0.001 + 0.05 * 0.999)
print(f"患病率 0.1% 时 P(D|T+) = {p2:.4f}")                    # 0.0194

# 2. Beta-二项后验 (例题 2): 先验 Beta(2,2), 10 次 7 正
a, b = 2 + 7, 2 + 3                                            # 后验 Beta(9,5)
print(f"后验均值 = {a/(a+b):.4f}")                             # 0.6429
lo, hi = beta.ppf(0.025, a, b), beta.ppf(0.975, a, b)
print(f"95% 等尾可信区间 = [{lo:.4f}, {hi:.4f}]")              # [0.3857, 0.8614]

# 3. 正态-正态后验 (例题 3)
mu0, tau2, sig2, n, xbar = 0.0, 4.0, 1.0, 10, 0.6
prec = 1/tau2 + n/sig2
post_mean = (mu0/tau2 + n*xbar/sig2) / prec
post_var = 1 / prec
print(f"后验均值 = {post_mean:.4f}, 后验方差 = {post_var:.4f}")
print(f"95% 区间 = [{post_mean-1.96*np.sqrt(post_var):.3f}, {post_mean+1.96*np.sqrt(post_var):.3f}]")

# 4. MH 采样: 估计 Beta(9,5) 后验均值 (仅需对数核, 无需归一化常数)
rng = np.random.default_rng(42)

def logp(x):                        # Beta(9,5) 的对数核: 8 ln x + 4 ln(1-x)
    return 8*np.log(x) + 4*np.log(1-x)

n_iter, x, acc, chain = 20000, 0.5, 0, []
for _ in range(n_iter):
    y = x + rng.uniform(-0.3, 0.3)  # 对称提议分布 (随机游走 MH)
    if 0 < y < 1 and np.log(rng.random()) < logp(y) - logp(x):
        x, acc = y, acc + 1
    chain.append(x)
chain = np.array(chain)[2000:]      # 丢弃 burn-in 段
print(f"MH 接受率 = {acc/n_iter:.3f}")                        # 约 0.58
print(f"MH 后验均值 = {chain.mean():.4f} (解析值 9/14 = 0.6429)")
```

> 输出与例题完全对应:患病率 1% → $1/6$;Beta(9,5) 区间 $[0.386, 0.861]$;正态–正态区间 $[-0.027, 1.198]$。MH 的均值估计约 0.6447,与解析值 0.6429 仅差 0.2%。

## 🧠 小结

1. 贝叶斯的核心一句话:**后验 ∝ 先验 × 似然**;数据到来前后,对参数的信念以分布形式更新
2. 共轭先验让后验闭式可写:Beta–二项、正态–正态、Gamma–泊松三组要能默写,均值都是「精度加权平均」
3. 后验推断三件套:后验均值(或 MAP)、可信区间(等尾 / HPDI)、后验预测分布
4. 先验强则结论依赖先验:伪样本数、敏感性分析是论文的加分点与易错点
5. 后验不可解析时用 MCMC:MH 靠接受-拒绝、Gibbs 靠条件分布采样,报告前必须 burn-in 与收敛诊断
