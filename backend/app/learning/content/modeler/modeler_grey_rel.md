## 📖 核心概念

### 1. 灰色系统与关联分析的思想

邓聚龙教授 1982 年提出灰色系统理论。按信息完备程度,系统分为三类:**白色系统**(信息完全已知)、**黑色系统**(信息完全未知)、**灰色系统**(部分已知、部分未知)。现实中的社会经济系统大多是灰色的——数据样本小、分布规律不清。

灰色关联分析(Grey Relational Analysis, GRA)的基本思想非常直观:**如果两条序列曲线的几何形状越相似,它们的关联就越紧密**。曲线走势同步上升、同步下降,说明背后的因素相互关联。与统计学相关分析不同,GRA 不要求大样本、不要求正态分布等假设,样本少、数据「贫」时也能用——这正是它在竞赛中的生存空间。

### 2. 参考序列与比较序列

- **参考序列**(母序列)$x_0 = (x_0(1), \dots, x_0(n))$:反映系统特征的序列,如 GDP、综合得分
- **比较序列**(子序列)$x_i = (x_i(1), \dots, x_i(n))$,$i = 1,\dots,m$:影响系统行为的因素序列,如投资、消费、出口

关联分析的目标:算出每个比较序列与参考序列的**关联度** $r_i$,排序即得因素影响力排序。

### 3. 无量纲化:为什么必须做

不同序列量纲、数量级不同(投资以亿元计、就业以万人计),直接相减没有意义。常用两种:

- **初值化**:$x'(k) = \dfrac{x(k)}{x(1)}$——所有序列除以自己的第一个值,突出「从起点出发的变化趋势」
- **均值化**:$x'(k) = \dfrac{x(k)}{\bar{x}}$——除以自己的均值,突出「围绕自身均值的波动」

> 💡 初值化是国赛论文中最常用的选择(与「发展速度」的直觉一致),但要注意:初值化后所有序列在 $k=1$ 处恒等于 1,第一点对关联系数「白送」一个 1(见例题 1 解析)。

### 4. 差序列与两级差

无量纲化后计算差序列:

$$\Delta_i(k) = \left| x_0'(k) - x_i'(k) \right|$$

再取全体差序列的两个极值:

- **两级最小差**:$m = \min_i \min_k \Delta_i(k)$
- **两级最大差**:$M = \max_i \max_k \Delta_i(k)$

### 5. 关联系数与关联度(邓氏关联度)

关联系数度量两序列在**第 $k$ 个点**上的关联程度:

$$\xi_i(k) = \frac{m + \rho M}{\Delta_i(k) + \rho M}, \qquad \rho \in (0, 1) \text{ 为分辨系数,通常取 } 0.5$$

- $\Delta_i(k) = 0$(两点重合):$\xi_i(k) = 1$,关联最强
- $\Delta_i(k) = M$(差距最大):$\xi_i(k) = \dfrac{\rho}{1+\rho}$(取 $\rho = 0.5$ 时为 $1/3$),关联最弱
- 因此**关联系数恒在 $[\rho/(1+\rho),\ 1]$ 之间**,它衡量的是相对差距,不是绝对差距

对关联系数逐点平均,得到**关联度**:

$$r_i = \frac{1}{n} \sum_{k=1}^{n} \xi_i(k), \qquad r_i \text{ 越大,序列 } i \text{ 与参考序列关联越紧密}$$

### 6. 两种典型用法

- **因素筛选**:参考序列取核心指标,比较序列为候选影响因素;关联度排序后筛掉关联度小的因素(常用于指标体系的精简)
- **综合评价**:参考序列取「理想方案」(各指标最优值拼成),比较序列为各评价对象;每个对象的关联度就是它的得分,关联度越大越好。这是灰色关联与 TOPSIS 思路的结合点(参见《TOPSIS理想解逼近法》单元)

## 🧮 公式与结论

### 邓氏关联度五步

1. 无量纲化:初值化 $x'(k) = x(k)/x(1)$ 或均值化
2. 差序列:$\Delta_i(k) = |x_0'(k) - x_i'(k)|$
3. 两级极差:$m = \min_i\min_k \Delta_i(k)$,$M = \max_i\max_k \Delta_i(k)$
4. 关联系数:$\xi_i(k) = \dfrac{m + \rho M}{\Delta_i(k) + \rho M}$
5. 关联度:$r_i = \dfrac{1}{n}\sum_k \xi_i(k)$,按 $r_i$ 降序排序

### 性质

- $\dfrac{\rho}{1+\rho} \le \xi_i(k) \le 1$;对**同一时点 $k$**,两个序列关联系数的大小关系不随 $\rho$ 改变($\xi_i(k) > \xi_j(k) \iff \Delta_i(k) < \Delta_j(k)$);但**平均关联度的排序可能随 $\rho$ 变化**——当两序列的差序列交叉(一个前段差距小、一个后段差距小)时,$\rho$ 增大(整体数值抬高、差距抹平)或减小(差距拉大)都可能导致总分排序反转,因此报告结果时应注明 $\rho$ 取值,必要时做 $\rho$ 敏感性检查
- 关联度是相对量:换一批比较序列,$r_i$ 会变;同一数据集内比较才有意义
- $x_i$ 与 $x_0$ 逐点重合时 $r_i = 1$(最大关联)

### 关联度的三种变体

- **邓氏关联度**:上式,最常用,对序列「距离」敏感
- **绝对关联度**:基于初值化后序列的**一阶差分**,度量变化率的相似性,剔除「平移差距」
- **相对关联度**:度量相对于起点的**变化速率**关联
- **综合关联度**:$r = \alpha r_{\text{绝对}} + (1-\alpha) r_{\text{相对}}$,兼顾水平与速率

## 💡 经典例题

### 例题 1:影响因素筛选(完整手算)

> 某省 4 年 GDP 为参考序列,固定资产投资、社会消费品零售额、某常数项支出为比较序列:
>
> $$\begin{aligned} x_0 &= (10,\ 12,\ 9,\ 15) \\ x_1 &= (5,\ 8,\ 7,\ 12), \quad x_2 = (20,\ 22,\ 21,\ 28), \quad x_3 = (7,\ 7,\ 7,\ 7) \end{aligned}$$

**第一步:初值化。** 各序列除以自身第一项:

$$\begin{aligned} x_0' &= (1,\ 1.2,\ 0.9,\ 1.5) \\ x_1' &= (1,\ 1.6,\ 1.4,\ 2.4), \quad x_2' = (1,\ 1.1,\ 1.05,\ 1.4), \quad x_3' = (1,\ 1,\ 1,\ 1) \end{aligned}$$

**第二步:差序列。**

$$\Delta_1 = (0,\ 0.4,\ 0.5,\ 0.9), \qquad \Delta_2 = (0,\ 0.1,\ 0.15,\ 0.1), \qquad \Delta_3 = (0,\ 0.2,\ 0.1,\ 0.5)$$

两级差:$m = 0$,$M = 0.9$。

**第三步:关联系数。** 取 $\rho = 0.5$,$\rho M = 0.45$:

$$\xi_1 = \left(\frac{0.45}{0.45},\ \frac{0.45}{0.85},\ \frac{0.45}{0.95},\ \frac{0.45}{1.35}\right) = (1,\ 0.5294,\ 0.4737,\ 0.3333)$$

$$\xi_2 = \left(1,\ \frac{0.45}{0.55},\ \frac{0.45}{0.60},\ \frac{0.45}{0.55}\right) = (1,\ 0.8182,\ 0.75,\ 0.8182)$$

$$\xi_3 = \left(1,\ \frac{0.45}{0.65},\ \frac{0.45}{0.55},\ \frac{0.45}{0.95}\right) = (1,\ 0.6923,\ 0.8182,\ 0.4737)$$

**第四步:关联度。**

$$r_1 = \frac{1 + 0.5294 + 0.4737 + 0.3333}{4} = 0.5841, \quad r_2 = \frac{1 + 0.8182 + 0.75 + 0.8182}{4} = 0.8466, \quad r_3 = \frac{1 + 0.6923 + 0.8182 + 0.4737}{4} = 0.7460$$

**排序:$r_2 > r_3 > r_1$,消费品零售与 GDP 关联最紧。**

**解析**:$x_2$ 与 $x_0$ 的曲线形状几乎同步(都在第 2 年上升、第 3 年回落、第 4 年冲高),关联度最高,符合直觉;$x_1$ 增速长期高于 $x_0$,形状偏离最大。注意两点:①**初值化白送了第 1 点**:所有序列初值化后第一点都是 1,$\xi_i(1) \equiv 1$ 会拉高所有关联度——这是初值化的固有效应,论文中不必回避;②$x_3$ 是常数序列,其关联度仍有 0.746,说明**关联度高不等于因果**,常数序列与上升序列的「形状相似」是虚假关联,GRA 只能作为筛选的参考,不能替代因果检验。

### 例题 2:理想序列法的综合评价

> 3 个方案、3 个正向指标,理想方案取各指标最优值:
>
> $$\begin{aligned} A_1 &= (8,\ 6,\ 7), \quad A_2 = (7,\ 9,\ 6), \quad A_3 = (6,\ 8,\ 9) \\ x_0 &= (8,\ 9,\ 9) \quad \text{(理想参考序列)} \end{aligned}$$

(本例指标已同量纲,直接计算差序列;一般情形应先无量纲化。)

$$\Delta_1 = (0,\ 3,\ 2), \qquad \Delta_2 = (1,\ 0,\ 3), \qquad \Delta_3 = (2,\ 1,\ 0)$$

两级差:$m = 0$,$M = 3$;$\rho = 0.5$,$\rho M = 1.5$。关联系数:

$$\xi_1 = \left(1,\ \frac{1.5}{4.5},\ \frac{1.5}{3.5}\right) = (1,\ 0.3333,\ 0.4286), \qquad r_1 = \frac{1.7619}{3} = 0.5873$$

$$\xi_2 = \left(\frac{1.5}{2.5},\ 1,\ \frac{1.5}{4.5}\right) = (0.6,\ 1,\ 0.3333), \qquad r_2 = \frac{1.9333}{3} = 0.6444$$

$$\xi_3 = \left(\frac{1.5}{3.5},\ \frac{1.5}{2.5},\ 1\right) = (0.4286,\ 0.6,\ 1), \qquad r_3 = \frac{2.0286}{3} = 0.6762$$

**排序:$A_3 > A_2 > A_1$。** 每个方案的关联度即其综合得分。

**解析**:$A_3$ 在指标 3 上与理想解完全重合(贡献 $\xi = 1$),总关联度最高。这个用法与 TOPSIS 高度互补:TOPSIS 强调「距离」,灰色关联强调「形状」,两者可结合成灰色关联 TOPSIS(参见《TOPSIS理想解逼近法》单元);权重可引入熵权或 AHP,把加权和 $\sum w_j \xi_i(j)$ 作为关联度(参见《熵权法与客观赋权》单元)。

## ⚠️ 常见易错点

1. **不做无量纲化直接相减**。不同量纲序列的差没有意义,必须先初值化或均值化;只对参考序列做、比较序列不做同样是错的
2. **两级极差取错**。$m$ 和 $M$ 必须对**全体**差序列取极值(两级),不是每个序列各自取极值;取错会导致 $\xi$ 全部偏高
3. **ρ 的取值方向理解反**。ρ 越小,关联系数之间差异被拉得越大(分辨率越高)、整体数值越低;ρ 与权重无关,通常取 0.5 并在论文中说明
4. **拿关联度当因果/显著性的证据**。关联度没有显著性检验,常数序列、同趋势序列都能拿到高关联度;因素筛选后应结合经济含义或统计检验再下结论
5. **跨数据集比较关联度**。换参考序列、换比较对象,关联度整体变化;只能同一分析内部排序
6. **忽略初值化的「第一点恒为 1」效应**。初值化后所有序列首点重合,关联系数恒为 1,会系统性抬高关联度;敏感时可用均值化或绝对关联度对比验证

## ✏️ 自测练习

**第 1 题(计算)**:$x_0 = (1, 2, 3)$,比较序列 $x_1 = (1, 2, 3)$ 与 $x_2 = (1, 2, 2)$。求两者的邓氏关联度($\rho = 0.5$,本例数据已同量纲,可直接计算)。

<details><summary>查看答案</summary>

$$r_1 = 1 \quad \text{(逐点重合,天然完全关联)}$$

对 $x_2$:$\Delta = (0,\ 0,\ 1)$,$m = 0$,$M = 1$,$\rho M = 0.5$:

$$\xi_2 = \left(1,\ 1,\ \frac{0.5}{1.5}\right) = (1,\ 1,\ 0.3333), \qquad r_2 = \frac{2.3333}{3} = 0.7778$$

$x_1 > x_2$,符合直觉($x_1$ 与参考序列完全重合)。

</details>

**第 2 题(判断)**:邓氏关联系数 $\xi_i(k)$ 的取值范围是 $[0, 1]$。对吗?

<details><summary>查看答案</summary>

**不准确。** 正确范围是 $\left[\dfrac{\rho}{1+\rho},\ 1\right]$:$\Delta_i(k) = 0$ 时取 1;$\Delta_i(k) = M$(最大差)时取 $\dfrac{m+\rho M}{M+\rho M} = \dfrac{\rho M}{(1+\rho)M} = \dfrac{\rho}{1+\rho}$($m = 0$ 时)。取 $\rho = 0.5$ 时下限为 $1/3$——所以关联度数值看起来总是「偏高」,这是构造使然,排序比较时不必惊讶。

</details>

**第 3 题(概念)**:分辨系数 ρ 取 0.1 与取 0.9,关联度会怎么变?排序会变吗?

<details><summary>查看答案</summary>

ρ 减小时,分子 $m + \rho M$ 减小,且分母中 $\rho M$ 占比下降,各关联系数的**数值整体下降、相互差异拉大**(分辨率提高);ρ 增大则数值整体抬升、趋于平坦。就单个时点而言,两个序列关联系数的大小关系与 ρ 无关(只取决于差序列的大小),但**平均关联度的排序可能随 ρ 改变**:当两序列与参考序列的差距「此起彼伏」(前段一个更近、后段另一个更近)时,ρ 的取值会改变总分排序。因此通常取 ρ = 0.5 并在论文中说明取值理由,必要时做 ρ 敏感性检查(如 0.3、0.5、0.7 三档对比)。

</details>

**第 4 题(概念)**:灰色关联分析与统计学中的 Pearson 相关系数有何区别?什么场景优先用 GRA?

<details><summary>查看答案</summary>

主要区别:①GRA 度量序列**几何形状**的相似性,相关系数度量**线性**相关强度;②GRA 无分布假设、无显著性检验,相关系数要求正态性并可做假设检验;③GRA 对样本量要求低,小样本(如 $n < 10$)仍可计算,相关系数在小样本下极不稳定;④GRA 结果依赖无量纲化方式与 ρ,相关系数不依赖。场景:数据量小、分布未知、关系非线性、需要快速筛选影响因素时优先 GRA;大样本、要求统计显著性时用相关分析,两者可互补使用。

</details>

## 🏆 竞赛实战链接

- **出镜频率**:灰色关联是国赛「小样本、贫信息」场景的常客,典型用法:①影响因素筛选(指标精简);②与熵权/TOPSIS 组合的综合评价(熵权灰色关联、灰色关联 TOPSIS);③GM(1,1) 灰色预测的前置分析

## 💻 代码实现

```python
import numpy as np

x0 = np.array([10., 12., 9., 15.])
X = np.array([[5., 8., 7., 12.],
              [20., 22., 21., 28.],
              [7., 7., 7., 7.]])

def grey_rel(x0, X, rho=0.5):
    """邓氏关联度。x0: 参考序列;X: 比较序列矩阵(每行一个序列)"""
    x0 = x0 / x0[0]                    # 初值化
    X = X / X[:, 0:1]
    delta = np.abs(X - x0)             # 差序列
    m, M = delta.min(), delta.max()    # 两级极差
    xi = (m + rho * M) / (delta + rho * M)   # 关联系数
    return xi, xi.mean(axis=1)         # 关联度

xi, r = grey_rel(x0, X)
print("关联系数:\n", np.round(xi, 4))
# [[1.     0.5294 0.4737 0.3333]
#  [1.     0.8182 0.75   0.8182]
#  [1.     0.6923 0.8182 0.4737]]
print("关联度:", np.round(r, 4))       # [0.5841 0.8466 0.746 ]
print("排序  :", np.argsort(-r) + 1)   # [2 3 1]

# 综合评价:理想序列法(例题 2)
x0_ideal = np.array([8., 9., 9.])
A = np.array([[8., 6., 7.],
              [7., 9., 6.],
              [6., 8., 9.]])
_, score = grey_rel(x0_ideal, A)       # 指标已同量纲,仍用初值化不影响排序
print("综合得分:", np.round(score, 4))  # [0.5873 0.6444 0.6762]
```

## 🧠 小结

1. 灰色关联的思想:曲线形状越相似,关联越紧密;适合小样本、贫信息、分布未知的场景
2. 五步流程:无量纲化(初值化/均值化)→ 差序列 → 两级极差 → 关联系数($\rho$ 通常 0.5)→ 平均得关联度排序
3. 关联系数恒在 $[\rho/(1+\rho), 1]$,数值天然偏高,排序比较才有意义;跨数据集不可比
4. 两大用法:因素筛选(参考 = 核心指标)与综合评价(参考 = 理想方案),后者是灰色关联与 TOPSIS/熵权组合的接口
5. 关联度高 ≠ 因果强;无显著性检验是 GRA 的先天短板,结论要结合领域知识与其他方法交叉验证
