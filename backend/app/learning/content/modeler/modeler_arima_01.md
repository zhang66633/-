## 📖 核心概念

### 1. 时间序列与平稳性

时间序列是按时间顺序排列的观测 $\{y_t\}$。ARIMA 建模的核心假设是**平稳性**:序列的统计性质(均值、方差、自协方差)不随时间的平移而改变。

- **严平稳**:任意时间窗口的联合分布都相同;**宽平稳**(工程上够用):均值恒定、方差有限、自协方差只依赖滞后阶数 $k$
- 平稳性为什么重要:非平稳序列的统计规律随时间的漂移,「过去学到的」无法用于「未来预测」
- **白噪声**:零均值、同方差、序列不相关的序列,是 ARIMA 的「理想残差」——建模成功的标志就是残差变成白噪声

### 2. ADF 单位根检验

- 原假设 $H_0$:序列**有单位根**(非平稳);备择假设:平稳
- $p < 0.05$ 拒绝原假设 → 平稳;注意与普通检验相反,这里我们**希望**拒绝 $H_0$
- 差分是对付非平稳的手术刀:一阶差分 $\nabla y_t = y_t - y_{t-1}$ 消去线性趋势;随机游走差分后变成白噪声
- $d$ 就是为达到平稳所需的差分阶数,一般 $d \leq 2$——**过度差分**会引入虚假的负自相关

### 3. AR(p) 与 MA(q):两类「记忆」

**AR(p) 自回归**:当前值由过去 $p$ 个值线性回归得到:

$$y_t = c + \phi_1 y_{t-1} + \dots + \phi_p y_{t-p} + \varepsilon_t$$

平稳条件:特征方程 $1 - \phi_1 z - \dots - \phi_p z^p = 0$ 的根全部在单位圆外;对 AR(1) 即 $|\phi_1| < 1$。AR 的记忆「无限长但逐期衰减」。

**MA(q) 移动平均**:当前值由过去 $q$ 个随机冲击(误差)加权:

$$y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \dots + \theta_q \varepsilon_{t-q}$$

MA 的记忆只有 $q$ 期——滞后超过 $q$ 阶的自相关系数**严格为 0**(截尾),这是定阶的关键特征。

### 4. ACF 与 PACF:定阶的两面镜子

- **ACF(k)**:$y_t$ 与 $y_{t-k}$ 的相关系数 $\rho_k$,衡量**总**相关(包含经中间各期间接传递的影响)
- **PACF(k)**:剔除中间各期影响后 $y_t$ 与 $y_{t-k}$ 的**直接**相关

定阶规则表:

| 模型 | ACF | PACF |
|------|-----|------|
| AR(p) | 拖尾(指数/震荡衰减) | $p$ 阶后截尾 |
| MA(q) | $q$ 阶后截尾 | 拖尾 |
| ARMA(p,q) | 拖尾 | 拖尾 |

「截尾」的判据:相关系数超出 $\pm 2/\sqrt{n}$ 的显著性带算显著,连续落入带内即为截尾。

### 5. Box–Jenkins 建模流程

1. 画时序图,识别趋势、季节性与异常点
2. ADF 检验,必要时差分(定 $d$)
3. 画 ACF/PACF,结合 AIC/BIC 定 $p, q$
4. 估计参数(极大似然),检查系数显著性
5. 诊断:残差白噪声检验(Ljung-Box 检验,$p > 0.05$ 通过)
6. 预测:点预测 + 区间预测

## 🧮 公式与结论

### AR(1) 的预测公式(手算模板)

对 $y_t = c + \phi_1 y_{t-1} + \varepsilon_t$($|\phi_1| < 1$,$\varepsilon_t \sim N(0, \sigma^2)$),在时刻 $T$ 向前 $h$ 步:

$$\hat y_{T+h \mid T} = \phi_1^h\, y_T + c\,\frac{1 - \phi_1^h}{1 - \phi_1}$$

$h$ 步预测的方差(区间宽度的来源):

$$\mathrm{Var}(e_{T+h \mid T}) = \sigma^2\,(1 + \phi_1^2 + \dots + \phi_1^{2(h-1)}) \ \xrightarrow{h \to \infty}\ \frac{\sigma^2}{1 - \phi_1^2}$$

- 点预测按几何速率收敛到无条件均值 $c/(1-\phi_1)$——**均值回复**
- 95% 预测区间:$\hat y_{T+h \mid T} \pm 1.96 \sqrt{\mathrm{Var}(e)}$;随 $h$ 增大而变宽,最终稳定在 $\pm 1.96\, \sigma/\sqrt{1-\phi_1^2}$
- 平稳序列的长期预测等于「均值 + 很宽的区间」——这不是缺陷,是统计规律的诚实表达

### AIC/BIC 定阶

$$AIC = -2\ln L + 2k, \qquad BIC = -2\ln L + k\ln n$$

$k$ 为参数个数。在候选 $(p, d, q)$ 网格中取最小者;两者冲突时,BIC 倾向更简洁的模型,预测任务常用 AIC。

### 差分与季节性提示

- 一阶差分:$\nabla y_t = y_t - y_{t-1}$;二阶差分:$\nabla^2 y_t = \nabla y_t - \nabla y_{t-1}$
- ACF 在季节滞后(如月度数据的滞后 12)处居高不下 → 存在季节性,应改用 SARIMA$(p,d,q)(P,D,Q)_s$,或先做季节差分 $\nabla_s y_t = y_t - y_{t-s}$
- 方差随水平增长(指数型序列)时先取对数再差分,即「对数收益率」:$r_t = \ln y_t - \ln y_{t-1}$

## 💡 经典例题

### 例题 1:判断平稳性与差分

> 序列 A:$y_t = 3, 6, 9, 12, 15$(确定性线性趋势);序列 B:随机游走 $y_t = y_{t-1} + \varepsilon_t$。判断平稳性,并说明差分后的形态。

**序列 A**:均值随 $t$ 线性增长 → 非平稳(ADF 无法拒绝单位根)。一阶差分:$\nabla y_t = 3, 3, 3, 3$,常数序列 → 平稳,$d = 1$。

**序列 B**:随机游走是非平稳的原型——方差 $\mathrm{Var}(y_t) = t\sigma^2$ 随时间线性增长、无界。一阶差分 $\nabla y_t = \varepsilon_t$ → 白噪声,$d = 1$。

**解析**:两者 $d$ 都取 1,但「病根」不同:确定性趋势 vs 单位根。实战中画图能区分——趋势平稳序列「贴着直线走」,随机游走「乱逛且越走越散」。前者正确做法是**先拟合趋势、对残差建模**(或直接用带漂移项 $\mu$ 的 ARIMA);对趋势平稳序列做差分反而是过度差分。这个区分是论文里体现功力的细节。

### 例题 2:AR(1) 手算预测

> 拟合得 $y_t = 0.6\, y_{t-1} + \varepsilon_t$($c = 0$,$\sigma = 1$,序列已中心化),最后一期观测 $y_T = 10$。求未来 3 步的点预测与 95% 区间。

| 步数 $h$ | 点预测 | 预测方差 | 标准差 | 95% 区间 |
|----------|--------|----------|--------|----------|
| 1 | $0.6 \times 10 = 6.0$ | $1$ | 1.000 | $6.0 \pm 1.96$,即 $(4.04, 7.96)$ |
| 2 | $0.6 \times 6 = 3.6$ | $1 \times (1 + 0.36) = 1.36$ | 1.166 | $3.6 \pm 2.29$,即 $(1.31, 5.89)$ |
| 3 | $0.6 \times 3.6 = 2.16$ | $1 \times (1 + 0.36 + 0.1296) = 1.4896$ | 1.221 | $2.16 \pm 2.39$,即 $(-0.23, 4.55)$ |

$h \to \infty$:点预测趋于 0(无条件均值 $c/(1-\phi_1) = 0$),方差趋于 $1/(1 - 0.36) = 1.5625$,标准差 1.25,区间稳定在 $\pm 2.45$。

**解析**:预测值以 0.6 的几何速率衰减回均值——序列「忘记」了当前值 10;区间从 $\pm 1.96$ 扩张到 $\pm 2.45$ 后不再变宽(新冲击的方差恰好被自回归衰减抵消)。若 $c \neq 0$,长期预测收敛到 $c/(1-\phi_1)$,可用此极限校验自己的计算。

### 例题 3:从 ACF/PACF 图定阶

> 模拟一个 $n = 100$ 的 MA(2) 序列($\theta_1 = 0.6,\ \theta_2 = 0.3$,seed 固定可复现),画出的样本 ACF 为 $(0.54, 0.25, 0.14, 0.11, 0.09, 0.06)$(显著性带 $\pm 2/\sqrt{100} = \pm 0.20$),PACF 为 $(0.55, -0.06, 0.04, 0.04, 0.03, -0.02)$。如何定阶?

**看截尾**:ACF 前两阶 $(0.54, 0.25)$ 显著,第 3 阶起 $(0.14, 0.11, \dots)$ 全部落入带内 → ACF 在 $q = 2$ 后截尾;PACF 一阶后迅速衰减 → 拖尾。按规则表:**MA(2)**。

**信息准则复核**:拟合 MA(2) 与 MA(3),AIC 分别为 261.75 与 263.23,BIC 为 272.09 与 276.15 → 两准则都选 MA(2)。

**残差诊断**:MA(2) 的残差 Ljung-Box 检验 $p = 0.87 > 0.05$,残差为白噪声,模型通过。

**解析**:定阶是「图 + 准则 + 诊断」三管齐下,不是看图猜数。若 ACF 与 PACF 都拖尾,则是 ARMA,直接在小网格 $(p,q) \in \{0,1,2,3\}^2$ 里用 AIC 搜索。论文里把这套流程写成表格——每个候选模型的 AIC 与残差检验 $p$ 值——评委一眼就明白你懂行。

## ⚠️ 常见易错点

1. **不检验平稳性直接建模**。两个独立的随机游走之间做回归也能得到「显著」的系数——伪回归;先用 ADF 检验,不平稳先差分
2. **ADF 结论解读颠倒**。$p > 0.05$ 意味着「不能拒绝有单位根」→ 非平稳,需要差分;把「接受原假设」说成「序列平稳」是最常见的翻车
3. **只凭肉眼定阶,不看显著性带**。截尾判断要用 $\pm 2/\sqrt{n}$;小样本下 ACF 本身噪声很大,肉眼「看起来截尾」不可靠
4. **只画 ACF 不画 PACF(或反之)**。AR 看 PACF 截尾,MA 看 ACF 截尾,两个图缺一不可
5. **差分过度**。对已经平稳的序列再差分,会引入虚假的 MA(1) 结构(负自相关);$d$ 一般不超过 2
6. **预测只给点值**。ARIMA 的区间预测是标配,且平稳序列的长期区间会稳定下来——直接报告软件输出的区间即可

## ✏️ 自测练习

**第 1 题(判断)**:随机游走 $y_t = y_{t-1} + \varepsilon_t$ 平稳吗?ADF 检验的原假设是什么?若 ADF 检验得 $p = 0.3$,说明什么、该怎么办?

<details><summary>查看答案</summary>

随机游走**非平稳**:方差 $t\sigma^2$ 随时间线性增长。ADF 原假设是「序列有单位根(非平稳)」;$p = 0.3 > 0.05$ 不能拒绝原假设 → 判定非平稳。处理:做一阶差分 $\nabla y_t = y_t - y_{t-1} = \varepsilon_t$(白噪声,平稳),再对差分序列建模,即 $d = 1$。

</details>

**第 2 题(计算)**:AR(1) 模型 $y_t = 2 + 0.5\, y_{t-1} + \varepsilon_t$,$\sigma = 1$,$y_T = 8$。求未来 2 步的点预测与 95% 区间,并给出长期预测极限。

<details><summary>查看答案</summary>

1 步:$\hat y_{T+1} = 2 + 0.5 \times 8 = 6$,方差 $1$ → 区间 $6 \pm 1.96 = (4.04, 7.96)$。
2 步:$\hat y_{T+2} = 2 + 0.5 \times 6 = 5$,方差 $1 \times (1 + 0.25) = 1.25$,标准差 $1.118$ → 区间 $5 \pm 2.19 = (2.81, 7.19)$。
长期:点预测收敛到 $c/(1-\phi_1) = 2/0.5 = 4$,方差收敛到 $1/(1-0.25) = 1.333$,区间稳定在 $4 \pm 2.26$。

</details>

**第 3 题(定阶)**:某平稳序列的样本 ACF 为 $(0.80, 0.64, 0.51, 0.41, \dots)$ 缓慢衰减,显著不为零;PACF 为 $(0.80, 0.05, -0.02, \dots)$ 一阶后即落入显著性带。定什么模型?

<details><summary>查看答案</summary>

ACF 拖尾、PACF 在 1 阶后截尾 → **AR(1)**。ACF 缓慢衰减与 $\phi_1 = 0.8$ 一致($\rho_k = \phi_1^k$),PACF 截尾是 AR 的特征。定阶后仍需用 AIC/BIC 与残差白噪声检验复核。

</details>

**第 4 题(概念)**:为什么说「长期预测等于均值 + 宽区间」是平稳序列的诚实表达,而不是模型的缺陷?

<details><summary>查看答案</summary>

平稳性意味着序列有「引力中心」(无条件均值),远离均值后会被拉回——所以点预测必然回归均值,这是数据本身的性质。区间变宽是因为预测期越远,需要「穿行」的随机冲击越多;区间最终稳定是因为自回归的衰减恰好抵消新冲击方差的累加。若题目需要「确定性趋势外推」式的预测(如人口增长),ARIMA 应带漂移项或与趋势模型结合使用。

</details>

## 💻 代码实现

```python
import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt

# 模拟一个 AR(2) 序列:y_t = 0.6 y_{t-1} + 0.3 y_{t-2} + eps
rng = np.random.default_rng(1)
n = 200
eps = rng.normal(0, 1, n)
y = np.zeros(n)
for t in range(2, n):
    y[t] = 0.6 * y[t-1] + 0.3 * y[t-2] + eps[t]

# 1) ADF 平稳性检验
p_adf = adfuller(y, autolag="AIC")[1]
print("ADF p 值:", round(p_adf, 4))          # p < 0.05 → 平稳

# 2) ACF / PACF(真实数据不平稳时先 y = np.diff(y))
plot_acf(y, lags=20); plot_pacf(y, lags=20); plt.show()

# 3) 拟合与诊断
model = sm.tsa.ARIMA(y, order=(2, 0, 0)).fit()
print(model.summary())                        # 系数应接近 0.6 / 0.3
lb = sm.stats.acorr_ljungbox(model.resid, lags=[10], return_df=True)
print("Ljung-Box p 值:", round(lb["lb_pvalue"][0], 3))   # > 0.05 通过

# 4) 预测
fc = model.get_forecast(10)
print("点预测:", fc.predicted_mean.round(2))
print("95% 区间:\n", fc.conf_int().round(2))
```

> 真实数据不平稳时:先 `y.diff().dropna()` 再走同一流程;对**差分序列**做的预测要用 `np.cumsum` 还原回原水平。

## 🧠 小结

1. 平稳性是 ARIMA 的地基:均值/方差/自相关不随时间变,预测才有「可学」的规律;ADF 检验 $p < 0.05$ 才平稳
2. 定阶三件套:ACF/PACF 图看截尾拖尾、AIC/BIC 网格比较、残差 Ljung-Box 白噪声检验
3. AR(p) 用过去的值,特征 PACF 截尾;MA(q) 用过去的冲击,特征 ACF 截尾;两者都拖尾才是 ARMA
4. AR(1) 预测:点预测按 $\phi_1^h$ 几何收敛到均值,区间先变宽后稳定——均值回复是平稳序列的本质
5. 竞赛论文的价值不在模型花哨,而在流程完整:检验 → 定阶 → 诊断 → 回测评估,一样都不能少
